# game-dev

《江湖从心》游戏开发总仓库 —— 武侠开放世界 + 单机 RPG 项目的工作空间。

## 仓库结构

| 目录 | 说明 |
| --- | --- |
| `jianghu-design/` | 方案设计项目。含完整策划案、执行版 GDD、系统设计、数值框架、引擎与技术选型评估 |
| `jianghu-game/` | 游戏开发项目。TypeScript + Phaser 3 技术栈，含 Core 逻辑、骨架（Rig）系统、动画运行时与测试 |
| `jianghu-tools/` | 辅助功能开发项目。编辑器、工具链与参考资料 |

## 根目录交付物

- `江湖从心_完整策划设计_v1.0.md` — 执行版 GDD（唯一执行口径）
- `江湖从心_引擎选型评估报告_v1.0.md` — 引擎与技术架构评估
- `江湖从心_策划案_v0.2.md` — 早期策划案

## 项目要点

- **玩法**：武侠开放世界 + 单机 RPG，2.5D 斜视角，水墨江湖风，多端支持
- **系统**：六类外功 + 内功 + 身法；功法品质 × 境界双维度；连招起势/收势匹配；好感度伙伴培养
- **商业化**：双轨定价 —— PC 买断 + 移动免费本体 + 纯外观/剧情/便利内购；不卖数值
- **技术栈**：TypeScript + Phaser 3 + Vite（PC 用 Electron，移动用 Capacitor）；Unity 6.x LTS 为备选

## 文档约定

- 设计文档与交付物统一使用 Markdown（`.md`）
- **不使用代码块**：图表、公式、流程、数据结构一律用表格 / 正文表达，文档内不出现围栏代码块（2026-10-11 起）
- 编号前缀 + 语义化目录名称，参考 GDD 行业标准

## 环境

进入游戏工程目录并安装依赖：先 `cd jianghu-game`，再运行 `pnpm install`（安装 Phaser / Vite / Electron 等依赖；首次需要联网）。
