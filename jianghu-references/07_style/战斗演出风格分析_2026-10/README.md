## 最值得带走的三件事

1. **绝学立绘演出模板**：黑白水墨底 + 左侧墨龙纹 + 彩色角色立绘 + 白色书法大字（2 行错落），单次 ≈1.0 s（视频口径），硬切进出，HUD 不隐藏。
2. **出手队列条 + 阵名幡**：把"战前布阵的成果"在战中持续可视化。
3. **音频留白**：绝学/爆发前 BGM 主动降层 0.5–2.5 s，给打击音效让位。
