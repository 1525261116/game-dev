# 江湖从心 · 素材参考库

> 美术 / 音效 / 设计参考素材的集中存放地。与 `jianghu-design`（方案设计）、`jianghu-game`（代码实现）、`jianghu-tools`（辅助工具）并列。

## 使用约定

**命名规则**：`子目录/用途简述_来源或日期.ext`，例如 `01_character/女侠立绘姿态_2026-10.png`、`03_animation/单刀缠头裹脑_b站某UP主.mp4`。

**来源标注**：每张图/每段视频尽量在同目录放一个同名 `.txt`，写明：来源 URL、原作者、授权情况（CC0/CC-BY/仅参考/授权可用）、采集日期。无来源标注的素材默认**仅作开发期参考**，不进入正式发行包。

**授权红线**：
- 正式纳入游戏资产前，必须确认授权可商用。
- LPC、CC-BY-SA、GPL 类资产仅可在**开发期占位**使用，发布前需替换或合规处理。
- 互联网随手抓的图一律按"仅参考"处理，不得打包进游戏。

**外链优先**：不便下载或体量过大的参考（如长视频、整本画册），放 `99_external_links/links.md`，记链接 + 用途 + 对应哪个子目录。

**与项目其他资产的关系**：
- 本目录是**参考与灵感来源**，不是游戏运行时资产。
- 游戏运行时贴图、动画、音频 → 进 `jianghu-game/assets/`（或对应引擎资产目录）。
- 自产/外包的正式美术成品 → 另设产出目录，不与本参考库混放。

## 维护建议

- 采集后随手归类，避免 `unsorted/` 堆积；如确需暂存，可在根目录临时建 `00_unsorted/`，每周清理一次。
- `07_style/` 应保持精挑细选，作为整体风格的"锚点"，不超过 30 张。
- 子目录过大（> 200 项）时考虑按二级主题再分，例如 `01_character/01a_体型/`、`01_character/01b_服饰/`。
