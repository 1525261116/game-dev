## 4. 本轮修掉的真实缺陷（3 个）

| # | 缺陷 | 症状 | 修复 |
|:-:|------|------|------|
| 1 | **回春（regen）反向生效** | `Math.max(1, round(hp × −4%))` = 1 → 每回合**扣 1 点血**，还被计入总伤害 | 负数百分比走治疗分支，产出 `heal` 事件；总伤害不再包含治疗 |
| 2 | **内力回复修正被采集后从未消费** | 状态「回气」与阵法「回气」的 `innerRegen` 是死字段 | 接入回合末内力回复 |
| 3 | **群体递减测试假阳性** | 旧断言用"位置切片"猜暴击，遇到"死亡事件插在两条伤害之间"就误判 | 改为**面板完全一致的三敌人夹具**，精确断言 0.85 / 0.70 |

另外：`封穴`（只能普攻 + 内力回复 −50%）此前完全未实现，本轮补上。
