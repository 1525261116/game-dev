### 人物属性系统结构性修订（覆盖 v0.3 部分决策）

按评审意见对属性 / 境界体系做 5 项结构性修订：

1. **功法境界改为等级区间制**（`05_combat/功法境界.md` 重写）
   - 「入门→小成→大成→圆满→破境」五档 → **「一重~十重」十档**（功法 Lv1~100，每 10 级一重）
   - **每门功法 = 1 个主动招式 + n 个被动招式**，达指定境界解锁对应被动（常见解锁点：三重/六重/十重）
   - 境界倍率表扩为 10 档（×1.0 → ×5.5），原「破境特殊效果」映射为被动招式
2. **人物境界阶梯重做**（`属性系统.md` / `成长曲线.md`）
   - 武者段：**武者一境~九境（Lv1~90）+ 武者圆满（Lv91~100）**，显示等级，每 10 级一境需突破
   - 满 Lv100 突破 → **后天武者**，此后**不显示等级**，纯靠突破进阶：
     后天（小成/大成/圆满）→ 半步先天 → 先天（小成/大成/圆满）→ 半步宗师 → 宗师（小成/大成/圆满）→ **武侠之巅**（宗师之上，须满足特定条件）
   - **资质门槛**：进入后天 / 先天 / 宗师必须**悟性资质达标**（门槛数值待定）
3. **五维 → 四维，悟性下调为隐藏属性**（`属性系统.md` / `天赋系统.md` / `角色设计模板.md` / `开局身份.md` / `装备数值.md`）
   - 基础维度收敛为 **臂力/身法/根骨/内息**；悟性不进加点面板，靠天赋/奇遇/宝典提升
   - 悟性作用：突破资质门槛 + 秘籍经验获取速率；「速成悟道流」加点流派移除
   - 天赋「悟性通神」改为加隐藏资质 + 降低突破资质门槛一档
4. **删除怒气**（`属性系统.md` / `战斗数值.md` / `战斗方式.md`）
   - L2 派生属性移除「怒气」，大招机制及其「手动大招」设置一并移除（恢复大招需另定积攒资源）
5. **删除招式属性绑定**（`属性系统.md` / `战斗数值.md` / `伤害计算.md`）
   - 取消「每门功法绑定 1 个主属性」；伤害公式属性侧统一为 **攻击力 = 臂力×3 + 装备攻击**
   - 核心公式改为：`基础伤害 = 攻击力 + 功法威力（品质×境界倍率×3）`
