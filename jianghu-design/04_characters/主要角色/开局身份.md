# 开局流程

## 固定身份：穿越成逃犯

主角身份**固定**，不存在「身份选择」：

- 现代人穿越，接手一个「被全江湖通缉的逃犯」身份
- 原身犯下大案（闯凌云阁禁地、杀执法长老玄真、夺秘境信物），主角因此开局即被追杀
- 只有碎片记忆，原身真实身份是贯穿全篇的谜题（查案核心悬念）

> 主角开场身份唯一，差异化来自「开局五问」决定的属性、武器与天赋，而非选身份。

## 开局五问（决定初始属性 / 武器加成 / 天赋）

开局通过五道选择题，决定主角的初始属性、武器加成与天赋：

| 问题 | 决定 |
|------|------|
| 1. 你期望的江湖是什么样的？ | 初始四维属性加点（另含隐藏悟性资质） |
| 2. 遇到坏人欺负好人，你会怎么做？ | 初始属性微调 |
| 3. 你喜欢什么兵器？ | 武器类型加成 |
| 4. 你觉得自己是什么样的人？ | 天赋倾向 |
| 5. 站在武林巅峰，你最想做什么？ | 天赋倾向 |

详见：[天赋系统](../../06_systems/天赋系统.md)

## 化名系统

- 逃犯身份不能暴露，开局（阶段1 幕4）需以**化名**行走江湖
- 玩家自定义化名（默认「沈一凡」），建立公开身份
- 化名是「藏」的核心：真名一旦暴露，通缉身份会引来追杀与势力围猎

## 设计要点

- 主角身份唯一（穿越成逃犯），保证主线叙事统一、悬念聚焦
- 开局差异由「五问」承担，覆盖不同游玩风格（稳/快/自由/潜力）
- 原身真实身份是谜（关联秘境守护者、世界核心秘密），通过碎片记忆逐步还原
- 「孤星遗子」式的身世谜团已融入主线设定：原身身份、妹妹林小满、秘境信物三者同源，随查案展开
