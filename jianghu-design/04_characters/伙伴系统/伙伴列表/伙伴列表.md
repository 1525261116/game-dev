# 伙伴列表

> 主线剧情伙伴（可入队角色）总表与详设。此外，寻访令抽卡招募的「弟子」为另一类伙伴，见 `06_systems/抽卡招募.md` 与 `06_systems/门派养成.md`。

## 1. 谢九

| 项目 | 内容 |
|------|------|
| **品质** | 稀有 |
| **定位** | 辅助 / 引路（探索型） |
| **天赋** | 探索天赋：情报获得率 +25%，线索发现 +20% |
| **入队条件** | 阶段1 幕3 主线必入 |
| **资质档** | 慧根（悟性 58） |
| **初始境界** | 先天小成（累计 6,200,000） |
| **善恶值 / 档** | +80 / 行走江湖 |
| **忠诚阵营** | 中立（隐退不涉朝政） |
| **成长性格** | 中庸（隐退散淡，骨子勤奋） |
| **处世 / 情感 / 武学倾向** | 隐忍 / 重情 / 淡泊 |
| **活动状态** | 正常（已隐退，成长缓慢） |
| **内力属性** | profound 深 |

- **背景**：表面是洛阳近郊破庙里的落魄江湖郎中，实为隐退多年的武林名宿，年轻时也卷进过秘境事件，一眼看出主角身上「秘境信物」的气息。不问来路、不点破，是主角的第一位引路人。
- **定位**：教主角在江湖「藏」的生存之道（化名、藏系统、藏信物），点破「孤木难成林」，推动主角自创门派。
- **好感度专属（生死之交）**：「旧事重提」——解锁谢九的秘境过往，获得秘境关键线索与一个隐藏被动。
- **剧情意义**：贯穿全篇的引路人，最终立场可能在决战中为救主角牺牲。

## 2. 陆青崖「青崖剑」

| 项目 | 内容 |
|------|------|
| **品质** | 稀有 |
| **定位** | 战斗（剑） |
| **天赋** | 战斗天赋：伤害 +20%，血量 +15% |
| **入队条件** | 阶段3–4 立场抉择（倒向主角方可入队） |
| **资质档** | 聪颖（悟性 48，临近慧根门槛，年轻潜力型） |
| **初始境界** | 武者八境（累计 1,000,000） |
| **善恶值 / 档** | +30 / 行走江湖 |
| **忠诚阵营** | 中立（凌云阁弟子，立场未定） |
| **成长性格** | 勤奋（年轻有为，主动试探主角） |
| **处世 / 情感 / 武学倾向** | 热血 / 重情 / 痴武 |
| **活动状态** | 正常（年轻成长中） |
| **内力属性** | fierce 猛 |

- **背景**：凌云阁年轻弟子，表面以「切磋/考察」之名接近主角，实为奉凌云阁之命试探信物下落。但随着接触加深，开始有自己的判断。
- **定位**：多周目变体角色——可倒向主角（伙伴）或继续效忠凌云阁（敌人），是阶段3–4 的重要变量。
- **好感度专属（生死之交）**：「青崖明志」——陆青崖彻底脱离凌云阁，解锁凌云剑法真传。
- **剧情意义**：体现「正派有私心、弟子也有良知」的主题，是凌云阁裂缝的具象。

| 项目 | 内容 |
|------|------|
| **品质** | 稀有 |
| **定位** | 战斗（暗杀） |
| **天赋** | 战斗天赋：伤害 +20%，血量 +15% |
| **入队条件** | 阶段3 与幽月教结盟 |
| **资质档** | 聪颖（悟性 45） |

| **善恶值 / 档** | −50 / 亦正亦邪 |
| **忠诚阵营** | 中立（幽月教，不涉朝政） |
| **成长性格** | 勤奋（主动接近主角拉拢，有野心） |
| **处世 / 情感 / 武学倾向** | 圆滑 / 多疑 / 务实 |
| **活动状态** | 正常 |
| **内力属性** | cunning 诡 |

- **背景**：幽月教妖女，亦正亦邪，主动接近主角以「交换情报」拉拢，同样觊觎秘境信物。若结盟，则成为主角的重要战力与情报来源。

- **剧情意义**：体现「邪派也有道义」，是势力博弈的重要棋子。

| **内力属性** | fierce 猛 |

## 设计备注

- 剧情伙伴与抽卡招募的「弟子」分属两类：前者有专属剧情与好感度，后者靠天赋分配岗位（见门派养成）。
- 伙伴上阵遵循「主角 + 3 伙伴」九宫格站位，站位讲究策略。
- 好感度系统详见 `伙伴系统/好感度系统.md`（5 级：陌路→生死之交）。
- 伙伴之间也有好感度，合得来有加成，合不来会吵架（后续细化）。
- **资质与培养**：4 伙伴均按角色通用模型标定资质档与悟性；玩家可送资质宝物（洗髓丹 +5 / 通灵丹 +10 / 天元丹 +20，单 NPC 累计 +30 上限）突破原天花板。周铁山（寻常→聪颖）可入后天、陆青崖（聪颖→慧根）可入先天，是长线培养爽点。
