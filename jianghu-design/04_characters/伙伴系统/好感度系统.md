# 好感度系统

## 好感度等级

| 等级 | 名称 | 数值 | 效果 |
|------|------|------|------|
| 1 | 陌路 | 0～20 | 不能组队 |
| 2 | 相识 | 21～40 | 可以组队，基础属性 +5% |
| 3 | 信任 | 41～60 | 解锁专属对话，基础属性 +10%，解锁一个被动技能 |
| 4 | 知己 | 61～80 | 解锁专属任务，基础属性 +15%，解锁第二个被动技能 |
| 5 | 生死之交 | 81～100 | 解锁专属技能/天赋，基础属性 +20%，解锁隐藏结局相关剧情 |

## 好感度怎么涨

| 行为 | 涨幅 |
|------|------|
| 一起战斗 | +1～3 |
| 送礼物 | +5～15 |
| 完成伙伴任务 | +10～20 |
| 剧情选择 | +5～10 |
| 客栈请客、一起喝酒 | +3～5 |

## 好感度怎么掉

| 行为 | 降幅 |
|------|------|
| 战斗中让伙伴死亡 | -5 |
| 剧情选择背叛伙伴 | -20 |
| 长期不带他上阵 | 缓慢下降 |

## 专属技能/天赋举例

| 伙伴类型 | 生死之交解锁技能 | 效果 |
|----------|------------------|------|
| 剑客伙伴 | 剑心相印 | 主角剑法威力 +15% |
| 拳师伙伴 | 并肩作战 | 拳掌眩晕概率 +10% |
| 医师伙伴 | 妙手回春 | 战斗中每回合回血 +5% |
| 商人伙伴 | 生意兴隆 | 开店收益 +20% |
| 盗贼伙伴 | 妙手空空 | 探索宝箱品质 +1 |

## 创意补充

- 伙伴有自己的脾气，送错礼物、选错对话会掉好感
- 伙伴之间也有好感度，合得来有加成，合不来会吵架
- 好感度太低或剧情背叛，伙伴会永久离队，甚至变成敌人
- 好感度够了触发伙伴专属奇遇，完成后解锁专属技能
- 好感度够了可以请伙伴指点武功，涨对应修为
- 伙伴会随机说出心事，倾听并帮忙解决，好感度大涨
- 生死之交的伙伴，在最终结局里会来帮你
