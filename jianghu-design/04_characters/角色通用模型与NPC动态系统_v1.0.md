# 角色通用模型与 NPC 动态系统 v1.0

> **定位**：把「主角 / 伙伴 / NPC / BOSS」统一为**同一套角色底座**，共用功法境界与人物境界双模板；在此之上构建一个**随时间演化、可被玩家改变、善恶各异、多姿多彩**的活江湖。
> **关联**：境界双线见 [`05_combat/境界系统.md`](../05_combat/境界系统.md)；修为见 [`05_combat/修为系统.md`](../05_combat/修为系统.md)；四维与 L3 隐藏属性见 [`05_combat/属性系统.md`](../05_combat/属性系统.md)；好感度见 [`04_characters/伙伴系统/好感度系统.md`](伙伴系统/好感度系统.md)；门派见 [`06_systems/门派养成.md`](../06_systems/门派养成.md)；正邪值见 [`08_balance/成长曲线.md`](../08_balance/成长曲线.md)。

## 一、设计目标与核心结论

### 1.1 一句话定位

> **一个角色模型，三种身份，一个会自己长大的江湖。**

主角、伙伴、NPC、BOSS 共用同一套 Character 底座——同样的四维、同样的双境界线、同样的 5 功法槽与 8 类修为。身份差异只靠「角色类型 + 子能力」扩展，不再各起炉灶。NPC 不是静态木桩，而是**按自己的悟性与性格随时间成长**，且**玩家的每一份介入（送宝物、结仇、救人）都会改写某个人的一生命运**。

### 1.2 设计信条（机制先行）

| 信条 | 落地方式 |
|------|----------|
| 机制服务于乐趣与节奏 | NPC 时间成长不是为模拟而模拟，而是制造"再回来发现故人变强了"的惊喜与"早培养早受益"的长线牵引 |
| 数值服务于自洽与长线 | 悟性决定天花板，避免 NPC 无限膨胀；时间成长有瓶颈期，保证玩家介入仍有意义 |
| 能一套参数解释的不用三套系统 | 善恶值复用主角正邪值，功法来源用标签而非另造获取系统 |
| 把决策留给关键机遇 | 平时 NPC 自演化无需玩家干预；玩家只在"送不送宝物、救不救此人、杀不杀此敌"的机遇点做关键决策 |

### 1.3 八条核心结论（结论先行）

| # | 结论 | 要点 |
|---|------|------|
| C1 | **统一角色底座** | 主角 / 伙伴 / NPC / BOSS 共用 Character 模型：四维 + L3 隐藏 + 人物境界 + 5 功法槽 + 8 修为 + 天赋 + 传记 |
| C2 | **双境界模板全员共用** | 功法境界（初窥→天人合一，10 境）与人物境界（武者一境→武侠之巅，22 阶）对所有角色一视同仁 |
| C3 | **悟性＝资质，决定天花板** | 悟性分 6 档（凡庸→绝顶），直接对应境界上限；天才即高资质档 NPC |
| C4 | **NPC 随时间自成长** | 每个游戏日结算经验增量，悟性越高成长越快、突破成功率越高；玩家不在场也演算 |
| C5 | **门派功法按地位 / 贡献分配** | 普通弟子得凡品、长老得极品、掌门镇派绝世；贡献值可兑换更高品质 |
| C6 | **跨门派功法来自生平经历** | 师承多门 / 友好赠予 / 奇遇偶得 / 杀人夺宝 / 交易兑换，五条经历路径 |
| C7 | **每个 NPC 有善恶值与阵营** | 复用主角正邪值 4 档；新增忠诚阵营标签（爱国 / 叛国 / 中立）与性格标签 |
| C8 | **玩家介入可改写 NPC 命运** | 送资质宝物可提升悟性、突破原天花板；剧情选择改善恶；救助结仇改关系 |

## 二、统一角色模型（Character 通用底座）

### 2.1 一个模型，三种身份

| 角色类型 | 共用底座 | 独有扩展 |
|----------|----------|----------|
| **主角** | Character 全量 | 开局五问天赋、穿越者系统（外挂）、自由加点 |
| **伙伴** | Character 全量 | 好感度系统（5 级）、入队条件、生死之交专属技能 |
| **NPC** | Character 全量（含传记、时间成长、善恶、阵营） | 门派地位、贡献值、生平事件线、离线演算状态 |
| **BOSS** | Character 全量（境界拉满或剧情锁定） | 多阶段战斗、固定招式表、剧情钩子 |

> **设计意图**：底座统一，意味着「培养主角的规则」可以原样用于培养伙伴、甚至 NPC。玩家救下的小角色，理论上能一路养成到宗师——这正是"高自由度江湖"的数值基础。

## 三、功法境界 + 人物境界 双模板（全员共用）

### 3.1 双境界线总览（复用既有定案）

| 维度 | 人物境界 | 功法境界 |
|------|----------|----------|
| 管什么 | 角色等级上限、属性台阶跃升 | 单门功法威力倍率、被动招式解锁 |
| 层级 | 武者九境 + 武者圆满 + 后天 / 先天 / 宗师 / 武侠之巅（22 阶） | 初窥门径 → 天人合一（10 境） |
| 突破方式 | 闭关耗时（期间不可战斗） | 参悟耗时（后台计时，不中断行动） |
| 减时丹药 | 凝神丹（每颗 −20%，至多 3 颗） | 悟道丹（每颗 −20%，至多 3 颗） |
| 成功率 | 有：基础 60% + 悟性资质 + 道具，上限 95% | 无：时间到即进阶 |
| 资质门槛 | 进后天 / 先天 / 宗师须悟性达标 | 无 |
| 失败 | 不降级；耗资源 + 冷却 | 不会失败 |
| 产出 | 属性跃升 + 境界称号 | 威力倍率 + 被动解锁 + **修为产出** |

> **本设计强调**：上表对**所有角色类型**生效。主角闭关、伙伴闭关、NPC 后台演算闭关，走的是同一张表、同一套公式——只是 NPC 的闭关由时间驱动自动发起（见第五节）。

### 3.2 NPC 闭关的特殊处理

| 项 | 主角 / 伙伴 | NPC |
|----|------------|-----|
| 触发 | 玩家手动发起 | 经验达上限后**自动发起**（离线演算） |
| 期间 | 不可战斗 / 探索 | 标记为"闭关中"，玩家访问时若需战斗则"出关"（进度按比例折算） |
| 成功率结算 | 闭关完成时即时结算 | 时间切片到点时结算（失败则冷却后再试） |
| 减时丹药 | 玩家自行服用 | NPC 自行服用（消耗其背包资源；无则硬等） |

> **设计意图**：NPC 的"闭关中"状态本身就是江湖信息——"听说武当张真人已闭关三月，不出关不见客"。玩家可趁 NPC 闭关时偷袭、抢夺，制造机遇与风险。

## 四、悟性资质 → 境界上限（决定天花板）

### 4.1 悟性资质 6 档

> **核心设计**：悟性（aptitude）是隐藏资质，**不可加点**，由天生 + 奇遇 + 宝物决定。它直接决定一个角色**这辈子能到的最高境界**。

| 资质档 | 悟性值 | 境界天花板 | 突破成功率加成 | 成长速率系数 | 人群占比（设计基准） |
|--------|--------|------------|----------------|--------------|----------------------|
| **凡庸** | 0 ~ 14 | 武者九境封顶（Lv90） | +0% | ×0.4 | 路人甲乙、百姓 |
| **寻常** | 15 ~ 29 | 武者圆满封顶（Lv100） | +5% | ×0.7 | 普通江湖人、低阶弟子 |
| **聪颖** | 30 ~ 49 | 后天圆满封顶 | +10% | ×1.0 | 可造之材、精英弟子 |
| **慧根** | 50 ~ 69 | 先天圆满封顶 | +15% | ×1.5 | 天才、长老级 |
| **通神** | 70 ~ 89 | 宗师圆满封顶 | +20% | ×2.0 | 宗师之资、掌门级 |
| **绝顶** | 90 ~ 100 | 可冲击武侠之巅 | +25% | ×3.0 | 百年一遇、主角级 |

> **门槛对齐**：后天门槛悟性 ≥30、先天 ≥50、宗师 ≥70（既有定案）。资质档的边界正好落在门槛上——聪颖档下限 30 = 刚好够入后天，慧根档下限 50 = 刚好够入先天，通神档下限 70 = 刚好够入宗师。
>
> **天赋特权**：「悟性通神」天赋让门槛 ×0.8（后天 24 / 先天 40 / 宗师 56）——视为"超资质突破"特权，使凡庸 / 寻常档的人也有机会越级入后天。本设计保留该特权，作用于所有角色类型。

### 4.2 资质档如何决定 NPC 初始值

| NPC 定位 | 默认资质档 | 初始境界（设计基准） |
|----------|-----------|---------------------|
| 路人 / 百姓 | 凡庸 | 武者一~三境 |
| 普通门派弟子 | 寻常 | 武者三~五境 |
| 精英弟子 / 江湖散人 | 聪颖 | 武者六~八境 |
| 长老 / 名宿 | 慧根 | 后天小成 ~ 先天大成 |
| 掌门 / 宗师 | 通神 | 先天圆满 ~ 宗师大成 |
| 隐世高人 / 主角对位 | 绝顶 | 宗师圆满 ~ 武侠之巅候选 |

> **"天才 NPC"** = 抽到高资质档的年轻 NPC。一个 18 岁的聪颖少年，可能 10 年游戏时间后成长为后天高手；一个慧根天才，可能 20 年后成先天宗师——这正是"天才会随着时间升级"的数值实现。

### 4.3 悟性的三个作用（对齐既有）

| 作用 | 公式 / 规则 | 来源 |
|------|------------|------|
| ① 境界天花板 | 见 4.1 资质档表 | 本设计 |
| ② 突破成功率 | 成功率 = 基础 60% + 悟性档加成 + 道具，上限 95% | 境界系统 §二 |
| ③ 秘籍经验速率 | 功法经验获取 ×（1 + 悟性 / 100） | 属性系统 §八 |

## 五、NPC 时间驱动成长（天才随时间升级）

### 5.1 成长机制总览

> **核心命题**：NPC 不是玩家手动练的，而是**游戏时间推进时自动演算**。玩家在别处冒险时，江湖在悄悄变化——故人变强了、天才冒头了、老对手闭关了。

**公式**：每日经验增量 = 基准日经验 × 悟性系数 × 性格系数 × 活动系数

| 因子 | 取值 | 说明 |
|------|------|------|
| 基准日经验 | 400 | 对齐主角 Lv1~10 段每级约 100~2000 经验，使 NPC 日成长与玩家同量级。**v1.2 演算修订**：原 200 经演算发现 §5.4 预期成长线全部偏移 1.6~2.6 倍，调至 400 后精确匹配（见 [角色数值演算报告](角色数值演算报告_v1.0.md) §四） |
| 悟性系数 | 凡庸 0.4 / 寻常 0.7 / 聪颖 1.0 / 慧根 1.5 / 通神 2.0 / 绝顶 3.0 | 见 §4.1 |
| 性格系数 | 勤奋 1.3 / 中庸 1.0 / 散漫 0.7 | growthTrait |
| 活动系数 | 闭关修炼 1.5 / 正常活动 1.0 / 受伤养伤 0.3 / 被囚禁 0.0 | 当前状态 |

### 5.2 演算周期与切片

| 项 | 规则 |
|----|------|
| 结算周期 | 每游戏日（现实 1 分钟 = 游戏 1 日，可调） |
| 触发时机 | 玩家过夜 / 切换区域 / 主线推进时间锚点 |
| 经验缓冲 | 未达上限则累积；达上限则标记"可突破" |
| 自动突破 | 可突破后，按性格决定是否立即闭关（勤奋立即、中庸看心情、散漫拖延） |
| 瓶颈期 | 达资质档天花板后，经验不再增长（停滞），需玩家送宝物突破资质 |

### 5.3 离线演算状态

| 状态字段 | 说明 |
|----------|------|
| lastTickAt | 上次结算的游戏时间戳 |
| bufferedExp | 跨周期累积的经验缓冲 |
| pendingBreakthrough | 是否在等待突破 |
| closedDoorUntil | 闭关到期时间（闭关中） |
| activityState | 修炼 / 正常 / 养伤 / 被囚 / 闭关 |

> **性能取舍**：不做全 NPC 实时模拟（数百 NPC 实时算会崩）。采用**惰性结算**——只在玩家访问某 NPC / 该 NPC 所在区域时，按 lastTickAt 与当前时间差一次性补算。未访问的 NPC 保持上次状态，访问时"追进度"。

### 5.4 成长时间线示例

| 场景 | 设定 | 10 游戏年后 |
|------|------|------------|
| 凡庸路人甲 | 18 岁，武者一境，凡庸 | 武者六境左右（封顶九境前停滞） |
| 聪颖少年天才 | 18 岁，武者三境，聪颖，勤奋 | 后天小成（已成一方高手） |
| 慧根门派新秀 | 20 岁，武者七境，慧根 | 先天大成（可挑战宗师） |
| 通神掌门 | 50 岁，宗师小成，通神 | 宗师圆满（接近天花板） |
| 玩家送宝物后的凡庸 | 受赠洗髓丹悟性 +20 → 寻常档 | 武者圆满（突破原天花板） |

> **乐趣来源**：玩家 10 年后回到新手村，发现当年救下的庸才小弟竟成后天高手——这是"早种善因早收果"的长线正反馈。

## 六、门派功法分配规则（地位 / 贡献）

### 6.1 门派功法品质 × 地位对照

> **核心规则**：门派 NPC 按其在门派的**地位**拥有对应品质的本门功法；**贡献值**积累可兑换更高品质。

| 门派地位 | 默认功法品质 | 可兑换上限 | 说明 |
|----------|-------------|-----------|------|
| 普通弟子 disciple | 凡品 ~ 良品 | 良品 | 入门基础功法 |
| 精英弟子 elite | 良品 ~ 上品 | 上品 | 部门骨干 |
| 堂主 / 执事 deacon | 上品 ~ 极品 | 极品 | 中坚管理层 |
| 长老 elder | 极品 | 绝世（需大功） | 高层，可触及镇派绝学 |
| 掌门 / 宗主 master | 绝世 | — | 镇派绝学持有者 |

### 6.2 贡献值系统

**公式**：贡献值 = 年限积分 + 任务积分 + 战功积分 − 过错扣分

| 来源 | 贡献变化 |
|------|----------|
| 入门每满 1 年 | +10 |
| 完成门派任务 | +5 ~ +30 |
| 比武获胜 / 代表门派出征 | +20 ~ +100 |
| 立大功（救掌门 / 护镇派之宝） | +100 ~ +500 |
| 过错（违门规 / 败阵辱师） | −20 ~ −200 |

**兑换阈值**（贡献值达标方可习得对应品质门派功法）：

| 品质 | 所需贡献值 | 备注 |
|------|-----------|------|
| 良品 | 30 | 弟子常规 |
| 上品 | 100 | 精英门槛 |
| 极品 | 300 | 长老门槛 |
| 绝世 | 800 | 镇派，仅掌门 / 大功长老 |

### 6.3 门派功法特色绑定（复用既有）

| 门派 | 武学特色 | 镇派绝学示例 |
|------|----------|-------------|
| 凌云阁 | 剑法 | 凌云九剑、青崖剑法 |
| 幽月教 | 暗杀 / 身法 | 幽月暗杀秘技 |
| 六扇门 | 刀法 / 缉捕 | 六扇缉捕刀 |
| 江湖散人（丐帮） | 拳掌 / 棍法 | 降龙十八掌（拳）、打狗棍法（棍） |
| 秘境守护者 | 上古奇门 | 河图洛书、太极八卦阵 |
| 自创门派 | 玩家自定 | 由玩家收集的武学路线决定 |

> **设计意图**：门派功法分配不是"随机给"，而是"地位 + 贡献"的**可推演**结果——玩家查一个 NPC 的门派地位与贡献，就能推断他大概会什么功法，形成江湖信息读取的乐趣。

## 七、跨门派功法获取（经历驱动）

### 7.1 功法来源标签

> 每门功法实例携带一个**来源标签**，记录它是怎么来的——这是"杀人夺宝""奇遇偶得"等经历的物质化记录。

| 来源标签 | 触发条件 | 可得品质 | 典型场景 |
|----------|----------|----------|----------|
| **门派传授** | 加入门派 + 地位 / 贡献达标 | 凡 ~ 绝（看地位） | 门派弟子本门功法 |
| **师承多门** | 生平拜过多位师父 | 看师父所授 | 游历学艺、转益多师 |
| **友好赠予** | 与他派 NPC 好感 ≥ 信任（41） | 良 ~ 上 | 切磋相得、礼尚往来 |
| **奇遇偶得** | 福缘触发秘籍事件 | 凡 ~ 绝（稀有） | 洞府遗刻、残卷拼合 |
| **杀人夺宝** | 击败持有者并搜身 | 继承对方所持 | 夺刀、抢剑、灭门取经 |
| **交易兑换** | 与门派友好值 ≥ +20 | 看兑换档 | 门派武学兑换系统 |
| **自创** | 角色自创（主角 / 高境界 NPC） | 看投入 | 开宗立派、宗师创招 |

### 7.2 跨门派 NPC 的生成规则

> **核心**：少部分 NPC 拥有非本门派功法，**全部由其生平事件驱动**，不是随机贴的。

| 生平事件 | 导致的跨门派功法 | 概率权重 |
|----------|-----------------|----------|
| 曾游历他派求学 | 师承多门（1~2 门他派功法） | 中（精英以上常 1 门） |
| 与他派高手亦师亦友 | 友好赠予（1 门） | 中 |
| 有奇遇线（福缘高） | 奇遇偶得（1 门，可能高品） | 低 |
| 曾灭门 / 杀人夺宝 | 杀人夺宝（继承对方功法） | 低（邪派 NPC 偏多） |
| 商旅出身 / 门派友好 | 交易兑换（1~2 门） | 中 |

> **设计意图**：跨门派功法让 NPC 有"故事感"——你见一个凌云阁弟子却会使幽月教暗杀术，背后必有一段往事，这正是查案、结交、探究的钩子。

### 7.3 功法实例结构

| 字段 | 类型 | 说明 |
|------|------|------|
| gongfaId | string | 功法图鉴 id |
| quality | 凡 / 良 / 上 / 极 / 绝 | 品质 |
| realm | 初窥 ~ 天人合一 | 当前功法境界 |
| exp | number | 当前境界经验 |
| **source** | 来源标签枚举 | 见 §7.1 |
| **obtainedAt** | 游戏时间锚点 | 何时获得 |
| **obtainedFrom** | string \| null | 从谁 / 何处获得（用于夺宝溯源） |

> **运行时修为校验（演算识别缺口，留待代码阶段）**：夺宝 / 获赠所得功法若修为不足该品质门槛，配置导入期校验不覆盖运行时事件。处理方案见 [角色数值演算报告](角色数值演算报告_v1.0.md) §6.4（推荐 B：入 gongfaInventory 但不可装入功法槽，修为达标后解锁）。具体字段实现（如 `unusable` 标记）留待代码 Sprint 落地，不在本设计稿定义。

## 八、NPC 生平传记系统

### 8.1 LifeEvent 事件结构

> 每个 NPC 有一条**生平事件线**（lifeEvents），按游戏时间排序。初始传记决定 NPC 的初始境界、功法、善恶、阵营；玩家介入会插入新事件，改写后续轨迹。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 事件 id |
| time | 游戏时间锚点 | 何时发生 |
| kind | 事件类型枚举 | 见 §8.2 |
| delta | 变更包 | 境界 / 功法 / 善恶 / 阵营 / 关系的变化量 |
| desc | string | 叙述文本（江湖风） |
| flags | 标签集 | 是否玩家介入、是否关键节点等 |

### 8.2 事件类型枚举

| kind | 说明 | 典型 delta |
|------|------|-----------|
| born | 出生 | 设定初始资质档 |
| joinSect | 拜师入门 | factionId、门派传授功法 |
| breakthrough | 境界突破 | personRealm +1 |
| learnGongfa | 习得功法 | gongfaInventory +1 |
| encounter | 奇遇 | 福缘事件、获功法 / 宝物 |
| goodDeed | 行侠 | morality + |
| atrocity | 恶行 | morality − |
| feud | 结仇 | 关系 − |
| grace | 受恩 | 关系 + |
| betray | 背叛 | loyalty 转叛国、morality − |
| redeem | 被救赎 | 玩家救助、morality +、关系 + |
| **playerGift** | **玩家赠予** | 资质 / 功法 / 装备变化（见 §十） |
| death | 死亡 | 角色退场 |

### 8.3 传记如何驱动初始值

| 步骤 | 规则 |
|------|------|
| 1. 定资质档 | 按 NPC 定位（§4.2）在档内随机一个悟性值 |
| 2. 回放传记 | 按 lifeEvents 顺序应用每个 delta，得到当前境界 / 功法 / 善恶 |
| 3. 校验天花板 | 任何突破不得超过资质档天花板；超出的 breakthrough 事件视为"未遂" |
| 4. 落地成长状态 | lastTickAt 设为当前，bufferedExp = 0，开始时间演算 |

> **设计意图**：传记 = NPC 的"存档回放"。一个 NPC 的全部当前状态，可由「初始资质 + 传记事件序列」完整重建——这意味着 NPC 状态可序列化、可复现、可被剧情脚本预设。

## 九、善恶值 + 阵营 + 性格标签（多彩江湖）

### 9.1 善恶值（复用主角正邪值，扩展到全员）

> **核心**：NPC 的 morality 与主角正邪值**同一套口径**，4 档分级，影响 NPC 行为倾向、可否招揽、剧情反应。

| 善恶档 | 名称 | 数值区间 | NPC 行为倾向 | 可否招揽 |
|--------|------|----------|-------------|----------|
| 正 | 侠义道 | +200 以上 | 行侠仗义、不欺弱、守信 | 主角正邪 ≥0 时易招 |
| 中正 | 行走江湖 | 0 ~ +200 | 利己但不害人、看情况 | 中立，多数可招 |
| 中邪 | 亦正亦邪 | −200 ~ 0 | 为达目的不择手段、灰色 | 主角正邪 ≤0 时易招 |
| 邪 | 魔道 | −200 以下 | 嗜杀、背信、夺宝 | 邪线主角易招，正线难 |

> **善恶变化来源**：行侠 +5~+50、守信 +5~+20、滥杀 −20~−100、背信 −10~−50、偷盗 −5~−30（对齐成长曲线 §三）。NPC 也有自己的善恶事件（goodDeed / atrocity），随生平累积。

### 9.2 忠诚阵营标签（爱国 / 叛国 / 中立）

| 标签 | 含义 | 典型 NPC |
|------|------|----------|
| patriot 爱国 | 忠于朝廷 / 国家大义 | 六扇门忠良、抗外侮的江湖人 |
| rebel 叛国 | 通敌 / 卖国 / 谋逆 | 通敌的凌云阁内鬼、卖国求荣者 |
| neutral 中立 | 不涉朝政、只问江湖 | 多数散人、隐世名宿 |

> **设计意图**：爱国 / 叛国是**阵营维度**，与善恶（道德维度）正交——一个"侠义道但叛国"的人（爱国叛国只是立场，未必是坏人）会让江湖更立体。这呼应"有爱国，有叛国"的诉求。

### 9.3 性格标签集

> 用于驱动 NPC 时间成长性格（growthTrait）、对话风格、剧情反应。标签从固定词表中取，可多选。

| 维度 | 取值 | 作用 |
|------|------|------|
| 成长性格 | 勤勤 / 散漫 / 中庸 | 时间成长系数（§5.1） |
| 处世 | 热血 / 平庸 / 隐忍 / 圆滑 | 对话风格、剧情反应 |
| 情感 | 重情 / 冷漠 / 多疑 | 好感度涨跌幅度 |
| 武学倾向 | 痴武 / 淡泊 / 务实 | 闭关发起倾向、可否指点武功 |

> "江湖有平庸有热血，有人情味有天才有坏人有好人"——以上标签正是这句话的字段化。

## 十、玩家介入动态演变（改写 NPC 命运）

### 10.1 介入方式总表

| 介入方式 | 改变的字段 | 机制 | 上限 / 边界 |
|----------|-----------|------|------------|
| **送资质宝物** | aptitude ↑ | 洗髓丹 +5 / 通灵丹 +10 / 天元丹 +20 | 单 NPC 最多 +30，且不得跨 2 档 |
| 送功法秘籍 | gongfaInventory +1 | 直接送一门功法（source = 友好赠予） | 受 NPC 修为门槛限制 |
| 送装备 | equipment 替换 | 提升战力 | — |
| 剧情选择 | morality / loyalty / 关系 | 关键抉择大幅改阵营 | 不可逆 |
| 救助 | 关系 +、morality + | 受恩事件、可触发报恩 | — |
| 结仇 / 伤害 | 关系 −、morality − | 结仇事件、可能招报复 | 极端可致 NPC 反目成仇 |
| 指点武功 | cultivation + | 好感 ≥ 信任可请指点（对齐好感度系统） | 每次 +1~3 对应修为 |

### 10.2 资质突破天花板（核心爽点）

> **核心机制**：玩家送资质宝物提升 NPC 悟性，可使其突破原资质档天花板——这是"把庸才养成宗师"的玩法根基。

| 原档 | 送 +20 宝物后 | 新天花板 | 说明 |
|------|---------------|----------|------|
| 凡庸(0~14) | → 寻常(15~29) | 武者圆满 | 可入武者圆满，仍难入后天 |
| 寻常(15~29) | → 聪颖(30~49) | 后天圆满 | 终于可入后天 |
| 聪颖(30~49) | → 慧根(50~69) | 先天圆满 | 可入先天 |
| 慧根(50~69) | → 通神(70~89) | 宗师圆满 | 可入宗师 |

**边界**：
- 单 NPC 累计悟性提升**最多 +30**（约跨 1~2 档），防"人人皆可宗师"。
- 资质宝物**极稀缺**（奇遇 / BOSS 掉落 / 炼丹高阶），不能量产。
- 提升悟性后，NPC 的"瓶颈期"解除，时间成长可继续推进到新天花板。
- **悟性 clamp（v1.2 演算补全）**：悟性值有硬上限 100，送宝物后取 `min(悟性 + 宝物加成, 100)`。通神档（70~89）送满 +30 会溢出 → clamp 至 100 → 进绝顶档 → 可冲武侠之巅（需消耗全部宝物配额于单 NPC，资源稀缺性自洽）。

### 10.3 玩家介入的事件化

所有玩家介入都**作为 playerGift / 玩家剧情事件插入 lifeEvents**，与 NPC 自身事件统一排队演算。这保证：
- 介入有**时间戳**，可追溯"某年某月，少侠赠我洗髓丹"；
- 介入与 NPC 自成长**叠加**而非覆盖；
- 多周目可复现同一 NPC 的不同命运线。

### 11.2 自洽性校验清单

| 校验维度 | 规则 | 违反后果 |
|----------|------|----------|
| 资质天花板 | NPC personRealm 不得超过其资质档上限 | 演算时截断 + 标记"瓶颈" |

### 11.3 长线演进校验

| 场景 | 演算结果 | 是否自洽 |
|------|----------|----------|
| 全凡庸 NPC 池 + 100 游戏年 | 全部停滞在武者九境 | 自洽（平庸者就是平庸者） |
| 1 个绝顶天才 + 50 游戏年 | 成长至武侠之巅候选 | 自洽（天才配得上时间投入） |
| 玩家给凡庸路人送 +30 宝物 | 凡庸 → 聪颖，可入后天 | 自洽（玩家介入有意义） |
| NPC 被囚禁 10 年 | activityState = 被囚，成长 0 | 自洽（不无中生有） |
| 邪派 NPC 杀人夺宝多次 | morality 持续 −、gongfa 来源多"杀人夺宝" | 自洽（恶人有恶人的样子） |

## 十四、定案口径（v1.1 收敛 Q1~Q5）

### 14.1 Q1 NPC 生成规模（定案）

| 层级 | 数量（设计基准） | 模型 | 是否演算 |
|------|------------------|------|----------|
| 核心 NPC（剧情 / 功能 / 可招揽） | 150 ~ 250 | Character 全模型 + 传记 | 是（惰性结算池） |
| 背景路人 | 500 ~ 800 | 轻量壳（名字 / 资质 / 对话） | 否 |
| 剧情锁定 NPC（主线 BOSS / 关键角色） | 10 ~ 20 | Character + 预设传记 | 境界剧情锁定，不参与时间成长 |

> 惰性结算池约 200 人，单次访问补算 O(1)，性能无压力。背景路人不进结算池，访问时即时生成固定对话。

### 14.2 Q2 时间流速（定案 v1.2：双轨时间）

> 关键取舍：江湖时间与闭关时间**解耦**。江湖时间慢（让 NPC 有时间跨度、剧情有年代感），闭关时间走现实单位（玩家等待有体感）。

**流速换算**：

| 现实单位 | = 江湖时间 |
|----------|-----------|
| 100 现实天 | = 100 游戏年 |
| 1 现实天 | = 1 游戏年 = 360 游戏日 |
| 1 现实时 | = 15 游戏日 |
| 1 现实分 | = 6 游戏小时 |

**双轨规则**：

| 时间轨 | 用途 | 流速 |
|--------|------|------|
| 江湖时间 | NPC 成长、季节、剧情时序、NPC 自动闭关（后台） | 100 现实天 = 100 游戏年 |
| 闭关时间 | 主角 / 伙伴主动闭关（玩家等待） | 按境界系统表，**现实**分钟 / 小时 |

**闭关期间江湖时间（定案 A：冻结）**：

> 主角 / 伙伴主动闭关时，江湖时间冻结，NPC 不成长；NPC 自动闭关（后台）走江湖时间，不受影响。

| 项 | 规则 |
|----|------|
| 主角 / 伙伴主动闭关 | 江湖时间冻结，期间 NPC 不长 |
| NPC 自动闭关（后台） | 走江湖时间，正常推进 |
| 不采用：同步推进 | 会导致宗师圆满闭关 120 现实时 = 5 现实天 = 5 游戏年，期间 NPC 暴涨 5 年，不合理 |

> **张力来源**：境界系统表里宗师圆满闭关 120 小时（GDD 定稿为游戏内时间）。本设计令闭关走**现实**单位——若江湖同步推进，120 现实时 = 5 现实天 = 5 游戏年，期间 NPC 成长 5 年（凡庸都能涨两三境），不合理。故定案 A（主角闭关时江湖冻结）。NPC 自动闭关走江湖时间（后台），不受此影响。

**节奏锚点**：

| 项 | 数值 |
|----|------|
| 主线时长 | 5 阶段 ≈ 5~10 游戏年 ≈ 5~10 现实天 |
| NPC 凡庸 10 游戏年成长 | 约 10 现实天的江湖时间推进 |
| 打坐推进时间 | 允许快进江湖时间，单次有上限（防刷） |
| 闭关减时 | 凝神丹每颗 −20%（至多 3 颗 = −60%）；武者境分钟级、后天起小时级 |

### 14.4 Q4 NPC×NPC 交互（定案：脚本触发，不实时演算）

| 项 | 规则 |
|----|------|
| 实时演算 | **不做**（太重且易生荒诞剧情） |
| 关系网 | 预设——部分核心 NPC 有预设关系（师徒 / 宿敌 / 同门 / 情缘） |
| 触发方式 | 由剧情脚本 / 奇遇触发，插入双方 lifeEvents |
| 玩家介入 | 可改变预设关系（救其师、杀其敌、断其缘） |
| 适用范围 | 仅核心 NPC（150~250）；背景路人不交互 |

> 设计意图：实时 NPC×NPC 演算不可控（易出现"路人甲乙突然结拜"的荒诞）；脚本触发可控、有叙事意义，且每个关系事件都是查案 / 结交的钩子。

### 14.5 Q5 经营 NPC 纳入（定案：纳入但降配）

| 项 | 规则 |
|----|------|
| 模型 | 走 Character 模型（统一底座） |
| 资质档 | 凡庸 / 寻常 |
| 天赋 | 偏生产（炼丹 / 种植 / 厨艺 / 酿酒 / 经营 / 探索） |
| 境界 | 卡在武者境，不参与后天以上突破 |
| 成长体现 | 生产技能等级，非境界 |
| 转战斗型 | 资质 ≥ 聪颖且有战斗天赋者可转（少见，需剧情触发） |

> 设计意图：统一模型省一套系统；经营 NPC 的"长大"体现在生产等级与产出品质，与战斗 NPC 的"境界突破"分轨——对应门派养成里的"看天赋用人"。
