## 十一、关系网拓扑（本批扩展）

> 本批 NPC 通过 17 条新关系（R11~R27）扩展主线关系网，把五大势力 + 散人 + 守境司编织成更密的活关系网。

| 势力 | 关系链扩展 |
|------|------------|
| 六扇门 | 展雄风→沈青衣（同门）→周铁山（师徒链 R12）→冷无霜（追查幽月教 R19） |
| 凌云阁 | 白慕寒→柳清寒（同门 R13）→陆青崖（师徒 R14）→慕容霜（同门竞争 R15） |
| 幽月教 | 夜裳→媚娘（师徒 R16）→月无瑕（同门 R17）→血手修罗（谢九宿敌 R18） |
| 丐帮/散人 | 洪七公→醉道人（同门 R21）→药王→老陈头（师徒 R22）→醉仙（酒友 R26） |
| 守境司 | 无相→玄阴+幻空（双护法 R23/R24）→林小满（囚禁） |
| 区域 BOSS | 蛟龙王↔王破浪（宿敌 R25，可挑拨） |
| 奇遇线 | 孤云→无名（残篇 R27）→醉仙（酒友引荐洪七公 R26） |

> **设计意图**：本批把主线 9 NPC 的单线关系网扩展为多线交织——例如玩家若走"六扇门线"，通过展雄风→冷无霜→月无瑕可与幽月教线交叉；走"散人线"通过洪七公→醉道人→药王可与炼丹/资质宝物线交叉。这让江湖不是单线任务链，而是一张可多路径探索的活关系网。
