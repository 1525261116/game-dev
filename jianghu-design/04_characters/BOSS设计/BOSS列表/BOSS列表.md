## 1. 孙黑虎「断魂刀」

| 项目 | 内容 |
|------|------|
| **势力** | 黑虎寨 |
| **登场** | 阶段1 幕6「打出声名」 |
| **定位** | 新手期小 BOSS |

- **背景**：盘踞洛阳近郊青山镇一带的山匪头子，劫掠乡里、绑票勒索，为害一方。
- **战斗特色**：一柄大刀走刚猛路数，力大势沉，但破绽大；适合作为新手战斗教学的标靶。
- **掉落**：普通刀法、基础装备、银两。
- **剧情意义**：主角化名「沈一凡」独闯黑虎寨、擒下孙黑虎，一战成名。

---

## 2. 玄真「玄剑真人」

| 项目 | 内容 |
|------|------|
| **势力** | 凌云阁 |
| **登场** | 背景（已被原身所杀）；可作回忆战/幻境战 |
| **定位** | 剧情 BOSS |

- **背景**：凌云阁执法长老，表面正道，实为图谋秘境之力、囚禁主角妹妹林小满之人。被原身闯禁地手刃，成为主角被通缉的直接「罪证」。
- **战斗特色**：凌云剑法凌厉，注重剑势；若作回忆战，可设计为「那一夜」的还原战。
- **掉落**：凌云阁剑法残篇（回忆战奖励）。
- **剧情意义**：主线核心悬念的关键——玄真私心在阶段3 被揭开，「复仇 + 救人」的真相由此闭环。

---

## 3. 秦望舒「望舒剑」

| 项目 | 内容 |
|------|------|
| **势力** | 凌云阁 |
| **登场** | 阶段3 末 – 阶段4 |
| **定位** | 中 BOSS |

- **背景**：凌云阁副阁主，玄真同伙，实际操控凌云阁搜寻秘境信物之人。实为秘境守护者（守境司）的棋子/代言人。
- **战斗特色**：剑法精妙、身法极快，善于拉开距离游斗；需玩家用连招与站位应对。
- **掉落**：凌云阁核心剑法、稀有装备。
- **剧情意义**：阶段3–4 的主要反派，门派战中被击败后败露，牵出幕后黑手无相。

---

## 4. 守境试炼「守门人」

| 项目 | 内容 |
|------|------|
| **势力** | 秘境守护者（守境司） |
| **登场** | 阶段4「深入秘境」 |
| **定位** | 试炼 BOSS（可选挑战） |

- **背景**：秘境入口的守护者，是守境司设下的第一道防线，考验闯入者。
- **战斗特色**：秘境阵法驱动，多阶段战斗（阵法形态 → 本体形态），考验玩家对系统与连招的理解。
- **掉落**：秘境材料、稀有装备、秘境线索。
- **剧情意义**：深入秘境的第一道门槛，为救妹妹与最终决战铺路。

---

## 5. 无相「守境人」

| 项目 | 内容 |
|------|------|
| **势力** | 秘境守护者（守境司） |
| **登场** | 阶段5「最终决战」 |
| **定位** | 终极 BOSS |

- **背景**：秘境守护者首领，上古势力守境司的当代执掌者。图谋借「秘境钥匙」（林小满的血脉）开启秘境、掌控世界本源，甚至染指穿越者系统之力。
- **战斗特色**：秘境之力加持，多阶段、多形态；战斗设计需呼应「复仇 / 救人 / 系统真相」的抉择机制。
- **掉落**：镇派绝学、传说装备（结局相关）。
- **剧情意义**：终极反派，最终决战对象，击败方式与结局走向直接关联。

## 设计备注

- BOSS 数量后续可扩展（区域 BOSS、支线 BOSS、门派战中的精英怪）。
- 终极 BOSS 无相的战斗需与阶段5 的「关键抉择」机制联动，而非单纯数值压制。
