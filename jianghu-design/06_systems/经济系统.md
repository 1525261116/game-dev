# 经济系统

## 赚钱途径

| 途径 | 说明 |
|------|------|
| 打怪卖装备 | 战斗获取装备出售 |
| 种田开店 | 生活经营产出 |
| 任务悬赏 | 完成悬赏任务 |

## 花钱方向

| 方向 | 说明 |
|------|------|
| 买装备材料 | 装备和锻造材料 |
| 抽卡招募 | 寻访令相关 |
| 开店投资 | 经营升级 |
| 家园升级 | 买地建房 |

## 设计要点

- 经济循环：赚钱 → 投资 → 更赚钱/更强 → 更多赚钱途径
- 没有体力限制，经济系统不卡进度
- 种田开店作为稳定收入来源，战斗作为爆发收入
- 寻访令不能用货币买，刷怪是唯一获取途径
