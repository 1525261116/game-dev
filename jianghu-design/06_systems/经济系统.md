> **定位**：整合现有经济系统 + 门派养成数值，产出完整经济循环——银两产出表、消耗表、物价体系、产出消耗平衡、防通胀/通缩机制。

## 一、设计目标与口径

### 1.1 一句话定位

> **赚钱 → 投资 → 更赚钱/更强 → 更多赚钱途径，没有体力限制，经济不卡进度。**

种田开店是稳定收入，战斗是爆发收入，寻访令不能用货币买（刷怪唯一获取）。

### 1.2 口径来源

| 项 | 值 | 来源 |
|----|------|------|
| 初始资金 | 500 两 | 门派养成数值 §六 |
| 建筑建造 | 1000~5000 两 / 座 | 门派养成数值 §六 |
| 建筑升级 | 2000~10000 两 / 级 | 门派养成数值 §六 |
| 商铺收益 | 50~500 两 / 天 | 门派养成数值 §六 |
| 寻访令 | 非货币，刷怪获取 | 门派养成 / 经济系统原版 |

## 二、银两产出表

### 2.1 四大产出途径

| 途径 | 类型 | 阶段1 | 阶段2 | 阶段3 | 阶段4 | 阶段5 | 说明 |
|------|------|------|------|------|------|------|------|
| 战斗（打怪卖装备） | 爆发 | 20~80 / 场 | 50~200 | 100~500 | 300~1000 | 500~2000 | 随阶段 BOSS / 精英递增 |
| 生产（种田开店） | 稳定 | — | 50~150 / 天 | 100~300 / 天 | 200~500 / 天 | 300~600 / 天 | 需建筑 + 经营 NPC |
| 任务悬赏 | 稳定 | 10~50 / 任务 | 30~100 | 50~200 | 100~300 | 200~500 | 委托 / 主线奖励 |
| 特产售卖 | 稳定 | — | 50~200 / 批 | 100~500 / 批 | 300~1000 / 批 | 500~2000 / 批 | 经营 NPC 产出 |

> **设计意图**：阶段1 只有战斗 + 任务（无门派无生产）；阶段2 起门派建立，生产成为稳定来源；阶段3+ 生产 + 特产占比上升，战斗转为爆发补充。

### 2.2 单日银两产出基准（阶段3，门派 2 级）

| 来源 | 单日产出 | 说明 |
|------|----------|------|
| 商铺（2 级 + 经营弟子） | ~150 两 | 50~500 区间中位 |
| 药田 + 厨房产出售卖 | ~80 两 | 药材 / 食物剩余售卖 |
| 任务悬赏 | ~100 两 | 日均 1 个任务 |
| 战斗（隔日） | ~200 两 | 隔日打一场精英 |
| **合计** | **~530 两 / 天** | 阶段3 基准 |

## 五、产出消耗平衡

### 5.1 阶段收支预估（阶段3，门派 2 级）

| 项 | 单日银两 | 说明 |
|----|----------|------|
| 产出合计 | +530 | 见 §2.2 |
| 建筑升级摊销 | −100 | 2 万两 / 200 天摊 |
| 装备 / 锻造 | −80 | 日均 |
| 突破材料摊销 | −50 | 5000 两 / 100 天摊 |
| 外交礼物 | −50 | 日均 |
| 消耗合计 | −280 | — |
| **净收支** | **+250 / 天** | 正向积累 |

> **平衡结论**：阶段3 每日净积累 ~250 两，约 80 天攒够一次大额消耗（建筑升级 2 万）——**节奏合理**：玩家有持续小积累感，又需规划大额支出。

### 5.2 防通胀机制

| 机制 | 说明 |
|------|------|
| 后期突破 sink | 宗师段单次 1~2 万，吸收后期产出 |
| 建筑升级 sink | 3 级建筑单次 1 万，多建筑多 sink |
| 武学兑换 sink | 传说武学 1 万+，同盟限定 |
| 寻访令非货币 | 刷怪唯一获取，银两不能直接换弟子 |
| 无体力限制 | 玩家可多刷战斗，但产出与战力挂钩，不无限膨胀 |

### 5.3 防通缩机制

| 机制 | 说明 |
|------|------|
| 生产稳定收入 | 商铺 + 特产保底，不靠战斗也有收入 |
| 任务保底 | 主线 / 悬赏始终有银两奖励 |
| 奇遇爆发 | 奇遇可获高额银两 / 高价值物品 |
| 初始资金 | 500 两起步，不卡新手 |

## 六、与现有系统对接

### 6.1 与门派养成对接

| 对接点 | 机制 |
|--------|------|
| 建筑 | 建造 / 升级是银两主要 sink |
| 生产 | 生产产出是银两主要 source |
| 外交 | 礼物赠送消耗银两 / 物品 |
| 武学兑换 | 物品折算兑换武学 |

### 6.2 与角色系统对接

| 对接点 | 机制 |
|--------|------|
| 境界突破 | 后期突破消耗银两（材料等价） |
| 资质宝物 | 炼丹产出洗髓丹 / 通灵丹（非银两消耗，走药材） |
| 经营 NPC | 生产技能等级影响产出品质与收益 |

### 6.3 与奇遇系统对接

| 对接点 | 机制 |
|--------|------|
| 奇遇奖励 | 经验 / 银两 / 装备 / 功法残卷 / 资质宝物 |
| 隐藏奇遇 | 高价值物品（洗髓丹 / 通灵丹） |

## 七、设计要点（保留原版 + 补充）

- 经济循环：赚钱 → 投资 → 更赚钱/更强 → 更多赚钱途径
- 没有体力限制，经济系统不卡进度
- 种田开店作为稳定收入来源，战斗作为爆发收入
- 寻访令不能用货币买，刷怪是唯一获取途径
- **后期突破 / 建筑升级 / 武学兑换三大 sink 防通胀**（v1.0 补充）
- **生产 + 任务保底防通缩**（v1.0 补充）
- **阶段3 净收支 +250 两/天，节奏合理**（v1.0 补充）
