# 门派养成系统（核心系统）

> **定位**：把《江湖从心》从「个人武侠 RPG」升级为「**门派养成 + 武侠 RPG**」。主角不加入门派，而是**自创门派**，以门派作为查案、复仇、救人的根基，最终左右江湖格局。
>
> 本系统整合原策划案中散落的「生活经营 / 抽卡招募 / 天赋系统 / 门派机制 / 经济系统」，统一到「自创门派」这个核心循环下。

---

## 一、核心定位

### 一句话定位

> 穿越者从「逃犯」走到「开宗立派」，用门派作为查案复仇的根基，最终左右江湖格局。

### 核心循环

```
逃犯流亡 → 散人立足 → 招募人手 → 自创门派 → 经营门派
           （阶段1）   （阶段2）    （阶段2末/3）  （阶段3起）
             ↓
   经营门派 = 生产（炼丹/种植/做菜/酿酒/经营） + 招募 + 外交
             ↓
   借门派之力查案/复仇/救人（主线） → 结局（阶段4-5）
```

### 与主线的关系（关键设计）

门派不是主线的「旁支玩法」，而是主线的「根基与手段」：

| 门派能力 | 主线用途 |
|----------|----------|
| 弟子探索/打探 | 推进查案：找妹妹林小满、查玄真之死真相 |
| 生产产物（丹药/酒/特产） | 外交礼物，换取情报、结盟、兑换武学 |
| 门派战 | 对抗凌云阁、秘境守护者的手段 |
| 门派声望 | 撬动江湖格局，影响结局走向 |

> 核心原则：**经营是手段，查案复仇是目的**。玩家做的一切经营，最终都服务于「查清那一夜真相 + 救出妹妹」。

## 二、核心系统清单（7 大系统）

| 系统 | 作用 | 对应原文 |
|------|------|----------|
| 1. 门派创立 | 从散人到开宗立派 | 势力框架「后期可自创门派」（提前为核心） |
| 2. 弟子系统 | 招募 + 天赋 + 生产 + 入队 | 抽卡招募 + 经营NPC + 伙伴系统（整合） |
| 3. 建筑系统 | 生产/修炼的前提 | 生活经营「家园买/建」（升级） |
| 4. 生产系统 | 炼丹/种植/做菜/酿酒/经营 | 生活经营「生活技能」（升级） |
| 5. 门派外交 | 友好值/仇恨值 → 兑换/开战 | 势力框架「仇恨值/友好值」（深化） |
| 6. 门派战 | 开战、踢馆、掉落 | 新增 |
| 7. 武学兑换 | 友好门派用物品换武学 | 新增 |

## 三、门派创立系统

### 创立条件（阶段2 末 / 阶段3 初）

1. 声望值达到阈值（阶段2 已打出名声）
2. 拥有据点（地图上多个可选址，各有优劣）
3. 招募到至少 N 名弟子（或剧情触发）
4. 完成关键剧情节点（如揭开凌云阁第一道裂缝后，主角意识到需要「自己的势力」）

### 据点选址

| 据点类型 | 优势 | 劣势 |
|----------|------|------|
| 中原繁华地 | 经济好、人脉多 | 势力关注度高、易暴露 |
| 边陲清幽地 | 隐蔽、资源独特 | 经济弱、交通不便 |
| 旧世家废墟 | 藏有秘境线索、有底蕴 | 可能有残留势力/诅咒 |

### 门派要素

- **门派名**：玩家自定义
- **门派等级**：影响可建建筑、可招弟子数量、声望上限
- **门派声望**：影响外交、招募、剧情
- **门派特色**：由玩家选择的武学路线/经营路线决定

## 四、弟子系统（整合「抽卡招募 + 经营NPC + 伙伴」）

### 弟子获取方式

| 方式 | 说明 |
|------|------|
| 寻访招募（抽卡） | 原「寻访令」机制，刷怪获取令，抽弟子 |
| 剧情招募 | 主线/支线中招募特定 NPC |
| 声望吸引 | 门派声望高，主动来投 |
| 奇遇触发 | 特殊事件获得稀有弟子 |

### 弟子天赋（核心养成决策）

每个弟子拥有天赋，玩家需**看天赋分配任务**：

| 天赋类型 | 擅长 | 适合岗位 |
|----------|------|----------|
| 战斗天赋 | 战力高、有专属招式 | 入队战斗 |
| 炼丹天赋 | 炼丹成功率高、品质好 | 丹房 |
| 种植天赋 | 产量高、成长期短 | 药田/农田 |
| 厨艺天赋 | 菜品品质好、有特殊buff | 厨房 |
| 酿酒天赋 | 酒品品质高、有特殊效果 | 酒坊 |
| 经营天赋 | 商铺收益高、砍价 | 商铺 |
| 探索天赋 | 打探情报、发现线索 | 探索/打探（推进主线） |

### 弟子用途

1. **生产**：分配到对应建筑，产出资源（需对应建筑）
2. **入队战斗**：战斗型弟子加入主角队伍（整合原「伙伴系统」）
3. **探索打探**：外出收集情报、找线索（推进主线查案）

> 关键：弟子天赋决定其最优岗位，玩家「看天赋用人」是核心养成乐趣。

---

## 五、建筑系统（生产的前提）

### 原则：建立对应建筑，方可进行对应操作

| 建筑 | 解锁操作 |
|------|----------|
| 丹房 | 炼丹 |
| 药田 / 农田 | 种植药材/食材 |
| 商铺 | 经营（买卖） |
| 厨房 | 做菜 |
| 酒坊 | 酿酒 |
| 练功房 | 弟子修炼、传授武学 |
| 藏经阁 | 存放/研习武学 |

### 建筑升级

- 升级提升产量、品质、解锁高级配方
- 建筑等级受门派等级限制

## 六、生产系统（生活技能）

| 技能 | 产物 | 用途 |
|------|------|------|
| 炼丹 | 丹药 | 回血、增益、突破、外交礼物 |
| 种植 | 药材、食材 | 炼丹/做菜原料、售卖 |
| 做菜 | 食物 | 回血、临时buff |
| 酿酒 | 酒 | 社交、外交礼物、临时buff |
| 经营 | 银两、特产 | 门派经济来源 |

### 产物去向（闭环）

```
生产 → ① 自用（回血/增益/突破）
      → ② 售卖（门派经济）
      → ③ 外交礼物（提升友好值）
      → ④ 兑换武学（友好门派的硬通货）
```

> 这个闭环把「生产、经济、外交、武学」四个系统串成一体，是门派养成的核心经济模型。

---

## 七、门派外交系统（友好值 / 仇恨值）

### 关系数值

- 与各门派（六扇门/凌云阁/幽月教/江湖散人〔丐帮〕等）的关系由**友好值 / 仇恨值**决定
- 影响方式：**NPC 互动 + 剧情选择 + 任务 + 礼物赠送**

### 友好值高 → 互利

| 行为 | 说明 |
|------|------|
| 兑换武学 | 用物品（特产/材料/丹药/酒）兑换该门派武学 |
| 贸易 | 互通有无，购买稀有材料 |
| 结盟 | 共同对抗第三方势力 |
| 情报共享 | 获取主线查案线索 |

### 仇恨值高 → 敌对

| 行为 | 说明 |
|------|------|
| 门派开战 | 对仇恨门派发起门派战 |
| 上门挑战（踢馆） | 单挑/小队挑战该门派 |
| 战利掉落 | 击败该门派弟子，掉落对应装备/技能 |

---

## 八、门派战系统

### 触发条件

- 与目标门派仇恨值达到阈值，可主动开战
- 或对方门派主动来犯

### 战斗形式

| 形式 | 说明 |
|------|------|
| 门派战（群战） | 主角带队 + 战斗型弟子 vs 对方门派 |
| 上门挑战（踢馆） | 单挑/小队挑战对方高手 |

### 战利品

- 击败对方弟子，**掉落对应装备/技能**
- 击败掌门/长老，掉落门派核心武学（对应「爆技能」爽点）

---

## 九、武学兑换系统

### 友好门派兑换

- 用物品（特产/材料/丹药/酒）在友好门派处兑换武学
- 武学与门派特色绑定（凌云阁=剑法、幽月教=暗杀类、六扇门=刀法/缉捕类）

### 自创门派武学

- 门派藏经阁可研习已获得的武学
- 形成门派特色武学路线（多周目可尝试不同流派）

## 十一、开发优先级（做减法，防复杂度爆炸）

| 优先级 | 内容 | 说明 |
|--------|------|------|
| **P0** | 主角养成 + 自创门派 + 弟子招募 + 基础建筑 + 外交 | 核心循环验证 |
| **P1** | 生产系统（炼丹/种植/做菜/酿酒/经营）+ 武学兑换 + 门派战 | 完善玩法闭环 |
| **P2** | 深度弟子 AI、门派外交网络、多周目变体 | 深度扩展 |

> 建议：先做 P0 验证「自创门派 + 弟子 + 外交」的核心乐趣，再逐步加生产与战斗，避免一次性堆砌导致系统失控。
