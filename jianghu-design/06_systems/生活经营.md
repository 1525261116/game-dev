# 生活与经营

## 家园

- 靠买/建
- 开局漂泊，赚钱后买地建房，慢慢升级

## 种田开店养宠物

- 在固定地点
- 主要赚钱和自给自足

## 生活技能

| 技能 | 用途 |
|------|------|
| 钓鱼 | 任务需要、卖钱 |
| 烹饪 | 烹饪食物加临时属性 |
| 炼药 | 炼制丹药 |
| 锻造 | 装备打造 |
| 缝纫 | 装备打造 |
| 制造 | 特殊道具 |
| 采药 | 炼药材料 |
| 挖矿 | 锻造材料 |
| 伐木 | 建造材料 |

### 用途汇总

- 任务需要
- 卖钱
- 炼制丹药
- 烹饪食物加临时属性
- 特殊道具开启隐藏任务

## 宠物

- 好看、陪伴、收集
- 不打架不经营
- 获取方式：野外捕捉、奇遇赠送、商店购买

## 经营 NPC

- 靠抽卡获取
- 专门帮忙种田、开店、养宠物
- 不同 NPC 擅长不同
- 支持一键操作

## 体力

- **没有体力限制**，想玩多久玩多久
