# 天赋系统

> **定位**：天赋是角色的「天生倾向」，决定角色在江湖中的最优成长路径与岗位分配。主角天赋由开局五问决定；弟子/NPC 天赋由资质档 + 出身决定。天赋不替代养成，而是给养成方向"指路"——看天赋用人，是门派养成的核心决策乐趣。
>
> **关联**：角色通用模型 §四 天赋字段；门派养成 §四 弟子天赋；资质宝物获取线；成长曲线。

---

## 一、天赋总览

### 1.1 天赋分类

| 大类 | 子类 | 持有者 | 作用 |
|------|------|--------|------|
| 主角天赋（6 种） | 独行/侠义/枭雄/通神/百兵/拳掌 | 仅主角，开局五问决定 | 定义主角江湖路线与战斗风格 |
| 战斗天赋 | 伤害型/防御型/控制型/辅助型 | 伙伴 + 战斗型弟子 + 部分 NPC | 入队战斗加成 |
| 生产天赋（7 类） | 炼丹/种植/厨艺/酿酒/经营/探索 + 战斗 | 弟子 + 经营 NPC | 决定弟子最优岗位 |
| 特殊天赋 | 穿越者/悟性通神/秘境血脉 等 | 剧情限定角色 | 不可重置，定义角色叙事定位 |

### 1.2 天赋档（品质）

> 与伙伴品质（普通/优秀/稀有/传说）对齐，天赋品质决定天赋效果的强度档。

| 天赋档 | 名称 | 效果强度 | 持有概率 | 对应伙伴品质 |
|--------|------|----------|----------|--------------|
| 凡 | 普通 | 基础效果 | 抽卡弟子约 60% | 普通 |
| 良 | 优秀 | 基础 ×1.3 | 约 30% | 优秀 |
| 上 | 稀有 | 基础 ×1.6 | 约 9% | 稀有 |
| 极 | 传说 | 基础 ×2.0 | 约 1% | 传说 |

> 天赋档作用于**单个天赋**，非角色整体。一个弟子可能「炼丹天赋·上品 + 战斗天赋·凡品」——玩家需判断它该进丹房还是入队。

## 二、主角六大天赋（开局五问决定）

### 2.1 开局五问

> 五道选择题，统计后从六大天赋中分配一个。五问分别考察：江湖观 / 处世态度 / 兵器偏好 / 性格倾向 / 终极目标。每题选项对应不同属性加成与天赋倾向，**统计后倾向最高的天赋即为结果**（并列时取第五问选择对应的天赋）。

| 题号 | 考察维度 | 影响 |
|------|----------|------|
| 第一问 | 江湖观 | 四维属性 + 悟性隐藏资质 |
| 第二问 | 处世态度 | 四维属性 + 悟性隐藏资质 |
| 第三问 | 兵器偏好 | 武学类型加成（非天赋，是被动倾向） |
| 第四问 | 性格倾向 | 天赋倾向计数 |
| 第五问 | 终极目标 | 天赋倾向计数（权重×2，决定性） |

**五问选项与属性加成**：

| 题目 | 选项 | 属性加成 | 倾向 |
|------|------|----------|------|
| 一·江湖观 | 快意恩仇 | 臂力+2，身法+1 | — |
| | 安居乐业 | 根骨+2，内息+1 | — |
| | 自由自在 | 身法+2，悟性+1 | 独行 |
| | 神秘莫测 | 悟性+2，内息+1 | 通神 |
| | 情义为先 | 内息+2，根骨+1 | 侠义 |
| 二·处世 | 拔刀相助 | 臂力+1 | 侠义 |
| | 暗中相助 | 身法+1，悟性+1 | — |
| | 报官处理 | 根骨+1，内息+1 | — |
| | 先看情况 | 悟性+2 | 通神 |
| | 不管闲事 | 身法+2 | 独行 |
| 四·性格 | 独来独往 | — | 独行+2 |
| | 喜欢结交朋友 | — | 侠义+2 |
| | 喜欢经营赚钱 | — | 经营倾向（非六大天赋，触发经商支线） |
| | 痴迷武学 | — | 通神+2 |
| | 喜欢探索冒险 | — | 福缘倾向（非六大天赋，触发奇遇加成） |
| 五·终极 | 归隐田园 | — | 经营倾向 |
| | 开宗立派 | — | 宗师倾向（非六大天赋，门派养成加成） |
| | 逍遥天下 | — | 独行+4 |
| | 守护苍生 | — | 侠义+4 |
| | 追求武道极致 | — | 通神+4 |

> 倾向计数规则：第四问 ×1，第五问 ×2。六大天赋中倾向最高者即为结果。"经营倾向""福缘倾向""宗师倾向"不计入六大天赋，若它们最高则按第五问选择回退到对应六大天赋（归隐→侠义，探索→独行，宗师→通神）。

### 2.2 六大主角天赋

| 天赋 | 触发条件 | 效果 |
|------|----------|------|
| 独行天下 | 独行倾向最高 | 独自上阵时伤害+30%、防御+20%、吸血+10%；带伙伴时减半（伤害+15%、防御+10%、吸血+5%） |
| 侠肝义胆 | 侠义倾向最高 | 正派势力好感获取+40%；正派商店价格-10%、正派任务奖励+20%；可触发正派 NPC 特殊互动 |
| 枭雄本色 | 枭雄倾向最高（侠义反极） | 邪派势力好感获取+40%；邪派商店价格-10%、邪派任务奖励+20%；可触发邪派 NPC 特殊互动 |
| 悟性通神 | 通神倾向最高 | 学武功速度+50%；经验获取+25%；隐藏悟性+5；**境界突破资质门槛 ×0.8**（后天30→24/先天50→40/宗师70→56） |
| 百兵之王 | 兵器偏好+独行 | 刀/剑/暗器/奇门/枪法威力+25%；所选兵器额外+10%暴击 |
| 拳掌双绝 | 兵器偏好拳掌 | 拳掌威力+25%；攻击 20% 概率造成眩晕 |

> 枭雄本色触发：当玩家在侠义相关选择中**持续选择冷血/利己项**（善恶值低于 0 时），侠义倾向反转为枭雄。这是唯一的"动态天赋"，允许玩家在游戏中由侠转枭（不可逆，体现江湖腐蚀）。

## 三、弟子生产天赋（7 类）

> 门派弟子的核心养成决策。每个弟子拥有 1~2 个生产/战斗天赋，玩家看天赋分配岗位。

### 3.1 七类天赋基础效果（凡品基准）

| 天赋 | 擅长 | 适合岗位 | 凡品效果 |
|------|------|----------|----------|
| 战斗天赋 | 战力高、有专属招式 | 入队战斗 | 伤害+10%、血量+5% |
| 炼丹天赋 | 炼丹成功率高、品质好 | 丹房 | 炼丹成功率+10%、出丹量+10% |
| 种植天赋 | 产量高、成长期短 | 药田/农田 | 产量+15%、成长期-10% |
| 厨艺天赋 | 菜品品质好、有特殊 buff | 厨房 | 品质提升一档概率+15%、buff 持续+20% |
| 酿酒天赋 | 酒品品质高、有特殊效果 | 酒坊 | 品质提升一档概率+15%、酒效+20% |
| 经营天赋 | 商铺收益高、砍价 | 商铺 | 收益+20%、采购价-10% |
| 探索天赋 | 打探情报、发现线索 | 探索/打探 | 情报获得率+15%、线索发现+10% |

### 3.2 天赋档对效果的影响

| 天赋档 | 战斗天赋 | 生产天赋 |
|--------|----------|----------|
| 凡 | 伤害+10%/血+5% | 基础效果 |
| 良 | 伤害+13%/血+7% | 基础×1.3 |
| 上 | 伤害+16%/血+10% | 基础×1.6 |
| 极 | 伤害+20%/血+15% | 基础×2.0 |

> 对齐已有伙伴标定：谢九探索天赋（情报+25%/线索+20%）= 上品；陆青崖/月无瑕/周铁山战斗天赋（伤害+20%/血+15%）= 极品。稀有伙伴天生上/极品天赋，优秀伙伴天生良品。

### 3.3 天赋与资质档搭配规则

> 决定弟子最优成长路径的核心规则——资质决定上限，天赋决定方向。

| 资质档 | 推荐天赋搭配 | 典型岗位 | 培养上限 |
|--------|--------------|----------|----------|
| 凡庸 | 生产天赋（任意） | 经营 NPC | 战斗天花板武者九境，建议走生产 |
| 寻常 | 生产天赋 / 战斗天赋·凡品 | 经营或低阶战斗 | 武者圆满，可做守卫型战斗 |
| 聪颖 | 战斗天赋·良品及以上 | 入队战斗 | 后天圆满，主力战斗弟子 |
| 慧根 | 战斗天赋·上品及以上 | 入队战斗/精英 | 先天圆满，可做战斗队长 |
| 通神 | 战斗天赋·极品 | 入队战斗/副将 | 宗师圆满，可独当一面 |
| 绝顶 | 战斗天赋·极品 | 入队战斗/核心 | 武侠之巅候选 |

> 设计意图：低资质弟子走生产线（成长快、即时正反馈），高资质弟子走战斗线（成长慢但天花板高）。玩家若强行让凡庸弟子走战斗，23 年才达武者九境天花板——可以养，但效率极低，这就是"看天赋用人"的决策张力。

## 四、特殊天赋

> 剧情限定角色专属，不可重置，不可抽取，定义角色叙事定位。

| 特殊天赋 | 持有者 | 效果 | 叙事定位 |
|----------|--------|------|----------|
| 穿越者 | 主角（专属） | 系统面板（奖励点/任务/存档）；悟性初始+10；可看 NPC 状态面板 | 外挂，主线叙事根基 |
| 悟性通神（强化版） | 主角可选 | 资质门槛 ×0.8；学武功 ×1.5；可发现武功隐藏搭配 | 痴武路线 |
| 秘境钥匙血脉 | 林小满（专属） | 隐藏天赋，可开启秘境核心；被守境司觊觎 | 终极反派线的钥匙 |
| 武学奇才 | 周铁山可触发 | 偶遇名师后，寻常资质可短暂爆发（活动系数 ×1.5，持续 1 游戏年） | 热血逆袭叙事 |
| 宗师气运 | 秦望舒 | 通神资质 + 气运加持，关键战斗概率闪避+暴击 | 反派强度来源 |
| 上古传承 | 无相 | 绝世功法直接登峰，无需修为积累 | 终极 BOSS 强度解释 |

## 五、天赋对成长曲线的影响

> 天赋不改变成长公式结构，只调整系数。

| 天赋 | 影响维度 | 系数 |
|------|----------|------|
| 悟性通神 | 学武功速度 | ×1.5 |
| 悟性通神 | 经验获取 | ×1.25 |
| 悟性通神 | 资质门槛 | ×0.8 |
| 战斗天赋·极 | 战斗伤害/血量 | ×1.2 / ×1.15 |
| 生产天赋·极 | 生产效率/品质 | ×2.0 |
| 探索天赋·上 | 情报/线索 | ×1.6 |
| 穿越者 | 悟性初始 | +10（固定） |

> 悟性通神的 ×0.8 资质门槛：后天 30→24、先天 50→40、宗师 70→56——使聪颖档（30~49）玩家选悟性通神后可跨档冲击先天圆满（门槛 50→40 落在聪颖档内）。这是"痴武者逆天改命"的数值根基。

## 六、天赋重置机制

### 6.1 主角天赋

| 时机 | 规则 |
|------|------|
| 多周目 | 每周目重新五问，可换天赋 |
| 4 周目解锁 | 解锁"天赋自选"，跳过五问直接选 |
| 单周目内 | 不可重置（唯一例外：侠→枭反转，不可逆） |

### 6.2 弟子天赋

| 时机 | 规则 |
|------|------|
| 招募时 | 随机生成（1~2 个，按概率） |
| 洗髓丹 | 可重置一个天赋档（不换天赋类型，只重置品质） |
| 天元丹 | 可更换一个天赋类型（极稀缺，与资质提升竞争资源） |

> 设计意图：天赋重置极稀缺，强迫玩家"看天赋用人"而非"洗出完美弟子"。天元丹只有 1~2 颗，玩家须在"提升资质上限"vs"换天赋类型"间抉择——这是资源稀缺制造的关键决策。

## 八、设计要点

- 天赋是"指路牌"不是"天花板"：低资质+生产天赋走经营线成长快、有正反馈；高资质+战斗天赋走战斗线天花板高。玩家若逆天赋养，效率极低但可行——这是高自由度的体现。
- 天赋档稀缺自洽：极品天赋约 1% 概率，玩家无法量产极品战斗弟子，必须靠剧情伙伴（谢九/陆青崖等自带上/极品）补强。
- 侠→枭反转不可逆：体现江湖腐蚀，是唯一的动态天赋，给"从侠客到枭雄"的堕落叙事以数值支撑。
- 穿越者天赋不可替换：主角专属，是系统面板的叙事根基，多周目保留。
