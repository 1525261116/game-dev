# 存档系统

> **定位**：存档是穿越者系统的核心功能之一——"存档点"是穿越者才能感知的时空锚点。它既是单机 RPG 的基础功能，也是防 SL 滥用（战斗序列制可 SL，但有约束）与多周目继承的承载层。
>
> **关联**：穿越者系统（存档是其功能）；结局系统（多周目继承规则）；战斗系统（战斗随机序列制可 SL）；奇遇系统（奇遇触发后存档）；门派养成（门派状态存档）。

---

## 一、核心原则

| 原则 | 说明 |
|------|------|
| 存档是穿越者功能 | 存档点是世界中"时空锚点"，只有穿越者能感知——叙事与机制统一 |
| 战斗可 SL | 战斗随机为"序列"制（对齐烟雨江湖），玩家可 SL 刷结果，但有约束 |
| 多周目不继承数值 | 每周目从零开始，但继承玩家天赋选择+图鉴+成就 |
| 自动 + 手动 | 自动存档防丢失，手动存档给玩家掌控 |
| 云端同步 | 多设备同步（PC/移动），存档加密 |

---

## 二、存档槽位

### 2.1 槽位配置

| 槽位类型 | 数量 | 说明 |
|----------|------|------|
| 手动存档 | 10 | 玩家自由存取 |
| 自动存档 | 3 | 轮转覆盖（旧→新） |
| 快速存档 | 1 | 快捷键瞬存（仅 PC） |
| 多周目槽 | 每周目独立 | 周目结束归档，不可覆盖 |

### 2.2 存档点机制

> 存档点是世界中的"时空锚点"，叙事上是穿越者感知的特殊地点。

| 存档点类型 | 位置 | 说明 |
|------------|------|------|
| 固定存档点 | 城/镇/门派/秘境入口 | 野外无存档点，城内可存 |
| 临时存档点 | 营地/破庙/篝火 | 野外过夜点，单次使用 |
| 穿越者系统 | 系统面板内（升级解锁） | 任意地点存档，但消耗"时之力" |

> 野外无固定存档点：强迫玩家"回城才能安全存档"，增加野外探索的风险感——但穿越者系统升级后可在任意地点存档（消耗时之力），这是穿越者外挂的体现。

---

## 三、自动存档触发

| 触发点 | 说明 |
|--------|------|
| 进入城镇 | 每次进城自动存 |
| 主线节点 | 每完成一个主线阶段自动存 |
| 闭关前/后 | 闭关是重大时间跳跃，必存 |
| 门派战前/后 | 战前战后必存 |
| 奇遇触发 | 奇遇开始时自动存（防错过） |
| 定时 | 每 10 现实分钟自动存（防闪退丢失） |

> 自动存档是安全网，不替代手动存档。玩家仍需主动管理存档槽。

---

## 四、手动存档限制

| 限制 | 说明 |
|------|------|
| 野外限制 | 野外无固定存档点，需回城或用穿越者系统 |
| 战斗中不可存 | 战斗中不可手动存档（防战斗 SL 刷到完美） |
| 剧情节点不可存 | 关键抉择剧情进行中不可存（防 SL 抉择） |
| 穿越者系统消耗 | 任意地点存档消耗"时之力"（稀缺资源） |

> 关键抉择不可存：防"存档试每个选项"的 SL 滥用——抉择的不可逆性是其叙事张力的来源。

---

## 五、战斗 SL 与防滥用

### 5.1 战斗序列制（可 SL）

> 对齐烟雨江湖：战斗随机为"序列"制，战斗开始时生成随机序列，玩家可 SL 重生成序列。

| 项 | 规则 |
|----|------|
| 序列生成 | 战斗开始时生成（暴击/闪避/掉落随机序列） |
| SL 效果 | 退出战斗重打，序列重新生成 |
| 允许 SL | 玩家可 SL 刷好结果，但有约束 |

### 5.2 防 SL 滥用约束

| 约束 | 说明 |
|------|------|
| 战斗中不可存 | 战斗中不可手动存，退出即结束 |
| SL 次数记录 | 隐藏记录 SL 次数，影响"福缘"（SL 多福缘降） |
| 掉落 SL 衰减 | 同一战斗 SL 超过 3 次，掉落品质概率衰减 |
| 时之力消耗 | 穿越者系统"回溯"功能（战斗内 SL）消耗时之力 |

> SL 不禁止但有隐性惩罚：SL 多则福缘降、掉落衰减——让 SL 刷有成本，但保留"关键战斗可 SL 刷好结果"的爽点。

### 5.3 穿越者"回溯"功能

| 功能 | 说明 |
|------|------|
| 战斗内回溯 | 消耗时之力，回退到战斗开始（重生成序列） |
| 解锁条件 | 穿越者系统 3 级解锁 |
| 时之力稀缺 | 击败 BOSS/完成主线获得，不可购买 |
| 限制 | 每场战斗最多回溯 2 次 |

> 时之力是穿越者系统的稀缺资源，回溯是其核心消耗——让"存档/SL"成为穿越者外挂的机制承载，而非单纯的系统功能。

## 六、存档内容结构

> 存档包含完整游戏状态，确保加载后无缝恢复。

| 内容 | 说明 |
|------|------|
| 主角状态 | 四维/境界/功法槽/修为/天赋/善恶/传记 |
| 伙伴状态 | 全部伙伴+好感度+在队状态 |
| 弟子状态 | 全部门派弟子+岗位+境界 |
| 门派状态 | 等级/声望/建筑/外交友好仇恨 |
| 世界时间 | 江湖时间+闭关时间+季节 |
| NPC 状态 | 核心 NPC 境界/善恶/活动/关系网快照 |
| 任务进度 | 主线/支线/奇遇进度 |
| 图鉴 | 功法/装备/NPC/奇遇图鉴 |
| 探索标记 | 地图标记/采集点/已发现区域 |
| 设置 | 玩家偏好设置 |
| 多周目元数据 | 周目数+已继承项+成就 |

> NPC 状态快照：核心 NPC 的境界/善恶/活动状态在存档时快照——惰性结算的补算基准是存档时的快照+当前时间差。

---

## 七、多周目继承规则

> 对齐结局系统 §多周目机制：不继承数值，继承玩家天赋+图鉴。

### 7.1 不继承项

| 项 | 说明 |
|----|------|
| 主角数值 | 四维/境界/功法/修为全归零 |
| 伙伴/弟子 | 全部清空 |
| 门派 | 清空 |
| 银两/装备/材料 | 清空 |
| 世界时间 | 重置 |
| NPC 状态 | 重置为初始 |

### 7.2 继承项

| 项 | 说明 |
|----|------|
| 玩家天赋选择 | 上周目选的天赋，本周目可直接选（不需五问） |
| 功法图鉴 | 已见过的功法图鉴保留（只读，不可用） |
| 装备图鉴 | 已见过的装备图鉴保留 |
| NPC 图鉴 | 已见过的 NPC 图鉴保留 |
| 奇遇图鉴 | 已触发的奇遇图鉴保留 |
| 成就 | 永久保留 |
| 周目数 | 累计，影响某些解锁 |

### 7.3 多周目解锁

| 周目 | 解锁 |
|------|------|
| 2 周目 | 新开局可选"跳过五问"+天赋自选（部分） |
| 3 周目 | 解锁"起点天赋点"+2（主角初始四维多 2 点） |
| 4 周目 | 解锁"天赋自选"（全部六天赋自由选） |
| 5 周目+ | 解锁"隐藏结局"线索（需满足其他条件） |

> 多周目鼓励重玩：不继承数值防"一周目变强后无脑二周目"，但继承天赋选择+图鉴+成就，让重玩有"知识积累"的优势——这是单机 RPG 的经典多周目设计。

## 八、云端同步

| 项 | 规则 |
|----|------|
| 同步 | 存档加密上传云端，多设备同步 |
| 平台 | PC（Steam）+ 移动（iOS/Android）跨平台同步 |
| 冲突 | 多设备同时游玩产生冲突，提示玩家选最新 |
| 隐私 | 存档仅含游戏状态，不含个人信息 |
| 离线 | 离线可玩，联网后自动同步 |

> 云端同步是 PC+移动双端的必需——玩家在 PC 玩到一半，移动端可无缝继续。

## 九、与穿越者系统对接

| 穿越者功能 | 存档对接 |
|------------|----------|
| 系统面板 | 存档/读档入口在面板内 |
| 任意地点存档 | 消耗时之力 |
| 战斗回溯 | 消耗时之力，回退战斗 |
| 存档点感知 | 系统升级后可在地图标记附近存档点 |
| 时之力 | 击败 BOSS/主线获得，是存档/回溯的消耗资源 |
| 系统骗人 | 关键时刻存档功能"受干扰"（无法存档/回溯），叙事张力 |

> 系统骗人：穿越者系统"关键时刻被上古势力干扰"的设定，在机制上体现为"关键剧情节点不可存档/回溯"——叙事与机制统一。

| 现有系统 | 对接点 | 是否冲突 |

## 十一、设计要点

- 存档是穿越者功能：叙事与机制统一——存档点是"时空锚点"，穿越者系统消耗"时之力"可任意存档/回溯，这是穿越者外挂的机制承载。
- 战斗可 SL 但有约束：序列制可 SL 刷结果，但 SL 多则福缘降/掉落衰减——保留"关键战斗可 SL"的爽点，防无脑刷。
- 关键抉择不可存：抉择的不可逆性是叙事张力来源，防"存档试每个选项"。
- 多周目不继承数值：防"一周目变强后无脑二周目"，但继承天赋选择+图鉴+成就，让重玩有知识积累优势。
- 时之力稀缺：是穿越者系统的核心消耗，仅 BOSS/主线获得，不可购买——保持存档/回溯的稀缺感。
- 系统骗人：关键时刻存档功能"受干扰"，叙事张力与机制统一。
