# 抽卡与寻访系统

> **定位**：寻访招募是门派弟子的核心获取方式之一（另三种：剧情招募/声望吸引/奇遇触发）。用专属"寻访令"招募江湖散人入自创门派，弟子天赋资质随机生成。寻访令**仅刷怪获取，不可用真金购买**——这是"不卖数值"商业化口径的硬边界。
>
> **关联**：门派养成 §四 弟子系统；角色通用模型（弟子也是 Character 底座）；天赋系统（弟子天赋档概率）；装备系统（寻访令品质与装备品质对齐）；经济系统（不与银两挂钩）。

---

## 一、寻访令

### 1.1 专属货币

| 项 | 规则 |
|----|------|
| 货币 | 寻访令（独立货币，不能用游戏内银两抽） |
| 获取 | 仅刷怪掉落（怪物掉落，非购买） |
| 商业化边界 | 不可用真金购买寻访令；移动端内购仅限外观/剧情/便利，不含寻访令——**不卖数值**口径的硬边界 |

### 1.2 寻访令品质

> 与伙伴品质（普通/优秀/稀有/传说）对齐，品质决定出好弟子的概率。

| 品质 | 影响出好伙伴概率 | 掉落来源 |
|------|------------------|----------|
| 普通 | 低（凡庸资质为主） | 普通怪 |
| 优秀 | 中（含寻常/聪颖） | 精英怪 |
| 稀有 | 高（含聪颖/慧根） | BOSS |
| 传说 | 最高（含慧根/通神） | 终极 BOSS / 高级奇遇 |

### 1.3 掉落规则

| 怪物类型 | 掉落品质倾向 | 掉落概率 |
|----------|--------------|----------|
| 普通怪 | 普通令为主 | 约 15% |
| 精英怪 | 优秀/稀有令 | 约 30% |
| BOSS | 传说令 | 100%（必掉） |
| 终极 BOSS | 传说令 + 额外 | 100% + 剧情限定 |

| 特殊规则 | 说明 |
|----------|------|
| 普通怪极小概率掉传说令 | 约 0.1%，制造惊喜 |
| 越级加成 | 打高等级怪，掉率与品质概率提升 |
| 越级惩罚 | 打低等级怪（差 4 级以上），经验和爆率减少 |

### 1.4 越级加成表

| 等级差（怪−角色） | 掉率加成 | 品质提升 |
|--------------------|----------|----------|
| +1~3 级 | 小幅 +10% | 品质不变 |
| +4~6 级 | 中幅 +25% | 品质+1 档概率 |
| +7 级以上 | 大幅 +50% | 品质+1 档概率翻倍 |

| 等级差（角色−怪） | 掉率惩罚 |
|--------------------|----------|
| 高 1~3 级 | -10% |
| 高 4~6 级 | -30% |
| 高 7 级以上 | -60%（刷低级怪低效） |

> 设计意图：越级打怪高回报，但风险大；刷低级怪低效，防"刷初始区"。

## 二、招募池分类

> 不同寻访令品质对应不同招募池，池内 NPC 资质档分布不同。

### 2.1 四大招募池

| 招募池 | 寻访令 | 资质档分布 | NPC 类型 |
|--------|--------|------------|----------|
| 草莽池 | 普通令 | 凡庸 70% / 寻常 25% / 聪颖 5% | 江湖散人、流民、落魄武人 |
| 江湖池 | 优秀令 | 凡庸 30% / 寝常 45% / 聪颖 20% / 慧根 5% | 游侠、落魄世家子弟、退伍军汉 |
| 名宿池 | 稀有令 | 寻常 20% / 聪颖 40% / 慧根 30% / 通神 10% | 隐退武人、破落门派遗孤、奇遇型散人 |
| 传奇池 | 传说令 | 聪颖 20% / 慧根 40% / 通神 30% / 绝顶 10% | 世家传人、上古传承持有者、秘境幸存者 |

> 资质档分布对齐角色通用模型 §三 悟性六档（凡庸/寻常/聪颖/慧根/通神/绝顶）。

### 2.2 池内 NPC 身份

> 招募到的 NPC 不是"无名弟子"，而是有身份背景的江湖人，带初始传记。

| 池 | 身份示例 | 初始传记钩子 |
|----|----------|--------------|
| 草莽池 | 流民/乞丐/猎户/樵夫 | 因战乱/灾荒流落江湖 |
| 江湖池 | 游侠/落魄世家/退伍军汉/小门派弟子 | 门派被灭/家道中落/得罪权贵 |
| 名宿池 | 隐退武人/破落门派遗孤/奇遇型散人 | 退隐后复出/复仇线/奇遇线 |
| 传奇池 | 世家传人/上古传承者/秘境幸存者 | 身负秘辛/被追杀/寻找传人 |

> 招募后生成 lifeEvents，可触发后续支线（如"落魄世家子弟"招募后可能触发家产继承支线）。这让抽卡不是"抽数值"，而是"抽江湖故事"。

## 三、概率与保底机制

### 3.1 单次招募概率

> 寻访令品质 × 池内资质分布 = 综合出好弟子概率。

以"稀有令·名宿池"为例：

| 资质档 | 概率 | 天赋档概率（同池） |
|--------|------|---------------------|
| 寻常 | 20% | 凡 60% / 良 30% / 上 9% / 极 1% |
| 聪颖 | 40% | 同上 |
| 慧根 | 30% | 同上 |
| 通神 | 10% | 同上 |

> 天赋档概率对齐天赋系统 §一（凡60%/良30%/上9%/极1%），与资质档独立滚动。

### 3.2 保底机制

| 保底类型 | 规则 |
|----------|------|
| 十连保底 | 每 10 次招募必出至少 1 名聪颖及以上资质弟子 |
| 五十连保底 | 每 50 次招募必出至少 1 名慧根及以上资质弟子 |
| 百连保底 | 每 100 次招募必出至少 1 名通神资质弟子 |
| 大保底 | 连续 200 次未出通神，下次必出通神 |

> 保底计数跨池共享（不同池的招募都计入同一计数器）。保底只保资质档，不保天赋档——天赋档仍随机。

### 3.3 重复招募处理

> 同一 NPC 不会重复招募（NPC 有唯一 id）。若池内剩余 NPC 耗尽，转为"通用人模板"生成（无专属传记，资质按池分布随机）。

| 情况 | 处理 |
|------|------|
| 池内专属 NPC 未招完 | 正常招募，带传记 |
| 专属 NPC 招完 | 生成通用人（无传记，资质随机） |
| 通用人上限 | 提示"暂无可用之才"，需等待刷新（游戏时间 30 日刷新池） |

## 四、弟子与角色系统对齐

### 4.1 弟子也是 Character 底座

> 招募到的弟子与主角/伙伴/NPC 共用同一套 Character 模型，培养规则一致。

| Character 字段 | 弟子初始值 | 成长规则 |
|----------------|------------|----------|
| 资质档/悟性 | 按池分布随机 | 可用资质宝物提升（+30 上限） |
| 人物境界 | 初始武者一境~三境 | 时间成长（基准 400 × 悟性系数 × 性格 × 活动） |
| 功法槽（5 槽） | 初始 1~2 槽有功法（池带） | 可传授/夺宝获取 |
| 善恶值 | 按出身随机（-50~+50） | 随玩家行为改变 |
| 忠诚阵营 | 初始中立 | 随门派归属改变 |
| 性格标签 | 按出身随机 | 可被剧情事件改变 |
| 天赋 | 1~2 个，按概率随机 | 洗髓丹重置档/天元丹换类型 |
| 传记 lifeEvents | 专属 NPC 带初始传记 | 玩家介入插入事件 |

### 4.2 弟子与伙伴的区别

| 维度 | 伙伴（剧情） | 弟子（招募） |
|------|--------------|--------------|
| 获取 | 主线剧情必入 | 寻访令招募 |
| 传记 | 有专属剧情线 | 池内专属 NPC 有简传记，通用人无 |
| 天赋档 | 自带上/极品 | 随机（凡~极） |
| 资质档 | 已标定（聪颖~慧根） | 随机（凡庸~通神） |
| 培养规则 | 与主角一致 | 与主角一致 |
| 上阵 | 主角+3 伙伴优先 | 战斗型弟子可替代伙伴入队 |

> 设计意图：伙伴是"有名有姓的江湖人"，弟子是"招募来的无名之辈"——但二者培养规则完全一致，理论上招募的通神资质弟子能一路养成到宗师，甚至比伙伴更强。这是"高自由度江湖"的数值基础。

## 五、弟子岗位分配

> 招募后，玩家看天赋分配岗位。对齐门派养成 §四 与天赋系统 §三。

| 天赋 | 岗位 | 需要建筑 | 产出 |
|------|------|----------|------|
| 战斗天赋 | 入队战斗 / 守卫 | 练功房 | 战力 |
| 炼丹天赋 | 丹房 | 丹房 | 丹药 |
| 种植天赋 | 药田/农田 | 药田 | 药材/食材 |
| 厨艺天赋 | 厨房 | 厨房 | 食物 |
| 酿酒天赋 | 酒坊 | 酒坊 | 酒 |
| 经营天赋 | 商铺 | 商铺 | 银两/特产 |
| 探索天赋 | 探索/打探 | 无（外出） | 情报/线索 |

> 一个弟子可有 1~2 个天赋，多天赋弟子可跨岗位调动（如"炼丹+探索"白天探索晚上炼丹），但单岗位效率按对应天赋档计算。

## 六、其他弟子获取方式

> 寻访令之外，另有三种弟子获取方式，对齐门派养成 §四。

| 方式 | 说明 | 资质倾向 |
|------|------|----------|
| 剧情招募 | 主线/支线招募特定 NPC | 已标定（如某些支线 NPC） |
| 声望吸引 | 门派声望达阈值，主动来投 | 随机，受声望影响偏向中高 |
| 奇遇触发 | 特殊事件获得稀有弟子 | 高资质（慧根/通神） |

> 声望吸引公式：声望 ≥ 500 时开始吸引弟子；每 +500 声望，来投弟子资质档期望+1 档（上限通神）。

## 七、商业化边界（硬约束）

| 项 | 规则 | 理由 |
|----|------|------|
| 寻访令 | 仅刷怪获取，不可真金购买 | 不卖数值 |
| 招募次数 | 无限（只要有令） | 鼓励肝 |
| 保底 | 计数跨池共享 | 防"氪一池" |
| 移动端内购 | 仅限外观/剧情/便利，不含寻访令/资质宝物/装备 | 双轨定价口径 |
| 加速 | 不卖"跳过保底"道具 | 不做付费加速 |

> 与 GDD 商业化口径完全一致：PC 买断 ¥68 + 移动免费本体 + 纯外观/剧情/便利内购，不卖数值、不做付费加速。

## 八、与现有系统对齐

| 现有系统 | 对接点 | 是否冲突 |
|----------|--------|----------|
| 门派养成 §四 | 弟子获取四方式对齐；岗位分配对齐 | 无（本设计细化概率） |

| 装备系统 | 寻访令品质（普通/优秀/稀有/传说）与伙伴品质对齐 | 无 |
| 经济系统 | 寻访令独立货币，不与银两挂钩 | 无 |
| 资质宝物获取线 | 弟子可用资质宝物提升（+30 上限） | 无 |
| 商业化口径 | 不卖数值/不做付费加速 | 无（硬约束） |

## 九、设计要点

- 寻访令仅刷怪获取：是"不卖数值"的硬边界，保证付费玩家与免费玩家在同一规则下获取弟子。
- 池内 NPC 带传记：抽卡不是"抽数值"，是"抽江湖故事"——招募落魄世家子弟可能触发家产支线，让抽卡有叙事钩子。
- 保底只保资质不保天赋：防"完美弟子"量产，天赋档仍随机，保留"看天赋用人"的决策张力。
- 弟子=Character 底座：招募的通神资质弟子理论上能养到宗师，比伙伴更强——高自由度的数值基础。
- 越级打怪高回报越级惩罚：防"刷初始区"，鼓励探索高难区域。
