# 抽卡与寻访令

## 抽卡资源

专属**寻访令**，不能用游戏内货币抽。

## 获取方式

刷怪获取。

## 寻访令品质

| 品质 | 影响出好伙伴概率 |
|------|------------------|
| 普通 | 低 |
| 优秀 | 中 |
| 稀有 | 高 |
| 传说 | 最高 |

## 掉落规则

| 怪物类型 | 掉落品质 |
|----------|----------|
| 普通怪 | 普通令 |
| 精英怪 | 优秀/稀有令 |
| BOSS | 传说令 |

- 怪越强掉率越高
- 普通怪也有极小概率掉传说令

## 越级加成

| 等级差 | 加成 |
|--------|------|
| 高 1～3 级 | 小幅加成 |
| 高 4～6 级 | 中幅加成 |
| 高 7 级以上 | 大幅加成 |

> 打低等级怪，经验和爆率减少。
