# 任务系统

## 任务类型

| 类型 | 说明 |
|------|------|
| 阶段目标 | 主线推进目标 |
| 支线故事 | 独立支线剧情 |
| 势力任务 | 各势力专属任务 |
| 随机奇遇 | 探索触发，以探索奇遇为主 |
| 悬赏任务 | 赏金任务 |

## 随机奇遇触发

**地点是基础，条件决定触发什么。**

触发条件因素：
- 声望
- 伙伴
- 天气
- 时间

## 奇遇玩法

- 做选择
- 打一场
- 解小谜题

## 选择影响

| 层级 | 影响 |
|------|------|
| 小选择 | 影响 NPC 态度和对话 |
| 中等选择 | 影响声望和势力好感度 |
| 大选择 | 影响后续支线和结局 |

## 任务奖励

经验、银两、装备武功、寻访令、好感声望、图鉴成就。

## 时间限制

- 部分任务限时——紧急任务限时，普通任务不限时

## 任务失败

- 不是死路，会触发另一种剧情，走向另一条路

## 任务日志

- 分类 + 地图标记 + 追踪引导

## 导航原则

- **拒绝自动寻路**，只给大致区域标记
- 具体要自己找，寻找过程中可能触发奇遇
- 隐藏任务发现：靠 NPC 对话/江湖传闻 + 探索为主，系统只做辅助
