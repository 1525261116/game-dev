# 门派战系统

> **定位**：门派战是"江湖恩怨"的终极解决方式——当外交（友好值/仇恨值）走到尽头，便刀剑相向。它是门派养成的外交出口，也是获取敌对门派武学/装备的关键途径，更是"踢馆/护派"这类武侠经典爽点的系统化承载。
>
> **关联**：门派养成 §七 外交 / §八 门派战骨架；战斗系统（九宫格/编队/阵法）；装备系统（战利掉落）；经济系统（战后赔偿）；角色系统（参战配置）；势力框架（五大势力仇恨）。

---

## 一、核心循环

> 门派战不是独立玩法，而是外交的延伸——"谈不拢就打"。

**循环**：外交积累（友好/仇恨）→ 仇恨达阈值 → 宣战/来犯 → 门派战 → 战后结算（声望/战利品/赔偿）→ 外交重置

| 阶段 | 行为 |
|------|------|
| 外交期 | 互动/任务/礼物改变友好值与仇恨值 |
| 临界期 | 仇恨值达阈值，可主动宣战；或对方主动来犯 |
| 战斗期 | 门派战（群战）或踢馆（单挑/小队） |
| 结算期 | 战利品掉落 + 声望变动 + 友好/仇恨重置 |

---

## 二、触发条件

### 2.1 主动宣战

| 条件 | 说明 |
|------|------|
| 仇恨值 ≥ 500 | 对目标门派仇恨值达阈值，可主动宣战 |
| 门派等级 ≥ 2 | 自创门派需达 2 级（有基本战力） |
| 弟子 ≥ 5 名 | 参战需最低兵力（含主角+伙伴+弟子） |
| 冷却期 | 宣战后 30 游戏日内不可再对该门派宣战（防刷） |

### 2.2 被动来犯

| 触发 | 说明 |
|------|------|
| 对方仇恨值满 | 敌对门派仇恨值对你达 500，概率主动来犯 |
| 剧情触发 | 主线阶段 3-4 凌云阁/守境司主动来犯 |
| 随机来犯 | 门派声望高+有敌对门派，每 100 游戏日概率来犯一次 |

### 2.3 踢馆（上门挑战）

> 不需宣战，直接单挑/小队挑战对方高手，是"低风险高回报"的试探手段。

| 条件 | 说明 |
|------|------|
| 无需仇恨值 | 任何时候可踢馆（但会+仇恨） |
| 单挑/小队 | 主角 1 人 或 主角+3 伙伴 |
| 对方应战 | 对方派同等级 1~4 人应战 |
| 失败惩罚 | 踢馆失败，主角重伤+声望-50+对方仇恨+100 |

---

## 三、参战配置

### 3.1 门派战（群战）

> 对齐战斗系统九宫格，上阵人数成长 3→4→5（门派战 6）。

| 项 | 规则 |
|----|------|
| 己方上阵 | 主角 + 2~3 伙伴 + 2~3 战斗型弟子 = 5~6 人 |
| 编队系数 | 人数 ÷ 4（5 人 1.25 / 6 人 1.5） |
| 阵法 | 需装备阵法（12 阵法可选），站位不符则部分/不生效 |
| 弟子境界限制 | 弟子境界低于武者五境不可上阵（防送死） |
| 预备队 | 门派战可有 2~3 名预备弟子，阵亡后轮换 |

### 3.2 对方门派配置

| 门派规模 | 对方参战 | 强度 |
|----------|----------|------|
| 小门派 | 3~4 人（弟子+长老） | 武者~后天 |
| 中门派 | 4~5 人（长老+精英） | 后天~先天 |
| 大门派 | 5~6 人（长老+掌门） | 先天~宗师 |
| 守境司 | 6 人（护法+无相） | 宗师~武侠之巅 |

### 3.3 踢馆配置

| 形式 | 己方 | 对方 |
|------|------|------|
| 单挑 | 主角 1 人 | 对方 1 人（同境界） |
| 小队 | 主角 + 3 伙伴 | 对方 4 人（精英~长老） |

---

## 四、战斗形式

### 4.1 门派战流程

| 阶段 | 说明 |
|------|------|
| 战前布阵 | 选阵法+站位+上阵弟子+预备队 |
| 第一波 | 对方弟子 vs 己方（消耗战） |
| 第二波 | 对方精英/长老 vs 己方（残血） |
| 决战 | 对方掌门/长老 vs 己方主力 |
| 结算 | 胜负判定+战利品+声望 |

> 门派战是连续多波战斗，考验的是门派整体战力深度，非主角一人之力。预备队轮换是关键——主力残血时换预备队顶上。

### 4.2 踢馆流程

| 阶段 | 说明 |
|------|------|
| 战前 | 选主角/小队配置 |
| 应战 | 对方派同等级 1~4 人 |
| 战斗 | 九宫格战斗，单局定胜负 |
| 结算 | 胜则掉落+声望，败则重伤+声望-50 |

---

## 五、战利品掉落

### 5.1 门派战掉落表

> 击败对方弟子/长老/掌门，掉落对应装备/武学。对齐装备系统品质档。

| 击败对象 | 装备掉落 | 武学掉落 | 概率 |
|----------|----------|----------|------|
| 普通弟子 | 凡兵~利器 | 凡品功法残篇 | 30% |
| 精英弟子 | 利器~宝器 | 良品功法 | 20% |
| 长老 | 宝器~神兵 | 上品功法 | 15% |
| 掌门 | 神兵~传世 | 极品~绝世功法 | 10% |
| 镇派绝学 | — | 绝世功法（镇派） | 击败掌门 100% |

> 镇派绝学是门派战的核心奖励——击败掌门必掉该门派镇派武学，这是"爆技能"爽点的系统化承载。

### 5.2 各门派镇派武学

| 门派 | 镇派武学 | 品质 | 击败掌门 |
|------|----------|------|----------|
| 六扇门 | 六扇追魂刀 | 极品 | 展雄风 |
| 凌云阁 | 凌云九剑 | 绝世 | 白慕寒 |
| 幽月教 | 幽月天魔舞 | 绝世 | 夜裳 |
| 丐帮 | 降龙十八掌 | 绝世 | 洪七公 |
| 守境司 | 河图洛书 | 绝世 | 无相 |

> 镇派武学不可通过兑换获取（武学兑换系统只到极品），只能门派战击败掌门获得——这是门派战的不可替代奖励。

### 5.3 其他战利品

| 类型 | 说明 |
|------|------|
| 银两赔偿 | 战胜方可索取战败方银两（按门派规模） |
| 材料 | 对方建筑可能被破坏，掉落建材/药材 |
| 弟子俘虏 | 击败的对方弟子可俘虏（可招募/赎回换银两） |
| 据点占领 | 极端情况（仇恨值满+门派战大胜）可占领对方据点 |

## 六、战后结算

### 6.1 声望变动

| 结果 | 声望变动 |
|------|----------|
| 门派战大胜（灭对方主力） | +200 |
| 门派战小胜（击败掌门） | +100 |
| 门派战惨胜（残血胜） | +50 |
| 踢馆胜 | +30 |
| 门派战败 | -100 |
| 踢馆败 | -50 |

### 6.2 外交重置

| 结果 | 友好/仇恨变动 |
|------|----------------|
| 门派战胜 | 对方仇恨清零→中立（被迫认输） |
| 门派战败 | 己方声望暴跌，对方仇恨维持 |
| 踢馆胜 | 对方仇恨+50（被挑衅） |
| 踢馆败 | 对方仇恨-20（看你弱者） |

> 门派战大胜可"打服"对方，仇恨清零转中立——这是"以战止战"的外交逻辑。

## 七、门派防守

> 被动来犯时的防守机制。

| 项 | 规则 |
|----|------|
| 预警 | 来犯前 1 游戏日预警，可备战 |
| 防守配置 | 主角+伙伴+弟子（同门派战） |
| 阵法加成 | 防守方阵法加成 ×1.2（主场优势） |
| 建筑防御 | 部分建筑提供防御加成（如练功房+弟子战力） |
| 失败惩罚 | 防守失败，据点被破坏+声望-150+银两被掠 |
| 求援 | 友好门派（友好值≥500）可概率派弟子来援 |

## 九、设计要点

- 门派战是外交的延伸：不是独立玩法，"谈不拢才打"——仇恨值阈值设计强迫玩家先尝试外交。
- 镇派绝学不可兑换：门派战击败掌门必掉镇派武学，这是"爆技能"爽点，也是门派战的不可替代奖励。
- 预备队轮换是关键：门派战是多波消耗战，考验门派整体战力深度，非主角一人之力——强迫玩家培养弟子梯队。
- 踢馆低风险高回报但有惩罚：失败重伤+声望-50，防"无脑踢馆"。
- 防守主场优势：阵法 ×1.2，鼓励玩家经营据点防御。
- "打服"逻辑：门派战大胜清零仇恨转中立，体现"以战止战"的江湖逻辑。
