## 一、设计目标与口径

### 1.1 一句话定位

> **地点是基础，条件决定触发什么，选择决定走向何方。**

奇遇是任务系统中最核心的体验——玩家靠探索发现、靠选择塑造江湖，错过就错过（真实有遗憾），鼓励多周目。

### 1.2 设计原则（保留并细化）

| 原则 | 说明 |
|------|------|
| 拒绝自动寻路 | 只给大致区域标记，具体要自己找 |
| 寻找中触发其他 | 探索过程中可能连锁触发其他奇遇 |
| 隐藏任务发现 | 靠 NPC 对话 / 江湖传闻 + 探索为主，系统只做辅助 |
| 时间限制 | 部分任务限时（紧急任务限时，普通不限时） |
| 失败不是死路 | 任务失败会触发另一种剧情，走向另一条路 |
| 错过就错过 | 真实有遗憾，鼓励多周目；不影响下一阶段推进 |

## 二、奇遇分类（5 类）

| 类型 | 定位 | 触发重心 | 奖励重心 | 占比（设计基准） |
|------|------|----------|----------|------------------|
| **探索奇遇** | 地点驱动的发现 | 地点 + 福缘 + 声望 | 经验、银两、材料、功法残卷 | 50% |
| **伙伴奇遇** | 携带特定伙伴触发 | 伙伴 + 地点 | 伙伴好感、专属对话、隐藏被动 | 20% |
| **势力奇遇** | 与门派关系触发 | 势力友好值/仇恨值 + 声望 | 武学兑换、势力情报、门派战契机 | 15% |
| **隐藏奇遇** | 极难发现的高价值 | 福缘 + 隐藏条件 | 资质宝物、绝世功法、隐藏结局线索 | 10% |
| **限时奇遇** | 紧急事件 | 时间窗 + 地点 | 高额奖励、关键剧情 | 5% |

> **设计意图**：探索奇遇占主体（50%），保证"到处逛都有惊喜"；伙伴奇遇强化养成牵引；势力奇遇把外交系统接入探索；隐藏奇遇对应资质宝物投放点；限时奇遇制造紧迫感。

## 三、EncounterEvent 数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 奇遇唯一标识 |
| type | explore / companion / faction / hidden / timed | 奇遇类型 |
| region | 区域枚举 | 中原洛阳 / 江南杭州 / 巴蜀成都 / 东南泉州 / 西北幽州 / 跨区域 |
| stage | 1~5 | 可触发的阶段（部分跨阶段） |
| triggers | TriggerCondition[] | 触发条件数组（见 §四） |
| choices | Choice[] | 选择项（见 §五） |
| rewards | Reward[] | 奖励表（见 §六） |
| npcHooks | string[] | 关联的 NPC id（可触发关系事件） |
| timeLimit | number / null | 限时秒数（仅 timed 类型） |
| oncePerSave | boolean | 是否单周目一次 |
| desc | string | 叙述文本（江湖风） |

### TriggerCondition 触发条件

| 字段 | 类型 | 说明 |
|------|------|------|
| kind | location / reputation / companion / weather / time / fortune / faction | 条件类型 |
| value | 条件值 | 地点 id / 声望等级 / 伙伴 id / 天气 / 时段 / 福缘阈值 / 势力友好值 |
| op | ≥ / = / ≤ | 比较运算 |

> 触发判定：所有 triggers 条件**同时满足**才触发（AND 逻辑）；部分奇遇支持多组条件（OR）。

## 四、触发条件矩阵

> 六维触发因素，地点是基础，其余决定触发什么。

| 维度 | 取值 | 说明 |
|------|------|------|
| **地点** | 五大区域 + 子地点 | 玩家到达某地点是触发基础 |
| **声望** | 0 无名 / 1 小有名气(100) / 2 名动一方(500) / 3 威震武林(2000) / 4 天下无双(10000) | 对齐成长曲线 §三 |
| **伙伴** | 携带特定伙伴 | 谢九 / 陆青崖 / 月无瑕 / 周铁山 / 寻访弟子 |
| **天气** | 晴 / 雨 / 雪 / 雾 / 夜 | 影响奇遇类型（雨夜西湖 vs 晴日青城） |
| **时间** | 昼 / 夜 / 晨 / 暮 | 部分奇遇仅夜间触发 |
| **福缘** | 0~100 | 隐藏属性，影响隐藏奇遇触发概率 |

### 触发条件示例

| 奇遇 | 触发条件 |
|------|----------|
| 破庙遗方（阶段1） | 地点=洛阳破庙 + 谢九任务完成 + 时段=任意 |
| 西湖夜雨（阶段2） | 地点=杭州西湖 + 声望≥1 + 天气=雨夜 |
| 青城遗刻（阶段2） | 地点=青城山 + 福缘≥40 |
| 海港古船（阶段3） | 地点=泉州海港 + 伙伴=月无瑕或陆青崖 |
| 边塞古墓（阶段4） | 地点=幽州边塞 + 声望≥3 |

> 与资质宝物获取线对齐：上表 5 个奇遇对应洗髓丹 / 通灵丹投放点。

## 五、奇遇玩法与选择影响

### 5.1 三种玩法

| 玩法 | 说明 | 典型场景 |
|------|------|----------|
| 做选择 | 多分支对话选择 | 救不救某人、信不信情报 |
| 打一场 | 战斗（单挑 / 小队） | 歼灭山贼、切磋高手 |
| 解小谜题 | 简单解谜 | 拼合残卷、开机关 |

### 5.2 选择影响层级（细化）

| 层级 | 影响范围 | 示例 |
|------|----------|------|
| 小选择 | NPC 态度和对话 | 帮老翁挑水→老翁态度变好、透露传闻 |
| 中等选择 | 声望和势力好感度 | 救下某门派弟子→该门派友好值 +20 |
| 大选择 | 后续支线和结局 | 杀 / 放某关键 NPC→解锁 / 关闭支线、影响结局判定 |

### 5.3 Choice 选择项结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 选择项 id |
| text | string | 选项文本 |
| requires | 条件 | 解锁该选项的条件（如好感≥信任） |
| outcomes | Outcome[] | 选择后果 |
| flags | 标签集 | 是否关键节点、是否影响结局 |

### 5.4 Outcome 后果结构

| 字段 | 类型 | 说明 |
|------|------|------|
| delta | 变更包 | 声望 / 好感 / 势力值 / morality / NPC 关系 |
| rewards | 奖励引用 | 触发的奖励 |
| nextEncounter | string | 连锁触发的下一奇遇 id |
| npcEvent | string | 触发的 NPC 关系事件（feud/grace/betray 等） |

## 六、奇遇奖励表

| 奖励类型 | 产出 | 说明 |
|----------|------|------|
| 经验 | 角色经验 | 提升等级（武者境） |
| 银两 | 货币 | 对齐经济系统 |
| 装备 | 武器 / 防具 | 对齐装备系统 |
| 功法残卷 | 可拼合的功法碎片 | 集齐可习得功法（source=奇遇偶得） |
| 资质宝物 | 洗髓丹 / 通灵丹 / 天元丹 | 对齐资质宝物获取线（隐藏奇遇为主） |
| 声望 | 声望值 | 提升江湖名望 |
| 好感度 | 伙伴好感 | 提升伙伴关系 |
| 关系事件 | NPC lifeEvent | 触发 NPC 关系网事件 |
| 情报 | 主线查案线索 | 推进查案（探索奇遇特产） |

### 奖励稀有度对应阶段

| 阶段 | 常见奖励 | 稀有奖励 |
|------|----------|----------|
| 阶段1 | 经验、银两、凡品装备 | 凡品功法残卷 |
| 阶段2 | 良品装备、材料 | 良品功法、洗髓丹（探索奇遇） |
| 阶段3 | 上品装备、势力情报 | 上品功法、通灵丹（隐藏奇遇） |
| 阶段4 | 极品装备、门派战契机 | 极品功法、通灵丹（隐藏奇遇） |
| 阶段5 | 绝品装备、结局线索 | 天元丹、绝世功法、隐藏结局 |

## 七、与角色系统对接

### 7.1 奇遇触发 NPC 关系事件

> 奇遇的 npcHooks 字段可触发关系网事件，插入双方 lifeEvents。

| 奇遇场景 | 触发的关系事件 | 机制 |
|----------|----------------|------|
| 救下某 NPC 的师父 | grace 事件，师徒关系 strength+ | 对齐关系网 §四 救其师 |
| 击败某 NPC 的宿敌 | feud resolved，宿敌 status→broken | 对齐关系网 §四 杀其敌 |
| 在两同门间传话 | 同门关系 strength 变化 | 对齐关系网 §四 离间同门 |
| 撮合情缘 | bondmate 关系 strength+ | 对齐关系网 §四 成其缘 |

### 7.2 奇遇获取资质宝物

> 隐藏奇遇是资质宝物的主要来源之一（对齐资质宝物获取线 §二~§四）。

| 宝物 | 奇遇类型 | 阶段 | 示例投放点 |
|------|----------|------|------------|
| 洗髓丹 | 探索 / 隐藏 | 1~4 | 破庙遗方、西湖夜雨、青城遗刻、海港古船、边塞古墓 |
| 通灵丹 | 隐藏 | 2~5 | 青城深处、秘境至宝 |
| 天元丹 | 隐藏 | 4~5 | 秘境核心（剧情关键节点） |

### 7.3 奇遇获取跨门派功法

> 奇遇偶得是跨门派功法六条路径之一（角色通用模型 §7.1）。

| 奇遇场景 | 所得功法 | source 标签 |
|----------|----------|-------------|
| 洞府遗刻拼合 | 上品 / 极品功法 | 奇遇偶得 |
| 残卷收集集齐 | 凡 ~ 绝（稀有） | 奇遇偶得 |
| 击败隐藏 BOSS | 继承对方所持 | 杀人夺宝 |

## 八、奇遇库组织（按区域 × 阶段）

> 奇遇按"区域 + 阶段"二维组织，每区域每阶段有基准奇遇数。

### 8.1 奇遇密度基准

| 阶段 | 每区域奇遇数 | 跨区域奇遇 | 全阶段合计 |
|------|--------------|------------|------------|
| 阶段1 | 3~5 | 1~2 | ~20 |
| 阶段2 | 4~6 | 2~3 | ~30 |
| 阶段3 | 5~7 | 3~4 | ~40 |
| 阶段4 | 4~6 | 3~4 | ~35 |
| 阶段5 | 3~5 | 2~3 | ~25 |
| **合计** | — | — | **~150** |

> **设计意图**：~150 个奇遇保证多周目探索的丰富感；阶段3 最密集（门派经营期，玩家活动范围最大）；阶段5 收束（聚焦结局）。

### 8.2 五区域奇遇特色

| 区域 | 奇遇特色 | 典型奇遇 |
|------|----------|----------|
| 中原洛阳 | 新手引导、市井传闻 | 破庙遗方、追兵首战、洛阳传闻 |
| 江南杭州 | 文人雅集、夜雨江湖 | 西湖夜雨、灵隐寺问禅、丝绸商路 |
| 巴蜀成都 | 道家遗刻、山险秘境 | 青城遗刻、青城深处、峨眉云海 |
| 东南泉州 | 海港古船、商旅奇遇 | 海港古船、番邦秘宝、海市蜃楼 |
| 西北幽州 | 边塞古墓、塞外豪情 | 边塞古墓、大漠孤烟、幽州铁骑 |
