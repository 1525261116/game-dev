# 结局设计总览

## 结局数量

**6 种结局**，由「最终抉择 + 声望好感 + 关键支线 + 门派成果」叠加决定。

## 结局决定因素

| 因素 | 说明 |
|------|------|
| 最终抉择 | 复仇 / 救人 / 系统真相（阶段5 关键抉择） |
| 声望和势力好感度 | 累积的江湖声望和各势力友好/仇恨值 |
| 关键支线做没做 | 特定支线（是否救下特定 NPC、是否完成关键奇遇） |
| 门派经营成果 | 门派等级、弟子、是否开宗立派成功 |

## 六大结局

| # | 结局 | 触发倾向 | 描述 |
|---|------|----------|------|
| 1 | **血债血偿**（复仇） | 最终选「复仇」+ 高仇恨/低侠义 | 手刃无相、以血还血，妹妹可能牺牲，主角成孤家寡人的武林传说 |
| 2 | **侠之大者**（救人） | 最终选「救人」+ 高侠义/高正派好感 | 救下妹妹、守护苍生，主角成一代大侠，受天下敬仰 |
| 3 | **归隐田园**（放下） | 最终选「放下/救人」+ 高经营成果 | 放下仇恨，与妹妹归隐，经营门派成一方乐土 |
| 4 | **天下无双**（宗师） | 高声望 + 高门派成果 + 开宗立派成功 | 登上武林之巅，自创门派成武林第一宗，主角成一代宗师 |
| 5 | **真相觉醒**（系统真相） | 最终选「系统真相」+ 关键奇遇完成 | 直面穿越者系统来历，揭示「回归现实」或「留在江湖」的选择 |
| 6 | **江湖之外**（隐藏） | 特殊条件（隐藏支线全完成） | 隐藏结局，揭示世界的终极真相 |

## 结局判定流程

```
阶段5 最终抉择（复仇/救人/系统真相）
        ↓
叠加：声望好感 + 关键支线 + 门派成果
        ↓
判定落入六大结局之一
```

## 图鉴和成就

- 永久保留
- 重开也能获取已有图鉴/成就的奖励

## 多周目结局

- 不同周目触发不同支线，导向不同结局
- 剧情略微改动，增加重玩价值
- 多周目可尝试不同门派路线（不同外交、不同门派武学流派）
