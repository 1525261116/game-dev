## 一、设计目标与口径

### 1.1 一句话定位

> **六大结局，由「最终抉择 + 声望好感 + 关键支线 + 门派成果」叠加决定，错过就错过，鼓励多周目。**

### 1.2 口径来源（已定案）

| 项 | 定案 | 来源 |
|----|------|------|
| 结局数量 | 6 种 | 结局总览 |
| 决定因素 | 最终抉择 + 声望好感 + 关键支线 + 门派成果 | 结局总览 |
| 多周目 | 什么都不继承，但增加玩家天赋；剧情略微改动 | 主线总览 |
| 图鉴成就 | 永久保留，重开可获取已有奖励 | 主线总览 / 结局总览 |
| 错过机制 | 错过就错过，真实有遗憾，不影响下一阶段 | 主线总览 |

## 二、六大结局触发条件量化

> 把总览的定性描述量化为可判定的阈值。

### 2.1 结局1：血债血偿（复仇）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 最终抉择 | 选「复仇」 | 阶段5 关键抉择 |
| 正邪值 | ≤ 0（亦正亦邪 / 魔道） | 复仇执念压倒侠义 |
| 林小满状态 | 可能牺牲 | 若未完成救妹支线 |
| 妹妹存活 | 不要求 | 复仇高于救人 |

**结局描述**：手刃无相、以血还血，妹妹可能牺牲，主角成孤家寡人的武林传说。

### 2.2 结局2：侠之大者（救人）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 最终抉择 | 选「救人」 | 阶段5 关键抉择 |
| 正邪值 | ≥ +200（侠义道） | 行侠仗义累积 |
| 正派势力好感 | 凌云阁 / 六扇门友好值 ≥ +60（同盟） | 正派认可 |
| 林小满状态 | 存活 | 完成救妹支线 |

**结局描述**：救下妹妹、守护苍生，主角成一代大侠，受天下敬仰。

### 2.3 结局3：归隐田园（放下）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 最终抉择 | 选「放下」或「救人」 | 放下仇恨 |
| 门派等级 | ≥ 3 级 | 经营有成正果 |
| 门派弟子数 | ≥ 10 人 | 门派成一方势力 |
| 正邪值 | ≥ 0（非魔道） | 无大恶 |

**结局描述**：放下仇恨，与妹妹归隐，经营门派成一方乐土。

### 2.4 结局4：天下无双（宗师）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 声望 | ≥ 10000（天下无双） | 威震天下 |
| 门派等级 | ≥ 3 级 | 开宗立派成功 |
| 主角境界 | ≥ 宗师圆满 | 武学巅峰 |
| 正邪值 | 不限 | 名望压倒道德倾向 |

**结局描述**：登上武林之巅，自创门派成武林第一宗，主角成一代宗师。

### 2.5 结局5：真相觉醒（系统真相）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 最终抉择 | 选「系统真相」 | 阶段5 关键抉择 |
| 关键奇遇 | 穿越者系统奇遇链完成 | 揭示系统来历 |
| 秘境核心 | 探索完成 | 阶段4-5 秘境 |
| 福缘 | ≥ 70 | 触发隐藏线索 |

**结局描述**：直面穿越者系统来历，揭示「回归现实」或「留在江湖」的选择。

### 2.6 结局6：江湖之外（隐藏）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 隐藏支线 | 全部完成 | 极难 |
| 关键 NPC | 特定 NPC 全存活 | 无重大死亡 |
| 福缘 | ≥ 90 | 接近满值 |
| 多周目 | ≥ 2 周目 | 第二周目起可触发 |

**结局描述**：隐藏结局，揭示世界的终极真相。

## 三、结局判定算法

### 3.1 判定流程

| 步骤 | 规则 |
|------|------|
| 1 | 阶段5 最终抉择（复仇 / 救人 / 系统真相 / 放下） |
| 2 | 叠加声望好感 + 关键支线 + 门派成果 |
| 3 | 按下表权重计算各结局得分 |
| 4 | 取得分最高且满足硬性条件的结局 |
| 5 | 若多个并列，按优先级：隐藏 > 系统真相 > 天下无双 > 侠之大者 > 归隐 > 血债 |

### 3.2 结局得分公式

**公式**：结局得分 = 最终抉择匹配 × 0.5 + 声望好感匹配 × 0.3 + 关键支线匹配 × 0.15 + 门派成果匹配 × 0.05

| 结局 | 抉择匹配 | 声望好感匹配 | 支线匹配 | 门派匹配 |
|------|----------|--------------|----------|----------|
| 血债血偿 | 复仇=1 | 正邪≤0 得分高 | 复仇支线 | 不要求 |
| 侠之大者 | 救人=1 | 正派好感高、正邪≥+200 | 救妹支线 | 不要求 |
| 归隐田园 | 放下/救人=1 | 正邪≥0 | 门派经营支线 | 门派≥3级+弟子≥10 |
| 天下无双 | 任意 | 声望≥10000 | 武学巅峰支线 | 门派≥3级 |
| 真相觉醒 | 系统真相=1 | 福缘≥70 | 系统奇遇链 | 不要求 |
| 江湖之外 | 任意 | 福缘≥90+多周目 | 隐藏支线全 | 关键NPC全存活 |

### 3.3 硬性条件（不满足直接排除）

> 部分结局有硬性门槛，不满足则即使得分最高也不触发。

| 结局 | 硬性条件 |
|------|----------|
| 侠之大者 | 林小满存活 + 正邪≥+200 |
| 天下无双 | 声望≥10000 + 主角境界≥宗师圆满 |
| 真相觉醒 | 系统奇遇链完成 + 秘境核心探索完成 |
| 江湖之外 | 隐藏支线全完成 + 多周目≥2 |

## 四、多周目机制

### 4.1 不继承 vs 继承

| 项 | 规则 | 来源 |
|----|------|------|
| 角色数值 | 不继承 | 主线总览 |
| 门派 / 弟子 | 不继承 | 主线总览 |
| 物品 / 银两 | 不继承 | 主线总览 |
| **玩家天赋** | **继承（增加）** | 主线总览 |
| **图鉴成就** | **永久保留** | 主线总览 / 结局总览 |
| 已触发结局记录 | 永久保留 | 本设计补充 |

### 4.2 多周目剧情变化

| 变化 | 说明 |
|------|------|
| 支线微调 | 不同周目触发不同支线，导向不同结局 |
| 门派路线 | 多周目可尝试不同外交 / 门派武学流派 |
| 隐藏内容 | 部分隐藏奇遇 / 结局需多周目解锁（如结局6） |
| NPC 变体 | 多周目变体角色（如陆青崖可倒向主角或敌人） |

### 4.3 玩家天赋继承

> 每完成一个周目，玩家可获得一个永久天赋（下一周目可选）。

| 周目数 | 解锁天赋 | 效果 |
|--------|----------|------|
| 1 周目完成 | 悟性通神（门槛×0.8） | 已有，开局可选 |
| 2 周目完成 | 福缘 +20 | 隐藏奇遇更易触发 |
| 3 周目完成 | 起始银两 ×2 | 经济起步快 |
| 4+ 周目 | 自选 1 个已通关结局的专属天赋 | 个性化 |

## 五、与 NPC 关系系统对接

### 5.1 关键 NPC 存活影响结局

> NPC 的生死是结局判定的关键支线条件。

| NPC | 影响结局 | 机制 |
|----|----------|------|
| 林小满 | 侠之大者（需存活）/ 血债血偿（可牺牲） | 救妹支线决定 |
| 谢九 | 侠之大者 / 归隐（若牺牲则加悲剧色彩） | 阶段5 救主剧情 |
| 陆青崖 | 多结局分支 | 倒向主角→侠线；倒向凌云阁→复仇线变量 |
| 月无瑕 | 真相觉醒（幽月教秘境线索） | 结盟后揭示秘境 |
| 周铁山 | 侠之大者（六扇门官方助力） | 转正后提供官方支持 |
| 无相 | 所有结局（必须击败） | 阶段5 最终决战 |

### 5.2 关系网对结局的涟漪

| 关系状态 | 结局影响 |
|----------|----------|
| 月无瑕与周铁山宿敌 | 若同时入队未调解→队内崩裂→影响救妹支线 |
| 陆青崖与凌云阁掌门同门→宿敌 | 倒向主角→凌云阁裂缝→侠线；否则→复仇线 |
| 谢九与幽月教宿敌 | 若玩家与幽月教结盟→谢九离队→失去引路人 |

> **设计意图**：关系网不是孤立的人际装饰，而是结局判定的隐性变量——玩家维护的关系会影响结局可达性，制造"人情债"的叙事重量。

## 六、结局图鉴与成就

### 6.1 图鉴永久保留

| 图鉴类型 | 内容 |
|----------|------|
| 结局图鉴 | 已触发的结局记录（含达成条件） |
| 奇遇图鉴 | 已发现的奇遇记录 |
| NPC 图鉴 | 已交互的关键 NPC 记录 |
| 武学图鉴 | 已习得的功法记录 |
| 势力图鉴 | 各势力友好 / 仇恨值峰值记录 |

### 6.2 成就奖励

| 成就 | 奖励 |
|------|------|
| 全结局达成 | 专属称号 + 玩家天赋 |
| 全奇遇发现 | 探索者天赋（福缘 +30） |
| 全 NPC 交互 | 江湖通天赋（情报 +50%） |
| 全武学收集 | 武学宗师天赋（功法经验 +50%） |
