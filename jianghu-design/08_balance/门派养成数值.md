# 门派养成数值规则

> 本文件细化 `06_systems/门派养成.md` 的数值规则，供后续数值策划与实现参考。所有数值为初始设计，需平衡调优。

---

## 一、友好值 / 仇恨值系统

### 数值范围与关系等级

| 数值区间 | 关系等级 | 可用行为 |
|----------|----------|----------|
| -100 ~ -60 | 死敌 | 可开战、可踢馆 |
| -60 ~ -20 | 敌对 | 敌对状态，对方会主动攻击 |
| -20 ~ +20 | 中立 | 正常往来 |
| +20 ~ +60 | 友好 | 解锁武学兑换、贸易 |
| +60 ~ +100 | 同盟 | 可结盟、情报共享 |

### 数值增减来源

| 行为 | 变化量 |
|------|--------|
| 对话选择（普通） | ±1 ~ ±5 |
| 剧情关键抉择 | ±10 ~ ±30 |
| 完成委托任务 | +5 ~ +20 |
| 礼物赠送 | +5 ~ +30（视礼物品质） |
| 门派人情往来 | +5 ~ +15 |
| 得罪对方（伤害其弟子/破坏其利益） | -10 ~ -40 |
| 主动开战 / 踢馆 | 直接降至 -60 以下（死敌） |

### 设计要点

- 友好值与仇恨值**独立计算**，不简单对冲——帮过你的人不会因为你之后敌对就忘记你帮过他
- 势力关系影响：招募、兑换、贸易、结盟、剧情分支
- 关键抉择（阶段3-5）对势力关系的影响是长期且不可逆的

## 二、武学兑换系统

### 兑换条件

- 目标门派友好值 ≥ +20（友好）
- 持有可兑换物品（特产/材料/丹药/酒）

### 武学品质与兑换消耗

| 品质 | 兑换所需物品价值（约） | 说明 |
|------|------------------------|------|
| 普通 | 100 ~ 300 | 基础招式 |
| 优秀 | 500 ~ 1200 | 进阶招式 |
| 稀有 | 2000 ~ 5000 | 门派特色武学 |
| 传说 | 10000+ | 镇派绝学（仅限同盟） |

### 兑换物品折算

| 物品类型 | 价值基准 |
|----------|----------|
| 特产 | 100 ~ 500 / 个 |
| 材料 | 50 ~ 300 / 个 |
| 丹药 | 200 ~ 2000 / 颗（视品质） |
| 酒 | 100 ~ 1000 / 坛（视品质） |

### 门派武学特色

| 门派 | 武学特色 |
|------|----------|
| 凌云阁 | 剑法（青崖剑法、凌云九剑等） |
| 幽月教 | 暗杀/身法类 |
| 六扇门 | 刀法/缉捕类 |
| 江湖散人（丐帮） | 拳掌/棍法 |

## 三、门派战系统

### 开战条件

- 目标门派仇恨值 ≤ -60（死敌）
- 主角门派等级达到要求
- 拥有足够战斗型弟子

### 战斗形式

| 形式 | 规则 |
|------|------|
| 门派群战 | 主角带队 + 战斗型弟子（最多 5 人）vs 对方门派弟子 |
| 上门踢馆 | 单挑/小队挑战对方高手，逐级挑战 |

### 战利掉落

| 击败目标 | 掉落 |
|----------|------|
| 普通弟子 | 对应门派普通装备/技能 |
| 精英弟子 | 优秀/稀有装备/技能 |
| 长老/掌门 | 门派核心武学、稀有装备 |

### 胜负影响

- 胜：对方仇恨值变化，门派声望提升，掉落战利品
- 负：门派损失弟子/资源，声望下降

## 四、弟子天赋系统

### 天赋类型与加成

| 天赋类型 | 擅长 | 数值加成（基准） |
|----------|------|------------------|
| 战斗天赋 | 入队战斗 | 伤害 +20%，血量 +15% |
| 炼丹天赋 | 炼丹 | 成功率 +20%，品质 +1 级 |
| 种植天赋 | 种植 | 产量 +30%，成长时间 -20% |
| 厨艺天赋 | 做菜 | 品质 +1 级，特殊 buff 概率 +15% |
| 酿酒天赋 | 酿酒 | 品质 +1 级，特殊效果概率 +15% |
| 经营天赋 | 经营 | 商铺收益 +25%，砍价能力 +20% |
| 探索天赋 | 打探情报 | 情报获得率 +25%，线索发现 +20% |

### 天赋品质

| 品质 | 加成倍率 | 获取概率（寻访） |
|------|----------|------------------|
| 普通 | ×1.0 | 高 |
| 优秀 | ×1.3 | 中 |
| 稀有 | ×1.6 | 低 |
| 传说 | ×2.0 | 极低 |

### 设计要点

- 每名弟子 1 个主天赋 + 可能 1 个副天赋
- 玩家需「看天赋用人」，天赋与岗位匹配时收益最大化
- 高阶弟子可培养/洗练天赋（后期系统）

## 五、建筑与生产系统

### 建筑清单

| 建筑 | 解锁操作 | 建造条件 |
|------|----------|----------|
| 练功房 | 弟子修炼、传授武学 | 门派创立即解锁 |
| 丹房 | 炼丹 | 门派 1 级 |
| 药田/农田 | 种植 | 门派 1 级 |
| 厨房 | 做菜 | 门派 2 级 |
| 酒坊 | 酿酒 | 门派 2 级 |
| 商铺 | 经营（买卖） | 门派 2 级 |
| 藏经阁 | 存放/研习武学 | 门派 3 级 |

### 建筑升级

| 等级 | 效果 |
|------|------|
| 1 级 | 基础产量/品质 |
| 2 级 | 产量 +50%，解锁中级配方 |
| 3 级 | 产量 +100%，解锁高级配方，品质上限 +1 |

### 生产产物与用途

| 技能 | 产物 | 主要用途 |
|------|------|----------|
| 炼丹 | 丹药 | 回血、增益、突破、外交礼物 |
| 种植 | 药材/食材 | 炼丹/做菜原料、售卖 |
| 做菜 | 食物 | 回血、临时 buff |
| 酿酒 | 酒 | 外交礼物、临时 buff、社交 |
| 经营 | 银两/特产 | 门派经济、外交礼物 |

### 产物闭环

**产物闭环**：生产 → 以下四个去向：

| 去向 | 说明 |
|------|------|
| 自用 | 回血 / 增益 / 突破 |
| 售卖 | 门派经济 |
| 外交礼物 | 提升友好值 |
| 兑换武学 | 友好门派的硬通货 |

## 六、经济数值（简）

| 项目 | 数值基准 |
|------|----------|
| 初始资金 | 500 两 |
| 建筑建造 | 1000 ~ 5000 两 / 座（视建筑） |
| 建筑升级 | 2000 ~ 10000 两 / 级 |
| 弟子招募（寻访令） | 非货币（刷怪获取） |
| 商铺收益 | 50 ~ 500 两 / 天（视等级/经营天赋） |

> 数值均为初稿，需在实现后通过测试迭代平衡。
