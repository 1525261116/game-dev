## 0.1 本文件是什么，怎么用

本文件不是"再写一遍策划案"，而是把既有方案设计稿**收敛为可执行的生产文档**：给出唯一口径的决策、可直接落表的数值、可分配工时的工作量、可验收的完成标准。

| 用法 | 说明 |
|------|------|
| **口径仲裁** | 既有设计稿之间存在数值与命名冲突（见 0.9 冲突裁决表），本文件为**唯一执行口径**；与旧稿冲突时以本文件为准 |
| **任务拆解** | 第 4、5 章给出内容清单与工时估算，可直接转为排期表与外包需求单 |
| **验收依据** | 每个系统在第 2 章给出「验收标准（DoD）」，未达标不算完成 |
| **技术输入** | 第 3 章配置表结构 = 程序与引擎落地的数据契约；第 5 章性能与包体预算 = 引擎选型的硬约束 |

**阅读路径建议**

- 制作人 / 主策：0 → 1 → 5 章
- 系统策划：2 → 3 章
- 关卡策划：4 → 3 章
- 主程 / 技术负责人：3.2 配置表契约 → 5.6 技术预算 → 引擎选型评估报告

## 0.2 产品定位

| 项目 | 内容 |
|------|------|
| **游戏名** | 江湖从心 |
| **类型** | 武侠开放世界 + 单机 RPG（地图节点式开放世界 + 战前布阵自动战斗） |
| **核心玩法** | 探索奇遇 / 功法搭配成长 / 门派养成 |
| **视角与画风** | 2.5D 斜视角（等距），水墨江湖，宣纸白 + 墨色 + 暗金 + 朱红 |
| **平台** | 移动端（iOS / Android）+ PC（Windows / macOS，Steam + 官网直发）；主机后续评估 |
| **一周目时长** | 30～40 小时（主线 + 主要支线）；全收集 60～80 小时 |
| **难度定位** | 有挑战：需要搭配功法与装备；无损档兜底机制，不卡死 |
| **商业化** | 移动端免费下载 + 纯外观 / 剧情 / 便利付费（不卖数值）；PC 端买断 + DLC（见 0.5） |
| **目标受众** | ① 武侠题材爱好者 ② 单机开放世界探索玩家 ③ 《烟雨江湖》类玩法用户 ④ 种田 / 开店 / 收集 / 抽卡轻度玩家 |
| **一句话概述** | 穿越者带着游戏系统，从逃犯走到开宗立派，用门派作为查案复仇的根基，最终左右江湖格局。 |

### 0.2.1 竞品坐标（用于差异化判断）

| 竞品 | 相同点 | 本作差异点 |
|------|--------|------------|
| 《烟雨江湖》 | 武侠探索、门派、随从、地图节点推进 | 功法「品质 × 境界」双维度 + 起势收势连招 + 三层词条，构筑深度显著更高 |
| 《我的侠客》 | 高自由度、多结局、周目循环 | 本作不做"沙盒式重开"，改为单周目 30~40h 的强叙事 + 结局导向 |
| 《太吾绘卷》 | 深度数值、江湖生态 | 本作降低上手门槛，全公式可预测、可自行计算 |
| 《鬼谷八荒》 | 修仙养成 + 奇遇 | 本作把"门派经营"做成第二主线载体，而非旁支系统 |
| 《大侠立志传》 | 多结局、事件网 | 本作以 2.5D 斜视角 + 布阵自动战斗形成表现差异 |

**差异化三句话**：功法构筑比同类深一档；门派养成与主线强绑定（不是挂机副玩法）；穿越者系统作为叙事装置参与玩法与剧情双向反噬。

## 0.3 设计支柱与可执行判据

| # | 支柱 | 执行判据（可直接用于评审） |
|---|------|---------------------------|
| 1 | **自由优先** | ① 不做自动寻路，只给区域标记；② 同一阶段至少 3 条达成路径；③ 主线无"必须做"的支线 |
| 2 | **养成驱动** | 每次战斗产出必须落入"经验 / 银两 / 装备 / 功法 / 寻访令"中的至少 2 类；任意 30 分钟游戏时长内玩家必然获得至少 1 次可见战力提升 |
| 3 | **真实有遗憾** | 奇遇/任务存在不可逆错过；错过不阻塞阶段推进；结局由"选择 + 声望 + 正邪值 + 关键支线"四因子决定 |
| 4 | **穿越者视角** | 系统功能随剧情分级解锁；"怀疑度"是可量化状态，达到阈值触发反噬事件链 |
| 5 | **多玩法并存** | 任一玩法模块都可被玩家"最低限度维持"（一键操作）；不设体力与在线时长限制 |

## 0.4 核心体验目标与体验曲线

**四大核心体验**（承接 `01_overview/核心体验.md`）

1. 主菜：开放世界探索武侠
2. 副菜：门派养成（自创门派 → 招募弟子 → 生产 → 外交）
3. 爽点：打怪升级、爆装备、爆技能
4. 特色：自由江湖，不同选择不同结局

**体验强度曲线（设计目标，用于关卡与数值校验）**

```
体验强度
  ▲
  │                        ┌───────┐  阶段5：天下无双（终局选择 / 多结局）
  │                 ┌──────┘       │
  │          ┌──────┘  阶段4：威震武林（门派战 / 势力结盟）
  │   ┌──────┘  阶段3：名动一方（自创门派 / 开宗立派）
  │ ┌─┘  阶段2：小有名气（势力接触 / 伙伴集结）
  │─┘ 阶段1：初入江湖（逃犯开局 / 学会战斗与搭配）
  └──────────────────────────────────────────────────► 时间
   0-3h      3-8h       8-16h      16-26h      26-40h
```

| 阶段 | 时长 | 等级区间 | 声望门槛 | 体验主菜 | 情绪目标 |
|------|------|----------|----------|----------|----------|
| 阶段 1 初入江湖 | 0～3h | Lv1～10 | 0 | 战斗教学 + 首个奇遇 + 逃犯身份 | 紧张、好奇 |
| 阶段 2 小有名气 | 3～8h | Lv10～25 | 100 | 势力接触 + 伙伴招募 + 首个门派 | 归属、扩张 |
| 阶段 3 名动一方 | 8～16h | Lv25～45 | 500 | 自创门派 + 经营闭环 + 门派战 | 成就、经营快感 |
| 阶段 4 威震武林 | 16～26h | Lv45～70 | 2,000 | 势力结盟 / 仇敌对抗 | 权力、对抗 |
| 阶段 5 天下无双 | 26～40h | Lv70～100+ | 10,000 | 真相揭示 + 终局选择 + 5+ 结局 | 决断、回味 |

## 0.5 商业化设计（关键决策）

> **问题**：原方案「免费能玩，花钱买加速、外观、剧情和便利」与「单机 RPG」存在结构性矛盾——单机离线游戏没有服务器，无法做体力/挂机驱动，若再承诺"不卖数值"，则"加速"类付费几乎没有支点，纯靠外观与剧情包难以覆盖 30~40 小时内容成本。
> 本节给出裁决：**双轨定价 + 三条付费线**。

### 0.5.1 决策矩阵

| 方案 | 收入上限 | 与"不逼氪"一致性 | 合规/版号影响 | 结论 |
|------|----------|------------------|----------------|------|
| A 全平台买断（PC ¥68 / 移动 ¥28） | 中 | 高 | 低（仍建议版号） | 备选 |
| B 全平台免费 + 内购（含加速） | 高 | 低（加速=卖时间=软性卖数值） | 高（国内手游需版号） | ✗ 否决 |
| C **双轨：PC 买断 + 移动免费本体 + 纯外观/剧情/便利内购** | 中高 | 高 | 中 | ✅ **采用** |

### 0.5.2 采用方案：双轨定价

| 平台 | 本体 | 付费点 | 定价建议（人民币，首年） |
|------|------|--------|--------------------------|
| **PC（Steam / 官网）** | 买断，含全部主线 + 五大区域 | ① 外观时装包 ② 剧情 DLC（后日谈 / 支线章节）③ 原声集 + 设定集 | 本体 ¥68（首发 9 折）；外观包 ¥6～18；剧情 DLC ¥18～28 |
| **移动端（iOS / Android）** | 免费下载，**第 1 章完整免费**（约 3 小时），第 2 章起一次性解锁 | ① 一次性"江湖通行证"解锁全部主线 ② 外观时装 ③ 便利道具（自动整理、离线经营结算、图鉴提示） ④ 剧情 DLC | 通行证 ¥30～40；外观 ¥6～18；便利道具 ¥1～6；DLC ¥18 |

**付费红线（写入策划案，任何人不得突破）**

1. 不卖战斗属性、不卖修为、不卖寻访令、不卖突破成功率。
2. 不卖"限时独占"内容；所有内容最终都可通过游玩获得。
3. 便利道具只减少**重复操作**，不减少**决策与探索**（不做自动寻路付费）。
4. 无抽卡付费：寻访令 100% 由游戏内掉落产出，不可用真实货币购买。
5. 无广告（不做激励视频，避免打断单机沉浸）。

### 0.5.3 收入结构目标（首年，保守测算）

| 来源 | 占比目标 | 说明 |
|------|----------|------|
| PC 买断 | 55% | 主线销量为核心，Steam 为主要渠道 |
| 移动通行证 | 25% | 转化率按免费下载的 4%~8% 估 |
| 外观 + 剧情 DLC | 20% | 长尾收入，按 DLC 每年 1~2 个节奏 |

> 定价与分成假设、回本测算见 [第 5 章 5.5 预算与回本测算](05_生产计划与执行.md)。

## 0.6 平台与发行策略

### 0.6.1 双端定位差异

| 维度 | PC 端 | 移动端 |
|------|-------|--------|
| 定位 | 完整体验、口碑与收入主力 | 碎片化体验、拉新与长尾 |
| 单次会话 | 60～120 分钟 | 15～30 分钟 |
| 操作 | 鼠标键盘 + 手柄（可选） | 触屏（单手可玩） |
| UI | 高信息密度、多面板并排 | 大按钮、二级页面、单手拇指热区 |
| 战斗 | 支持战前布阵 + 手动大招（可选开关） | 默认全自动，仅布阵与设置 |
| 存档 | 本地 + 云存档（Steam Cloud / iCloud） | 本地 + 云存档（可选） |
| 首章 | 付费试玩 Demo（存档继承） | 完整免费 |

**共享要求**：同一份内容数据、同一套战斗逻辑、同一套存档结构（跨端互通，通过账号或存档码）。

### 0.6.2 发行路径（含版号约束）

> 中国大陆商业运营的手游与含内购的游戏需要**版号（ISBN）**，审批周期通常 6～18 个月且不可控。这是排期的一级风险项，必须前置决策。

| 路径 | 说明 | 建议 |
|------|------|------|
| **路径 1：先出海，后国内** | Steam 全球 + App Store / Google Play 海外首发（无需国内版号） | ✅ **主线路径**：先行验证口碑与收入 |
| **路径 2：国内 PC 先行** | Steam 中国区 + WeGame（PC 端无版号可上 Steam 国际版；国内平台需版号） | 视平台要求执行 |
| **路径 3：国内手游** | 需版号；建议**立项即启动申请**，与研发并行 | 备选，不阻塞出海首发 |
| **路径 4：主机** | PS / Xbox / Switch 需各平台认证，建议放在 PC 版稳定后 | 后续评估 |

**执行要求**：策划内容需从立项起就**规避审核风险**（血腥表现分级、历史人物使用、穿越题材的表述、未成年人保护相关设计），详见 [第 5 章 5.7 合规与风险](05_生产计划与执行.md)。

## 0.8 范围边界（做什么 / 不做什么）

### MVP（垂直切片必须包含）

- 完整战斗系统（九宫格布阵 + 自动结算 + 连招 + 词条 + 伤害公式全量）
- 完整养成闭环（等级 / 属性加点 / 境界突破 / 功法装备 / 装备强化）
- 1 个完整区域（中原·洛阳，含 6 个可探索场景、12 个奇遇、3 个精英、1 个 BOSS）
- 2 名可招募伙伴 + 好感度全流程
- 门派系统**框架**（可创建门派、1 类生产、1 类外交）
- 存档 / 读档 / 自动存档 / 死亡结算
- 双端可运行（PC + 1 款移动真机）

### 明确不做（首版）

| 不做项 | 原因 |
|--------|------|
| 联机 / PVP / 排行榜 | 单机定位，成本高、与设计支柱冲突 |
| 自动寻路 | 违反"自由优先"支柱 |
| 体力 / 在线时长限制 | 违反"没有体力限制，想玩多久玩多久" |
| 战力数值付费 | 违反付费红线 |
| 主机版首发 | 认证成本与人力不允许 |
| 全程语音 | 改为关键剧情配音（预算控制） |
| 随机生成开放世界 | 采用手工节点地图，保证叙事密度 |
