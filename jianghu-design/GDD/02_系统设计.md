## 2.1 S1 战斗系统

### 目标
在"战中全自动"的前提下，把策略深度前移到**战前**（布阵 / 功法顺序 / 词条 / 装备），同时保留一个可控的即时介入点。

### 规则

**1）参战与站位**

- 常规战斗：主角 + 3 伙伴 = **4 人**；门派战群战：主角 + 战斗型弟子，**最多 5 人**。
- 九宫格 3×3，编号 1~9：

```
前排(1,2,3)   承伤优先、受近战直击    刀法/拳掌/枪法/坦克
中排(4,5,6)   均衡、可进可退          剑法/均衡
后排(7,8,9)   免受近战直击、易被远程锁定 暗器/内功/治疗
```

- 敌方 AI 优先攻击**同列**单位；范围功法（如枪法横扫前排三格）会连带站位密集目标。
- **列连击**：同一列的前中后三人若外功起势/收势匹配，可跨位触发连击。

**2）出手顺序**（固定，可预测）

```
① 先手判定：比较双方（身法 + 先手加成，来自轻功/词条），高者先手
② 回合内：按场上单位身法值从高到低依次行动
③ 同身法：先手方优先 → 再按站位顺序 1→9
```

**3）单次攻击结算流程**（顺序固定，不可调整）

```
出手 → ① 命中判定 → ② 暴击判定 → ③ 伤害计算 → ④ 防御减免
     → ⑤ 增伤/减伤修正 → ⑥ 吸血结算 → ⑦ 施加状态
```

| 步骤 | 内容 |
|------|------|
| ① 命中 | `命中率 = 90% + 命中加成 − 目标闪避`，钳制 **5%~95%**；未命中即结束 |
| ② 暴击 | 概率 = 暴击率（上限 75%）；触发时伤害 ×暴击倍率（150%，上限 300%） |
| ③ 伤害 | `基础伤害 = 攻击力 + 修为差距 + 功法威力` |
| ④ 减伤 | `× (1 − 防御/(防御+150))`，结果不为负 |
| ⑤ 增伤 | `× (1 + 连招 + 词条 + 天赋 + 境界)`，各来源相加 |
| ⑥ 吸血 | 最终伤害 × 吸血率，**不溢出**（封顶气血上限） |
| ⑦ 状态 | 眩晕 / 击退 / 封穴 / 无视防御等按概率施加 |

**4）内力系统（无冷却）**

- 套路释放消耗内力（攻击型与辅助型均消耗）：凡品 10 / 良品 20 / 上品 35 / 极品 55 / 绝世 80。
- 每回合回复：`内息/10 + 内功加成`。
- 内力不足 → 自动改用**普攻**（`攻击力 × 0.5`，无消耗）。
- **无冷却**：内力够就能放。

**5）战斗倾向设置（玩家可选）**

| 设置 | 行为 |
|------|------|
| 优先连招 | AI 追求起势/收势匹配，最大化连招收益（推荐默认） |
| 优先输出 | AI 优先释放最高威力技能，不刻意连招 |
| 自动使用内功主动技 | 开 / 关（见下） |

**6）内功主动技（对原"大招"的替代方案，P1）**

> 原方案的"怒气 + 大招"已删除。为保留玩家在战中的介入感，新增**内功主动技**：不引入新资源，直接消耗内力手动释放。

| 项 | 规则 |
|----|------|
| 解锁 | 主修内功达到「登堂入室」后解锁 |
| 消耗 | 内力 ×40% 上限（一次性） |
| 效果 | 由内功决定：刚猛=全体增伤 30%（3 回合）；灵动=全队先手 +50%（3 回合）；诡变=敌方全体减速 + 我方吸血 +20%（3 回合）；深厚=全队吸血 + 转为护盾 |
| 频率 | 每场战斗限 2 次 |
| 移动端 | 默认自动释放，可在设置中改为手动 |

**7）胜负与回合上限**

- 一方全员气血归零即结束；**30 回合**未分胜负判定为负（防止无限磨）。
- 全队覆灭 → 进入 S13 死亡流程。

### 数值
见 [第 3 章 3.1 战斗数值](03_数值框架.md)。

### 界面

| 界面 | 内容 |
|------|------|
| 布阵界面 | 九宫格拖拽 / 点选换位；显示先手判定预估值、连招链路连线预览、词条生效高亮 |
| 战斗界面 | 顶部回合数与速度控制（1×/2×/4×/跳过）；双方血条 + 内力条；出手队列；连招提示飘字 |
| 战斗结算 | 经验 / 银两 / 掉落（逐件翻开）/ 修为变化 / 声望变化 / 好感度变化 |

### 依赖
S2 属性、S4 功法、S5 装备、S3 境界倍率。

### 验收标准（DoD）

1. 100 场自动化模拟战斗可一键跑完，输出 TTK、平均回合数、各流派胜率报表。
2. 全部加成来源可计算、可拆解展示（悬浮显示"攻击力 520 = 臂力 330 + 装备 190"）。
3. 战斗全程无随机数以外的不可解释结果；同样输入必定同样输出（除随机种子）。
4. 单场战斗（4v4，2× 速度）时长 30～90 秒。
5. 移动端与 PC 端战斗逻辑完全一致（同种子同结果）。

## 2.2 S2 属性与加点

### 目标
玩家 5 秒看懂四维；深度放在派生属性与搭配；属性与功法解耦，任何加点都能修任何功法。

### 规则

**L1 基础四维**（唯一加点处）

| 属性 | 直接作用 | 次级作用 | 代表流派 |
|------|----------|----------|----------|
| 臂力 | 攻击力（×3）、暴击率（每 10 点 +1%） | 招架对抗、刚猛伤害倾向 | 爆发输出流 |
| 身法 | 出手速度、命中/闪避（每 10 点各 +1%） | 连招容错、先手权、移动速度 | 灵动闪避流 |
| 根骨 | 气血（每点 +20）、防御（每点 +1.5） | 招架对抗、吸血容错、前排承伤 | 铁壁吸血坦 |
| 内息 | 内力（每点 +10）、内力回复（每 10 点 +1/回合） | 内功被动强度、连招续航 | 内功续航流 |

**L2 派生属性**：全部由公式派生 + 外部注入，详见 3.1。

**L3 成长 / 隐藏属性**：修为、声望、正邪值、福缘、悟性、内力属性（刚猛/灵动/诡变/深厚）、好感度。

**加点规则**

| 项 | 规则 |
|----|------|
| 固定成长 | 每级四维各 +1 |
| 自由点 | 每级 +3；每次人物境界突破 +5 |
| 洗点 | 可重置，消耗道具（洗髓丹）或银两；价格随等级递增（见 3.5） |
| 上限 | 四维无硬上限，由境界台阶与修为门槛自然约束 |
| 伙伴 | **同深度**：与主角共用同一套四维、加点、境界规则（差异只在获取来源与专属技能） |
| 伙伴加点 | 默认**自动分配**（按伙伴倾向模板），玩家可手动改写（混合制，见 3.2 决策 Q1） |

**对抗配对（不设互克环）**

| 机制 | 配对 | 结算 |
|------|------|------|
| 命中对抗 | 命中（身法）↔ 闪避（身法） | 决定是否生效，命中率 5%~95% |
| 招架对抗 | 我方臂力 ↔ 敌方根骨（差值） | 被招架后按差值造成部分伤害；系数待验证，见 3.1.6 |

### 数值
见 3.1 与 3.5。

### 界面
养成面板（四维 + 自由点 + 境界称号 + 突破按钮 + 洗点）、战斗详情面板（全 L2 + 来源拆解）、L3 面板（悟性以"资质"定性描述，不显示数值）。

### 依赖
S14 天赋、S3 境界。

### 验收标准

1. 加点界面实时预览 L2 变化；一次加点操作 ≤ 2 步。
2. L2 每项均可展开来源构成，来源类别 ≥ 5 类（基础/装备/功法/天赋/词条/好感）。
3. 洗点后四维与派生完全回退，无残留（自动化测试覆盖）。
4. 四维合计与参考面板偏差 ≤ 10%。

## 2.3 S3 人物境界与突破

### 目标
用台阶式成长制造"大跳跃"仪式感；后天起隐藏等级，只以境界称号呈现。

### 规则

**境界阶梯（22 阶）**

| 段落 | 阶 | 等级 | 突破条件 |
|------|----|------|----------|
| 武者 | 武者一境～九境 | Lv1~90（每 10 级一境） | 银两（逐阶递增） |
| 武者 | 武者圆满 | Lv91~100 | 银两 + 凝神丹 |
| 后天 | 后天·小成 / 大成 / 圆满 | 不显示等级 | 银两 + 凝神丹 + 后天材料（药王谷炼丹线）+ **悟性 ≥ 门槛 A** |
| 过渡 | 半步先天 | — | 先天资源（天地灵物，探索/奇遇线）+ **悟性 ≥ 门槛 B** |
| 先天 | 先天·小成 / 大成 / 圆满 | 不显示等级 | 先天资源 + 凝神丹 |
| 过渡 | 半步宗师 | — | 宗师资源（武学至宝 / 宗师之证）+ **悟性 ≥ 门槛 C** |
| 宗师 | 宗师·小成 / 大成 / 圆满 | 不显示等级 | 宗师资源 + 凝神丹 |
| 顶点 | 武侠之巅 | — | 特定条件（机缘 + 资质 + 收集） |

**突破流程（闭关耗时制）**

```
达到经验上限 → 发起闭关（消耗资源）→ 计时（可提前出关，进度保留）
→ 结算成功率（60% + 悟性资质加成 + 道具，上限 95%）
→ 成功：四维各 +5、自由点 +5、解锁下一段经验上限、称号更新、专属演出
→ 失败：不降级不掉级，冷却"打坐一个时辰"后可重试，已消耗时长与资源不返还
```

**减时与丹药**

| 丹药 | 用途 | 效果 | 单次上限 |
|------|------|------|----------|
| 凝神丹 | 人物境界突破 | 每颗 −20% 闭关时长 | 3 颗（最多 −60%） |
| 悟道丹 | 功法境界参悟 | 每颗 −20% 参悟时长 | 3 颗（最多 −60%） |

> 两种丹药**不可混用**；配方分开设计。

### 数值
突破耗时、资源消耗、凝神丹产出闭环见 [3.3](03_数值框架.md)（含对原缺口的回算与定稿）。

### 界面
突破界面：境界进度、闭关剩余时长、成功率（含悟性资质加成明细）、消耗资源清单、失败冷却；高仪式感演出。

### 依赖
S11 经济、S8 生活（丹药）。

### 验收标准

1. 闭关状态可在游戏内以"时辰"推进（睡觉 / 打坐）；提前出关进度保留且不丢失资源。
2. 突破成功率计算结果可展示拆解；上限 95% 生效。
3. 后天起不再显示等级，仅显示境界称号与属性。
4. 每次突破的属性跃升与自由点按规则入账，可回放校验。

## 2.4 S4 功法系统（功法 / 境界 / 修为 / 连招 / 词条）

### 目标
提供全游戏最深处的构筑乐趣：**品质决定底子，境界决定深度，连招与词条决定爆发上限**。

### 规则

**1）学习与装备**

| 项 | 规则 |
|----|------|
| 学习 | 不限数量、可遗忘、可重复学习（重复学习不再增加对应修为） |
| 装备位 | **5 个**：套路一、套路二、套路三、内功、身法（原"外功"统称"套路"，含攻击+辅助型） |
| 品质 | 凡品 → 良品 → 上品 → 极品 → 绝世 |
| 学习门槛（修为） | 凡 0 / 良 10 / 上 30 / 极 60 / 绝 100（v0.14 缩 10 倍，**门槛口径见 3.4 修正**） |
| 套路六类 | 刀法 / 剑法 / 拳掌 / 暗器 / 奇门（含攻击+辅助）/ 枪法 |
| 内力属性 | 内功决定：刚猛 / 灵动 / 诡变 / 深厚（决定词条联动） |
| 多余功法 | ① 传承给伙伴或自己 ② 多本特定凡品合成 → 随机一本良品 ③ 后续扩展 |

**2）功法境界（十境）与参悟**

- 境界：初窥门径 → 略有小成 → 登堂入室 → 融会贯通 → 炉火纯青 → 登峰造极 → 出神入化 → 大巧若拙 → 超凡入圣 → 天人合一。
- 功法 Lv1~100，每 10 级一境；到达境内上限需**发起参悟**。
- 参悟为**后台计时，不中断行动**（初稿：可同时参悟，是否限 2 门待验证）。
- **无成功率**，时间到即进阶；悟道丹减时。
- 每门功法 = **1 个主动招式** + **n 个被动招式**（常见解锁点：第 3 / 6 / 10 境；普通功法 1~2 个被动，顶级 3 个以上）。

**3）修为（8 类，唯一来源 = 武功境界突破）**

- 类别：刀法 / 剑法 / 拳掌 / 暗器 / 奇门 / 枪法 / 内功 / 身法（互不通用）。
- 产出：前 5 次突破各 +1；后 4 次为 2/3/4/5；每提升一个品级每次突破 +2。
- 单门练满：凡 19 / 良 37 / 上 55 / 极 73 / 绝 91 点。
- **进入伤害公式（双差值制）**：
  `修为差距 = 内力修为差距 + 功法类型修为差距`；合计为负 → ÷2；跨类型不结算；建议封顶（单项 ±100、合计 ±150，待验证）。

**4）连招（起势 / 收势）**

| 情况 | 效果 |
|------|------|
| 套路一收势 = 套路二起势 | 连招成功，套路二威力 **+30%** |
| 套路二收势 = 套路三起势 | 三连成功，套路三威力 **+60%**，触发吸血 |
| 连招失败 | 不增不减，正常释放（无惩罚） |
| 辅助型套路插入 | 连招链中断（辅助型起势/收势 1/1 不匹配），下一门攻击型重新起势，无惩罚 |

**5）三层词条**

| 层 | 组合 | 示例效果 |
|----|------|----------|
| 一：套路 × 套路 | 同类或跨类 | 狂风刀法+断岳刀法 → 断岳威力 +20%；刀法+拳掌「刚柔并济」攻击+10% 防御+10%；剑法+暗器「灵动双绝」闪避+10% 暴击+10%；枪法+奇门「奇正相生」击退+额外效果 |
| 二：内功 × 套路 | 词条类型匹配（刚猛/灵动/诡变/深厚） | 金刚不坏体（刚猛）+断岳刀法（刚猛）→ 刀法威力+20% 防御+10%；纯阳无极功（深厚）+流云剑法（灵动）→ 剑法内力消耗−25% 连击+1 |
| 三：内功 × 身法 | 内功词条 × 轻功类型 | 金刚不坏体+铁布衫轻功 → 气血+15% 受伤−10%；吸星大法+凌波微步 → 吸血+15% 闪避+15% |

- 不匹配时：内功基础属性照常生效，仅无额外联动。
- **词条是流派差异的主要承载**（因招式属性绑定已取消）。

### 数值
品质威力、境界倍率见 3.1.4；修为门槛修正见 3.4。

### 界面
功法图鉴（品质/境界/被动/词条标签）、搭配面板（5 位 + 实时显示连招链路与词条触发）、参悟队列。

### 依赖
S1 战斗、S3 境界。

### 验收标准

1. 5 个功法位的任意组合都能正确计算连招链路与词条生效，界面实时反馈。
2. 参悟期间可正常探索战斗，退出游戏后计时仍正确（离线计时）。
3. 修为产出与消耗可对账：任意时刻"已获得修为 = 各功法突破产出之和"。
4. 功法图鉴可筛选按品质/类型/词条类型，筛选条件 ≥ 4 维。

## 2.5 S5 装备与掉落

### 目标
提供清晰的"爆装备"爽感与稳定的战力补足线（占总权重约 10%，但决定手感）。

### 规则

| 项 | 规则 |
|----|------|
| 品质 | 凡兵 → 利器 → 宝器 → 神兵 → 传世 |
| 品质倍率 | ×1.0 / ×1.5 / ×2.2 / ×3.2 / ×5.0 |
| 部位 | 武器（攻击）、防具衣/甲（防御+气血）、饰品戒指/项链（全四维）、鞋（身法+移动） |
| 等级缩放 | `属性 = 基准 × (1 + (装备等级 − 30) × 5%)` |
| 强化 | 消耗材料 + 银两，+1～+10，每级 +4% 主属性（见 3.6） |
| 词条 | 每件装备 0～3 条词条，品质决定条数上限（见 3.6 词条池） |
| 套装 | 通用 2 件套 +10% 部位属性；门派套 4 件套 对应门派武学威力 +15%；传世套 4 件套 全属性 +15%、暴击伤害 +20% |
| 分解 | 无用装备可分解为强化材料（100% 回收强化材料，50% 回收银两） |

### 掉落规则（详见 3.7）

- 所有怪都掉寻访令；怪越强掉率越高；普通怪也有极小概率掉传说令。
- 越级加成：怪比玩家高 1~3 级 → 经验/掉率 +20%；+4~6 → +50%；+7 以上 → +100%。
- 低等级衰减：玩家比怪高 1~3 → 80%；−4~6 → 50%；−7 以上 → **10%（保底）**。

### 界面
背包装备页（品质色、对比提示）、强化界面、分解界面、图鉴。

### 依赖
S11 经济、S8 锻造。

### 验收标准

1. 掉落表可通过配置直接驱动，不需改代码；1000 次模拟掉落的实际分布与配置偏差 ≤ 5%。
2. 装备对比提示正确显示"换上后 L2 变化"。
3. 强化 100% 成功（首版不做失败降级），成本曲线与产出匹配。
4. 分解产物与强化投入可对账。

## 2.6 S6 伙伴 / 好感度 / 寻访令

### 目标
伙伴是战斗的 3/4 战力来源，也是叙事与情感的载体。

### 规则

**1）品质与获取**

| 项 | 规则 |
|----|------|
| 伙伴品质 | 普通 → 优秀 → 稀有 → 传说 |
| 获取 | 仅通过**寻访令**招募；寻访令只能通过刷怪掉落获取，**不可用真实货币购买** |
| 寻访令品质 | 普通 / 优秀 / 稀有 / 传说（品质影响出好伙伴概率） |
| 掉落来源 | 普通怪 → 普通令；精英怪 → 优秀/稀有令；BOSS → 传说令 |

**2）养成（与主角同深度）**

- 共用同一套四维 + 加点 + 境界规则；升级、突破、装备、功法全部可培养。
- 差异：① 初始四维倾向模板不同 ② 有专属技能 / 被动 ③ 好感度系统。

**3）好感度（0~100，5 级）**

| 等级 | 区间 | 效果 |
|------|------|------|
| 陌路 | 0~20 | 不能组队 |
| 相识 | 21~40 | 可组队，基础属性 +5% |
| 信任 | 41~60 | 专属对话，属性 +10%，解锁 1 个被动技能 |
| 知己 | 61~80 | 专属任务，属性 +15%，解锁第 2 个被动技能 |
| 生死之交 | 81~100 | 专属技能/天赋，属性 +20%，解锁隐藏结局相关剧情 |

**提升**：一起战斗 +1~3；送礼 +5~15；完成伙伴任务 +10~20；剧情选择 +5~10；客栈请客/一起喝酒 +3~5。
**下降**：战斗中伙伴死亡 −5；剧情背叛 −20；长期不带该伙伴上阵 → 缓慢下降。

**4）伙伴生态（创意补充，全部保留）**

- 伙伴有脾气：送错礼物、选错对话会掉好感。
- 伙伴之间也有好感：合得来有加成，合不来会吵架（形成"队伍化学反应"）。
- 好感过低或背叛 → 永久离队，甚至变为敌人。
- 好感达标 → 触发专属奇遇，完成后解锁专属技能。
- 好感达标 → 可请伙伴指点武功，涨对应修为（**例外通道**，见 3.4）。
- 伙伴会随机说出心事，倾听并帮忙 → 好感大涨。
- 生死之交的伙伴会在最终结局出场。

### 界面
伙伴列表（品质、定位、倾向）、好感面板（等级、进度、礼物偏好、专属技能树）、寻访界面（消耗寻访令，展示概率公示）。

### 依赖
S1、S5 掉落、S9 任务。

### 验收标准

1. 每名伙伴有独立倾向模板、专属技能、礼物偏好与 1 条专属奇遇。
2. 寻访概率在界面公示（合规要求）；概率与配置表一致。
3. 好感度变化全部有来源记录，可在面板查看流水。
4. 伙伴离队/背叛有明确的前置预警（避免无预警挫败）。
5. **保底机制**：连续 30 次寻访未出稀有及以上，第 31 次必出稀有（写死，不随版本改动）。

## 2.7 S7 门派养成

### 目标
把"生活经营"从旁支玩法升级为**主线查案复仇的根基与手段**：弟子打探线索、产物换情报与武学、门派战对抗仇敌。

### 规则

**1）建立与等级**

| 项 | 规则 |
|----|------|
| 建立条件 | ① 声望 ≥ 500（名动一方）② 拥有据点 ③ 招募到**至少 3 名弟子**（N 值定稿为 3）④ 完成关键剧情节点（揭开凌云阁第一道裂缝） |
| 时机 | 阶段 2 末 ～ 阶段 3 初 |
| 据点选址（三选一） | 中原繁华地（经济好/人脉多 ↔ 关注度高/易暴露）／边陲清幽地（隐蔽/资源独特 ↔ 经济弱/交通不便）／旧世家废墟（藏秘境线索/有底蕴 ↔ 可能有残留势力） |
| 门派要素 | 门派名（自定义）、门派等级、门派声望、门派特色（由武学路线/经营路线决定） |
| 门派等级 | 1～5 级；提升需门派声望 + 资源；等级限制可建建筑等级与弟子位 |
| 解锁建筑 | 练功房（创建立即可）→ 丹房/药田/农田（1 级）→ 厨房/酒坊/商铺（2 级）→ 藏经阁（3 级） |
| 弟子位 | 1 级 3 人 → 2 级 5 人 → 3 级 7 人 → 4 级 9 人 → 5 级 12 人 |
| 弟子获取 | ① 寻访招募（寻访令）② 剧情招募 ③ 声望吸引（门派声望高，主动来投）④ 奇遇触发 |

**门派生产能力（5 项主技能）**：炼丹（丹药：回血/增益/突破/外交礼物）、种植（药材食材）、做菜（食物：回血/临时 buff）、酿酒（酒：社交/外交礼物/临时 buff）、经营（银两/特产）。9 项生活技能（钓鱼/采药/挖矿/伐木/锻造/缝纫/制造等）作为**原料与加工输入**接入上述 5 项。

**2）弟子（天赋 7 类）**

| 天赋 | 基准加成 |
|------|----------|
| 战斗 | 伤害 +20%、血量 +15% |
| 炼丹 | 成功率 +20%、品质 +1 级 |
| 种植 | 产量 +30%、成长时间 −20% |
| 厨艺 | 品质 +1 级、特殊 buff 概率 +15% |
| 酿酒 | 品质 +1 级、特殊效果概率 +15% |
| 经营 | 商铺收益 +25%、砍价 +20% |
| 探索 | 情报获得率 +25%、线索发现 +20% |

- 天赋品质倍率：普通 ×1.0 / 优秀 ×1.3 / 稀有 ×1.6 / 传说 ×2.0；每名弟子 1 主天赋 + 可能 1 副天赋。
- **一键操作**：新增"门派托管"——自动派遣、自动收取、自动加工。移动端默认开启。

**3）生产（回流战斗）**

```
生产 → ① 自用（丹药/食物/装备 → 战前增益或突破资源）
      → ② 售卖（银两）
      → ③ 外交礼物（提升友好值）
      → ④ 兑换武学（友好门派的硬通货）
```

**4）外交**

| 关系档 | 区间 | 效果 |
|--------|------|------|
| 死敌 | −100 ~ −60 | 可开战、可踢馆 |
| 敌对 | −60 ~ −20 | 对方主动攻击 |
| 中立 | −20 ~ +20 | 正常往来 |
| 友好 | +20 ~ +60 | 解锁武学兑换、贸易 |
| 同盟 | +60 ~ +100 | 可结盟、情报共享 |

- 友好值与仇恨值**独立计算，不简单对冲**。
- 增减：对话 ±1~5；剧情关键 ±10~30；委托 +5~20；礼物 +5~30；人情往来 +5~15；得罪 −10~40；主动开战 → 直接降至 −60 以下。
- 武学兑换：友好 ≥ +20 且有可兑换物；价格按品质：普通 100~300 / 优秀 500~1200 / 稀有 2000~5000 / 传说 10000+（仅同盟）。

**5）门派战**

- 开战条件：目标仇恨值 ≤ −60 + 主角门派等级达标 + 足够战斗型弟子。
- 形式：门派群战（最多 5 人 vs 对方弟子）／上门踢馆（逐级挑战）。
- 战利：普通弟子 → 普通装备/技能；精英 → 优秀/稀有；长老/掌门 → 门派核心武学与稀有装备。
- 胜负：胜 = 仇恨值变化 + 门派声望 + 战利品；负 = 损失弟子/资源 + 声望下降。

**6）门派与主线绑定（关键设计）**

| 阶段 | 门派作用 |
|------|----------|
| 阶段 3 | 建立门派 = 复仇与查案的"合法外衣"；弟子探索天赋产出线索 |
| 阶段 4 | 门派战对抗仇敌；外交决定结盟对象 |
| 阶段 5 | 门派规模影响终局结局版本（开宗立派型结局） |

### 数值
见 3.8 门派养成数值。

### 界面
门派主界面（总览 + 弟子 + 建筑 + 外交 + 战报）、弟子详情、生产队列（一键）、外交关系图。

### 依赖
S6 弟子、S8 生活、S11 经济、S12 声望。

### 验收标准

1. 门派每项产出都能追踪到"最终流向"（自用/售卖/礼物/兑换）报表。
2. 一键托管可在 ≤ 3 次点击内完成全部日常。
3. 弟子天赋加成在战斗中可见（伤害/产量日志）。
4. 外交关系变化有事件日志与预警。

## 2.9 S9 任务与奇遇

### 目标
用"不自动寻路 + 有条件触发"的设计保证探索的价值感。

### 规则

| 任务类型 | 说明 |
|----------|------|
| 阶段目标 | 主线推进，由等级 + 声望门槛触发 |
| 支线故事 | 人物/势力故事，含不可逆错过 |
| 势力任务 | 委托与悬赏，影响势力好感与正邪值 |
| 随机奇遇 | 地点 + 条件触发，探索核心产出 |
| 悬赏任务 | 重复可做，稳定产出银两/寻访令 |

**奇遇触发公式（可配置）**

```
触发判定 = 地点匹配 AND (声望区间 OR 正邪区间) AND 条件满足(伙伴/天气/时间/前置任务)
            AND rand() < 基础触发率 × (1 + 福缘加成)
```

**奇遇玩法形式**：做选择 / 打一场 / 解小谜题（三者至少一）。

**选择影响分级**

| 级别 | 影响 |
|------|------|
| 小选择 | NPC 态度与对话 |
| 中选择 | 声望与势力好感度 |
| 大选择 | 后续支线与结局 |

**任务奖励**：经验、银两、装备、功法、寻访令、好感、声望、图鉴成就。

**其他规则**

- 时间限制：紧急任务限时，普通任务不限时。
- 任务失败不是死路 → 触发另一条剧情分支。
- 任务日志：分类 + 地图标记 + 追踪引导。
- **拒绝自动寻路**，只给大致区域标记；寻找过程中可能触发奇遇。
- 隐藏任务发现：靠 NPC 对话 / 江湖传闻 + 探索为主，系统仅辅助。

### 界面
任务日志（分类、地图标记、追踪）、奇遇触发演出（水墨插画 + 选项）、江湖传闻面板。

### 依赖
S1、S6、S12。

### 验收标准

1. 奇遇全部由配置表驱动（地点、条件、分支、奖励），可无代码新增。
2. 单条奇遇从设计到进包 ≤ 2.5 人日（含文案与配置）。
3. 每个区域奇遇数量 ≥ 规划值，且至少 30% 有分支后果。
4. 错过提示明确（窗口关闭时给出一次"你已错过"的弱提示，不含补救入口）。
5. 地图标记精度：只标区域，不标具体点。

## 2.10 S10 穿越者系统

### 目标
玩家的"外挂"，同时是叙事张力来源：用得多会被怀疑。

### 规则

**功能分级解锁**

| 等级 | 功能 | 升级方式 |
|------|------|----------|
| Lv1 | 查看敌人基础属性、任务导航（区域级） | 开局自带 |
| Lv2 | 查看掉落列表、地图探索标记 | 做任务 / 打怪 / 收集 |
| Lv3 | 武功搭配提示、自动采集 / 一键操作 | 同上 |
| Lv4 | 敌人抗性与弱点分析、突破成功率预估 | 同上 |
| Lv5（终局） | 秘境线索 / 真结局相关提示 | 剧情解锁 |

**限制与隐藏**

- 系统需要升级；**会骗人/有隐藏**——关键时刻信息不全，甚至被上古势力干扰。
- 普通 NPC 不知道系统存在（玩家的秘密）。
- 玩家可选择用不用；**用多了会被怀疑**。
- 聪明或强大的 NPC 会察觉异常并产生怀疑。
- 被怀疑后：普通人只是怀疑 → 聪明人开始调查 → 强大势力可能想抢或利用。

**怀疑度（新增量化机制，P1）**

| 项 | 规则 |
|----|------|
| 数值 | 0~100，分 4 档：无感（0~20）/ 疑心（21~50）/ 调查（51~80）/ 觊觎（81~100） |
| 上升 | 在他人面前使用系统功能（每次 +1~3）；被 NPC 目击异常（+5~10）；剧情暴露（+10~30） |
| 下降 | 长期不使用（每游戏日 −1）；刻意隐匿行为（−2）；完成"掩饰"任务（−10） |
| 后果 | 疑心：NPC 对话变化；调查：触发跟踪/盘问事件链；觊觎：势力发起抢夺/利用任务链 |
| 上限保护 | 达到"觊觎"后不直接 Game Over，而是开启一条**高危支线**（可选择对抗或妥协） |

### 界面
系统面板（半透明淡蓝 + 墨色，不挡画面）、信息提示浮层、怀疑度间接呈现（NPC 态度与台词变化，**不显示数值**）。

### 依赖
S9、S6。

### 验收标准

1. 系统功能分级解锁与剧情进度绑定，无提前泄漏。
2. 怀疑度状态可被玩家从 NPC 反馈中感知（至少 3 种表现）。
3. 系统"骗人"事件 ≤ 全流程 3 次，且每次必须可被玩家事后察觉规律（不做无理由误导）。
4. 系统开关可全局关闭（关闭后不影响任何成就达成）。

## 2.11 S11 经济系统

### 目标
银两作为通用润滑剂，产出与消耗平衡；**不设体力**，想玩多久玩多久。

### 规则

| 项 | 内容 |
|----|------|
| 货币 | 银两（唯一主货币）；门派贡献（门派内）；寻访令（非货币，招募专用） |
| 产出 | 打怪卖装备、种田开店、任务悬赏、分解、门派生产售卖 |
| 消耗 | 买装备材料、开店投资、家园升级、突破资源、丹药、洗点、强化、门派建筑 |
| 不支持 | 真实货币购买银两（**不做**，避免"付费买数值"） |

### 数值
产出/消耗平衡表见 [3.9](03_数值框架.md)。

### 界面
背包（分类/筛选/批量出售）、商店、门派账本（收支日报）。

### 验收标准

1. 银两产出/消耗比在任意 5 小时窗口内维持在 0.9~1.1（通过埋点统计）。
2. 全流程不存在"必定破产"或"金钱无限"的区间（模拟 3 条不同玩法路径验证）。
3. 商店出售/购入价差合理（出售 = 价值 ×30%）。
4. 门派账本可查看最近 7 日收支明细。

## 2.12 S12 势力 / 声望 / 正邪值

### 目标
声望管"江湖名望"（解锁玩法内容），正邪值管"道德倾向"（解锁结局与阵营）。两者独立。

### 规则

**五大势力**

| 势力 | 定位 | 特色产出 |
|------|------|----------|
| 六扇门（朝堂系） | 官方，查案、追捕、密探 | 刀法 / 缉捕类 |
| 凌云阁（名门正派） | 正道领袖，剑法正宗 | 剑法（青崖剑法、凌云九剑等） |
| 幽月教（魔道邪宗） | 亦正亦邪，暗杀夺宝 | 暗杀 / 身法类 |
| 江湖散人（含丐帮） | 自由人，靠奇遇与散人传承 | 拳掌 / 棍法 |
| 秘境守护者（守境司） | 隐秘上古势力，后期解锁 | 世界核心秘密 |

**门派机制（执行口径）**：**主角不加入任何门派，而是自创门派**（权威定义见 `06_systems/门派养成.md`）。与既有门派的关系由**友好值 / 仇恨值**双轨决定，通过 NPC 互动 + 剧情选择 + 任务 + 礼物改变：友好 → 兑换武学 / 贸易 / 结盟 / 情报共享；仇恨 → 门派战 / 踢馆 / 战利掉落。自创门派后可招募弟子、建建筑、开展生产（炼丹 / 种植 / 做菜 / 酿酒 / 经营）。

**声望（0~10000，5 档）**

| 档 | 名称 | 门槛 | 解锁 |
|----|------|------|------|
| 0 | 无名 | 0 | 基础玩法 |
| 1 | 小有名气 | 100 | 势力接触 |
| 2 | 名动一方 | 500 | 自创门派 |
| 3 | 威震武林 | 2,000 | 门派战、结盟 |
| 4 | 天下无双 | 10,000 | 终极内容、结局 |

**正邪值**

| 档 | 名称 | 区间 | 影响 |
|----|------|------|------|
| 正 | 侠义道 | > +200 | 正派门派准入、正线结局、侠义奇遇 |
| 中正 | 行走江湖 | 0 ~ +200 | 中立，多数内容开放 |
| 中邪 | 亦正亦邪 | −200 ~ 0 | 部分邪派奇遇、灰色选项 |
| 邪 | 魔道 | < −200 | 邪派门派准入、邪线结局、魔道奇遇 |

**恶行不减声望**——只影响正邪值。

### 界面
势力关系图、声望进度、正邪值以"江湖评价"定性呈现（称号 + 描述，不显示数字）。

### 依赖
S9 任务。

### 验收标准

1. 声望与正邪值互不影响（自动化测试：只做恶行时声望不下降）。
2. 五大势力各有 ≥ 3 条专属任务链与 ≥ 1 门专属武学。
3. 加入/退出门派的影响在 NPC 对话、商店价格、任务可接取性三处可见。
4. 结局判定读取四因子（终局选择、声望、正邪值、关键支线），可穷举验证 ≥ 5 个结局均可达成。

## 2.13 S13 存档 / 死亡 / 周目

### 规则

| 项 | 规则 |
|----|------|
| 存档类型 | 自动（进入场景、战斗前、突破前、每 10 分钟）+ 手动（3 个槽位） |
| 死亡 | 可存档；死亡 = 游戏结束；按当前声望与完成阶段给予结局 |
| 无档 | 从头开始（但**图鉴与成就永久保留**） |
| 读档 | 从最近存档继续；不清除已获图鉴/成就 |
| 云存档 | PC：Steam Cloud；移动：可选账号云同步；支持跨端存档码 |
| 多周目 | 不继承等级/装备/功法/银两/门派；继承图鉴与成就；每增加一周目解锁 1 个周目天赋（最多 3 槽）；二周目起开放隐藏势力线与真结局路径 |

**存档数据结构要求（技术契约）**

- 版本号 + 迁移函数（保证老存档在新版本可读）。
- 存档必须包含：角色状态、伙伴、门派、任务进度、奇遇触发记录、缺失内容标记（错过的记录也要存）、图鉴、设置。
- 存档大小 ≤ 2MB（不含截图）。

### 验收标准

1. 存档/读档 100 次无数据丢失（自动化回归）。
2. 崩溃后自动存档可恢复至最近节点（损失 ≤ 10 分钟进度）。
3. 跨端存档码可在 PC↔移动间互通。
4. 版本升级后旧存档可正常读取（前 3 个大版本兼容）。
5. 死亡结算演出 ≤ 20 秒，可跳过。

## 2.14 S14 天赋 / 开局五问

### 规则

**开局五问**：决定初始四维、兵器加成倾向、天赋倾向。主角身份固定为**穿越成逃犯**，无身份选择。

**六大天赋（五问统计生成，可多选命中）**

| 天赋 | 效果 |
|------|------|
| 独行天下 | 独自上阵：伤害 +30%、防御 +20%、吸血 +10%；带伙伴时减半（+15%/+10%/+5%） |
| 侠肝义胆 | 正派势力好感 +40%、正派商店 −10%、正派任务奖励 +20%；可触发正派 NPC 特殊互动 |
| 枭雄本色 | 邪派势力好感 +40%、邪派商店 −10%、邪派任务奖励 +20%；可触发邪派 NPC 特殊互动 |
| 悟性通神 | 学武功速度 +50%、经验 +25%、隐藏悟性 +5、突破资质门槛降低一档 |
| 百兵之王 | 刀/剑/暗器/奇门/枪法威力 +25%；所选兵器类型额外 +10% 暴击 |
| 拳掌双绝 | 拳掌威力 +25%；攻击 20% 概率眩晕 |

**周目天赋（二周目起）**：① 五问可重选一项 ② 初始携带 1 本指定凡品功法 ③ 寻访令掉率 +20% ④ 起点声望 +100。

### 验收标准

1. 五问的组合可产生全部 6 个天赋中的至少 1 个，且不出现"无天赋"情况。
2. 天赋加成全部在增伤修正/好感计算阶段可见并可拆解。
3. 周目天赋槽正确叠加（最多 3 个）。

## 2.15 系统耦合矩阵与健康度校验

| 系统 | 主要产出 | 流向 1 | 流向 2 | 流向 3 | 是否孤立 |
|------|----------|--------|--------|--------|----------|
| 战斗 | 经验/银两/装备/寻访令 | 属性 | 伙伴 | 经济 | 否 |
| 门派 | 丹药/材料/情报/贡献 | 突破 | 战斗（增益） | 经济 | 否 |
| 生活 | 食材/药材/矿石 | 炼丹/烹饪 | 锻造 | 门派外交 | 否 |
| 奇遇 | 功法/词条/线索/寻访令 | 功法体系 | 叙事 | 声望 | 否 |
| 宠物 | 装饰/小额材料 | 家园 | 图鉴 | — | **弱耦合（可接受，纯收集向）** |
| 穿越者 | 信息 | 战斗决策 | 探索效率 | 怀疑度 | 否 |

**每季度健康度校验项**

1. 每个系统被玩家实际使用的比例（埋点）；低于 15% 的系统需重做入口或奖励。
2. 玩家最强搭配 Top10 的分布（若 Top1 > 25% 说明失衡）。
3. 各阶段平均停留时长 vs 设计值偏差 > 30% 即需调参。
4. 内容消耗速度（每小时消耗的奇遇/任务数）。
