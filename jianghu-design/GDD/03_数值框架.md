## 3.1 战斗数值

### 3.1.1 属性换算（L1 → L2）·定稿

| 一级属性 | 二级属性    | 公式                           | 上下限                         |
| ---- | ------- | ---------------------------- | --------------------------- |
| 臂力   | 攻击力     | `臂力 × 3 + 装备攻击`              | 无硬上限                        |
| 臂力   | 暴击率     | `5% + 臂力/10% + 装备/词条`        | **上限 75%**                  |
| 身法   | 命中 / 闪避 | `每 10 点身法 = +1% 命中 / +1% 闪避` | 命中 **5%~95%**；闪避 **上限 60%** |
| 身法   | 出手速度    | `身法 + 轻功/词条先手加成`             | 决定出手顺序                      |
| 根骨   | 防御力     | `根骨 × 1.5 + 装备防御`            | 减伤边际递减（常数 **150**）          |
| 根骨   | 气血      | `根骨 × 20 + 装备气血 + 内功气血`      | 无硬上限                        |
| 内息   | 内力      | `内息 × 10 + 内功内力`             | 无硬上限                        |
| 内息   | 内力回复    | `内息/10 + 内功加成`（每回合）          | —                           |
| —    | 暴击伤害    | `150% + 装备/词条`               | **上限 300%**                 |
| —    | 吸血      | 内功被动 / 词条 / 三连 / 天赋          | **不超过气血上限**                 |
| —    | 增伤修正    | `1 + 连招 + 词条 + 天赋 + 境界`      | 各来源**相加**                   |

### 3.1.2 核心伤害公式 ·定稿

| 量 | 公式 |
|----|------|
| **攻击力** | 臂力 × 3 + 装备攻击 |
| **功法威力** | 品质基础威力 × 功法境界倍率 × 3 |
| **修为差距** | 内力修为差距 + 功法类型修为差距（合计为负 → ÷ 2；封顶见 3.4.4） |
| **基础伤害** | 攻击力 + 修为差距 + 功法威力 |
| **实际伤害** | 基础伤害 × 减伤修正 × 暴击修正 × 增伤修正 |
| **减伤修正** | 1 − 防御力 ÷（防御力 + 150） |
| **暴击修正** | 暴击时 ×1.5（暴击伤害上限 300%），否则 ×1.0 |
| **增伤修正** | 1 + 连招加成 + 词条加成 + 天赋加成 + 境界加成 |

**权重目标**：四维属性 **45%** ／ 功法威力 **45%** ／ 装备·词条·天赋 **10%**。每次数值调整后必须重跑权重校验（3.10）。

### 3.1.3 防御减伤曲线（常数 150）

| 防御 | 0  | 50  | 100 | 150 | 300   | 600 | 900   |
| -- | -- | --- | --- | --- | ----- | --- | ----- |
| 减伤 | 0% | 25% | 40% | 50% | 66.7% | 80% | 85.7% |

> 高防御适合前排承伤，但永远无法接近 100%。设计上限：单次减伤不超过 **90%**（防御 1350 时达到，正常流程不可达）。

### 3.1.4a 群体伤害递减系数（多目标）

> 功法主动招式的**范围**（10 型，见 [`05_combat/功法系统.md`](../05_combat/功法系统.md) §6.5）命中多个目标时，伤害**按目标序位递减**，防止 AOE 收益随敌人数线性放大。

**递减公式**：第 i 个目标的伤害系数 **a_i = 最大值( 0.40 , 1 − 0.15 ×（i − 1）)**，其中 i 为本次结算中的目标序位（第 1 位为全额）。

| 序位 i | 1 | 2 | 3 | 4 | 5 | 6 | ≥7 |
|:------:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| 系数 a_i | **1.00** | 0.85 | 0.70 | 0.55 | 0.40 | 0.40 | 0.40 |
| 累积 S(i) | 1.00 | 1.85 | 2.55 | 3.10 | 3.50 | 3.90 | +0.40/个 |

- **乘在最终伤害上**（每个目标独立走完 命中 → 暴击 → 基础伤害 → 减伤 → 增伤 后再乘 `a_i`），**不**乘在招式倍率上。
- **只作用于伤害**——治疗 / 增益 / 阵法与内功主动技的 buff **不递减**。
- **序位来源** = 选目标算法的排序位（第 1 位 = 主目标，全额）。
- **校验**（`范围大招 ×0.7` 打 n 个的总有效倍率）：n=2 → 1.30（略亏于单体爆发 1.5）、n=3 → 1.79、n=4 → 2.17、n=6 → 2.73。定位为"**清怪工具而非点杀工具**"。
- **兜底**：若原型实测 AOE 过强，给全体 / 排 / 列范围加**内力消耗 ×1.2~1.3**，或把下限由 0.40 降到 0.35。

### 3.1.5 回合与 TTK 目标

| 敌方类型          | 目标回合数（4 人队，2× 速度） | 目标单场时长   |
| ------------- | ----------------- | -------- |
| 普通怪（3~4 只）    | 2～4 回合            | 20～40 秒  |
| 精英怪（1 + 2 小怪） | 5～8 回合            | 45～80 秒  |
| BOSS          | 10～15 回合          | 90～150 秒 |
| 门派群战（5v5+）    | 8～12 回合           | 80～120 秒 |

**校验公式**

| 量 | 公式 |
|----|------|
| **目标回合数 T** | 敌方总气血 ÷（我方人数 × 单人每回合期望伤害） |
| **我方人数** | 4（门派战 5） |
| **单人每回合期望伤害** | 对所有招式求和（招式倍率 × S(命中数) × 单目标基础伤害 × 命中率）× 释放频率 × 0.9 |

> **多目标折算（新增）**：引入范围维度（[3.1.4a](#314a-群体伤害递减系数多目标)）后，须按每门功法的**范围**折算命中数 `n` 与其累积系数 `S(n)`；单体 `S(1)=1` 时退化为原式。**禁止**用 `× n` 估算 AOE 输出（会高估群攻、低估 TTK）。

**失衡红线**：任意一场战斗 > 30 回合（判负）或 < 1 回合（秒杀）即视为数值缺陷。

### 3.1.6 招架对抗系数 ·定稿（原为待验证）

- 触发：防守方有招架类功法/天赋时，按 `招架率 = 10% + 根骨/20%（上限 40%）` 判定。
- 招架后伤害保留比例：

**保留比例 = 0.30 + 0.70 × 钳制(（我方臂力 − 敌方根骨）÷（我方臂力 + 敌方根骨）, 0, 1 )**——括号内比值小于 0 记 0、大于 1 记 1。

| 臂力 vs 根骨     | 保留比例 | 说明    |
| ------------ | ---- | ----- |
| 臂力 = 根骨      | 65%  | 中性    |
| 臂力 = 2× 根骨   | 88%  | 力量压制  |
| 臂力 = 0.5× 根骨 | 53%  | 被稳稳招架 |

> 修正说明：上表把"差值"改为"比值"，避免高等级数值膨胀导致招架完全失效。原型验证后可整体调整系数区间 [0.2, 0.8]。

### 3.1.7 命中 / 闪避 / 暴击 ·定稿

| 项    | 公式                    | 上下限      |
| ---- | --------------------- | -------- |
| 命中率  | `90% + 命中加成 − 目标闪避`   | 5% ~ 95% |
| 闪避率  | `身法/10% + 装备/词条`      | 上限 60%   |
| 暴击率  | `5% + 臂力/10% + 装备/词条` | 上限 75%   |
| 暴击伤害 | `150% + 装备/词条`        | 上限 300%  |

判定顺序：**先命中，后暴击**；两者独立。

### 3.1.8 内力消耗与续航校验

| 项      | 数值                               |
| ------ | -------------------------------- |
| 套路内力消耗 | 凡 10 / 良 20 / 上 35 / 极 55 / 绝 80 |
| 每回合回复  | `内息/10 + 内功加成`                   |
| 普攻兜底   | `攻击力 × 0.5`，无消耗                  |

**续航校验目标**：上品功法（消耗 35）在 Lv50 面板（内息 90 → 内力 1300，回复 19/回合）下可连续释放 **≈ 37 回合**，超过回合上限 30 —— **不允许出现"打不完就没蓝"的情况**（除极端消耗构筑，那是玩家主动选择）。

### 3.1.9 阵法 / 编队 / 状态数值（对齐《烟雨江湖》）

> 规则见 [2.1-8) 阵法系统](02_系统设计.md) 与 [2.1-9) 状态效果](02_系统设计.md)。  
> 数据表：`src/data/formations.ts`（12 阵法）、`src/data/status.ts`（**16 状态**）。

**① 编队系数（上阵人数 3→4→5，门派战 6）**

| 我方人数 |   编队系数   | 敌方气血缩放 | 说明                |
| :--: | :------: | :----: | ----------------- |
|   3  |   0.75   |  ×0.75 | 阶段 1~2（主角 + 2 伙伴） |
|   4  | **1.00** |  ×1.00 | 基准（阶段 3）          |
|   5  |   1.25   |  ×1.25 | 阶段 4~5（门派等级 ≥ 3）  |
|   6  |   1.50   |  ×1.50 | 门派战（含战斗型弟子）       |

**编队系数 = 我方人数 ÷ 4**；**敌方气血 = 基础模板气血 × 编队系数**。

> **目的**：保证 TTK 恒定（[3.1.5](#315-回合与-ttk-目标) 的目标回合数不因人数变化而漂移）。  
> **验收**：`sim-battle` 必须对 3/4/5/6 人编队各跑 100 场，TTK 偏差 ≤ 30%。  
> **唯一口径**：本节系数为**全局唯一**（3 人 0.75 / 4 人 1.00 / 5 人 1.25 / 6 人 1.50）；`GDD/02` §2.1、`04_characters/伙伴系统` 及任何旧稿一律以本节为准。

**② 阵法加成上限**

- 阵法加成计入**增伤 / 减伤修正**，与词条、天赋**相加后仍受既有总上限约束**：
  - 增伤总计 ≤ **+60%**
  - 减伤总计 ≤ **90%**
- 站位不符：完全符合 = 100% 生效；部分符合 = **50%** 生效；完全不符 = **0%**（UI 明示）
- 阵法等级 1~5 级，加成线性提升（1 级 → 5 级）

**③ 状态数值**

| 项      | 规则                                                                                 |
| ------ | ---------------------------------------------------------------------------------- |
| 抵抗阀    | **韧性** = 根骨 × 0.5 + 内功 + 装备 + 境界；`生效率 = 有效值/(有效值+韧性)`，下限 **25%**                   |
| 来源系数   | 按施加方品质：凡 1.0 / 良 1.1 / 上 1.25 / 极 1.5 / 绝 1.75                                     |
| 阶梯原则   | 状态越强 → **基础概率越低 且 基础有效值越低**（双低）。眩晕 20% / 75（终值 10.8% 最低）；击退 45% / 130（终值 30.2% 最高） |
| 生效率用法  | 控制类**掷骰**（中 / 不中）；减益与持续伤害类**打折数值**（`实际效果 = 面板 × 生效率`）                              |
| 控制递减   | 同目标同场：第 2 次受控 ×0.6，第 3 次及以后 ×0.35（仅控制类）                                            |
| 同状态叠加  | 减益**层数 +1**（不超上限）、剩余回合取较大值；增益**不叠层**、取最大值并刷新回合                                     |
| 层数上限   | 中毒 3 / 流血 5 / 灼烧 3 / 破防 3 / 虚弱 3；破绽不可叠                                             |
| 持续伤害结算 | 回合末统一结算；中毒 / 灼烧按**最大气血**，流血按**当前气血**                                               |
| 属性类状态  | 计入 L2 派生计算，**不得突破**暴击 75% / 闪避 60% / 命中 5~95% / 暴伤 300%                            |
| 免疫标记   | `ironWall` 免疫击退与破防；`immuneFirstControl`（守境阵 5 级）免疫首次控制；`定神` 免疫控制类                  |
| 回合上限   | 单状态最长 3 回合（除战斗结束）                                                                  |
| 组合效果   | **6 组**（腐骨 / 焦土 / 处决 / 崩溃 / 狂飙 / 生生不息），同目标双状态自动触发                                  |

> 完整规则、状态总表、有效值表与生效率验算见 [`05_combat/状态效果系统.md`](../05_combat/状态效果系统.md)。

### 3.2.3 敌方模板 ·定稿（用于关卡配置表）

**推导规则（三步）**

1. **敌方单只气血** = 我方单人目标气血 × 类型系数 × 同场数量修正。其中类型系数：普通怪 1.0 / 精英 3.5 / BOSS 11.0 / 门派弟子 1.3；同场数量修正 = 1 ÷（1 + 0.15 ×（N − 1）），N = 该场敌人数。
2. **敌方攻击** ≈ 我方攻击 × 0.7（普通）/ 0.85（精英）/ 1.0（BOSS）。
3. **敌方防御** ≈ 我方防御 × 0.7（普通）/ 0.9（精英）/ 1.1（BOSS）。

| 等级段      | 普通怪 气血/攻击/防御           | 精英 气血/攻击/防御            | BOSS 气血/攻击/防御           |
| -------- | ---------------------- | ---------------------- | ----------------------- |
| Lv1~10   | 200 / 25 / 10          | 700 / 40 / 15          | 2,200 / 55 / 20         |
| Lv11~25  | 800 / 75 / 35          | 2,800 / 120 / 55       | 8,800 / 160 / 70        |
| Lv26~45  | 1,600 / 165 / 75       | 5,600 / 260 / 110      | 17,600 / 340 / 140      |
| Lv46~70  | 2,700 / 330 / 155      | 9,500 / 520 / 220      | 29,700 / 700 / 270      |
| Lv71~100 | 6,800 / 700 / 340      | 24,000 / 1,100 / 480   | 74,800 / 1,450 / 590    |
| 后天段      | 12,000 / 1,300 / 620   | 42,000 / 2,000 / 880   | 132,000 / 2,700 / 1,080 |
| 先天段      | 18,000 / 2,000 / 900   | 63,000 / 3,100 / 1,280 | 198,000 / 4,200 / 1,560 |
| 宗师段      | 25,000 / 2,900 / 1,250 | 87,000 / 4,500 / 1,800 | 275,000 / 6,000 / 2,200 |

**验证示例（Lv50，我方 4 人）**

- 我方单人期望伤害 ≈ 580/回合 → 全队 2,320/回合。
- 普通怪 3 只：总气血 1,600 × 3 × 1 ÷ (1+0.15×2) ≈ 3,700 → **1.6 回合**（偏快）。
- 调整：普通怪同场 4 只（总气血 ≈ 5,000）→ **2.2 回合** ✓
- 精英 1 + 小怪 2（9,500 + 3,200 = 12,700）→ **5.5 回合** ✓
- BOSS 29,700 → **12.8 回合** ✓

## 3.7 时间系统 ·新增（原方案缺失，影响全部"耗时"机制）

> **问题**：原方案中人物闭关、功法参悟均为"耗时制"，但从未定义时间如何流逝、玩家能否花钱跳过。若不定义，全部"耗时"门槛失效。

### 3.7.1 时间单位与推进方式

| 项      | 规则                                          |
| ------ | ------------------------------------------- |
| 单位     | **时辰**（1 时辰 = 2 游戏小时）；1 游戏日 = 12 时辰 = 24 小时 |
| 自然推进   | 游玩行为推进（探索、战斗、任务按 1～5 分钟实时 = 1 时辰的换算推进）      |
| 主动推进   | **睡觉/过夜**：每日 1 次，推进 6 时辰（12 小时），免费          |
| 赶路推进   | 区域间移动消耗 1～3 时辰；城镇内移动不消耗                     |
| 闭关     | 人物境界突破，期间不可战斗/探索，可提前出关                      |
| 参悟     | 功法境界，**后台计时**，不中断行动                         |
| **禁止** | 不提供"付费跳过时间"（违反付费红线）                         |

### 3.7.2 一周目时间预算 ·定稿

| 项                         | 数值                                                   |
| ------------------------- | ---------------------------------------------------- |
| 玩家实际游玩时长                  | 30～40 小时                                             |
| 时间推进速率                    | 1 实时分钟 ≈ 1 时辰（含战斗与探索的自动推进）                           |
| 一周目游戏内总时长                 | **≈ 1,800～2,400 时辰（3,600～4,800 游戏小时 ≈ 150～200 游戏日）** |
| 闭关占用（21 次，后期平均用 2~3 颗凝神丹） | ≈ 500~600 小时（**约 10%~15%**） ✓                        |
| 可用于参悟的等效时长                | ≈ 1,600～2,200 小时                                     |
| 可练满功法数                    | `总时长 ÷ 129 小时 ≈ 12～17 门` ✓                           |

> **校验结论**：时间预算与"修为门槛需练满 8～11 门功法"的设计意图**匹配**。若压缩游戏时长至 25 小时，需同步下调参悟时长 30%。

### 3.7.3 昼夜与天气

- 昼夜：主要影响**氛围与事件触发**（夜间出现的敌人/奇遇），不折腾战斗数值。
- 天气：影响部分奇遇触发与部分生活技能产出，不影响战斗公式。
- **不做**"夜间命中下降"这类影响战斗的设定（保持公式可预测）。
