## 4.1 世界结构与区域规划

### 4.1.1 三层结构

| 层级 | 单元 | 说明 |
|------|------|------|
| 1 | 世界（大地图） | 最外层容器 |
| 2 | 区域（5 个 + 1 个终局秘境区） | ← 等级带 + 势力带 |
| 3 | 地点节点（城镇 / 野外 / 副本入口） | ← 大地图点选 |
| 4 | 小场景（可探索单元） | ← 点击式探索 + 奇遇触发 |
| 5 | 遭遇（战斗 / 事件 / 宝箱） | ← 战斗与奖励的最小单位 |

### 4.1.2 五大区域 + 终局区

| 区域 | 中心 | 等级带 | 主题 | 核心势力 | 周边节点 | 主线阶段 |
|------|------|--------|------|----------|----------|----------|
| **中原·洛阳** | 洛阳 | Lv1~15 | 庙堂与江湖 | 六扇门、江湖散人（丐帮） | 南阳渡、落霞镇、凤鸣集、双王镇、青山镇 | 阶段 1~2 |
| **江南·杭州** | 杭州 | Lv15~30 | 名门与暗流 | 凌云阁 | 姑苏、龙泉镇、泰安镇 | 阶段 2~3 |
| **巴蜀·成都** | 成都 | Lv30~45 | 乱局与生机 | 药王谷、青城道门 | 青城山、明月山、药王谷 | 阶段 3~4 |
| **东南·泉州** | 泉州 | Lv35~50 | 商路与远方 | 衡山派、海商行会 | 南岭、衡山、泉州港 | 阶段 3~5 并行 |
| **西北·幽州** | 幽州城 | Lv45~70 | 魔道与上古 | 幽月教、秘境守护者 | 敦煌、大雪山、塞北 | 阶段 4~5 |
| **终局·秘境**（新增） | 秘境核心 | Lv70~100+ | 真相与抉择 | 守境司 | 大雪山腹地、秘境入口、秘境核心、无相之殿 | 阶段 5 + 后天/先天段 |

### 4.1.3 区域设计模板（每个区域必须回答的 8 个问题）

| # | 问题 | 示例（中原·洛阳） |
|---|------|-------------------|
| 1 | 玩家为什么来？（叙事钩子） | 逃犯身份暴露，必须离开青山镇避风头 |
| 2 | 这里的核心玩法是什么？ | 缉捕/查案任务 + 丐帮情报网 + 匪患清剿 |
| 3 | 标志性场景是什么？ | 洛水码头、白马寺、天牢、黑虎寨 |
| 4 | 新机制是什么？ | 首次接触"势力友好值"与"悬赏任务" |
| 5 | 等级带与战力锚点？ | Lv1~15；玩家战力 1×，敌人 0.7~1.0× |
| 6 | 产出什么关键资源？ | 小麦/铁矿/洛水瓷；首本良品功法《断魂刀法》 |
| 7 | 有多少隐藏内容？ | 3 个隐藏点（白马寺后院、废弃矿洞深处、关帝庙） |
| 8 | 离开时玩家应该记住什么？ | "名字立起来，命就轻了"（谢九台词） |

## 4.4 支线 / 奇遇 / 势力任务规划

### 4.4.1 支线（44 条）

| 类型 | 数量 | 单条时长 | 设计要点 |
|------|:----:|----------|----------|
| 人物支线（伙伴专属） | 12 | 20~40 min | 每条对应 1 名伙伴，完成后解锁专属技能 |
| 势力支线 | 16 | 15~30 min | 每条绑定 1 个势力的立场冲突 |
| 地点支线 | 12 | 10~20 min | 绑定城镇/据点，揭示当地故事 |
| 长线支线（跨区域） | 4 | 1~2 h | 跨 2 个以上区域，影响结局变量 |

**支线设计规范**

1. 每条支线必须有**至少 1 个不可逆后果**（错过或选择）。
2. 奖励必须包含构筑向资源（功法/词条/寻访令/凝神丹），不能只给银两。
3. 单条支线文本量 ≤ 2,500 字（控制本地化成本）。
4. 每条支线配置 ≥ 1 个地图标记点。

## 4.5 关卡（小场景 / 副本）设计规范

### 4.5.1 小场景结构模板

1. 入口
2. 探索区 A：2~3 个可交互点 + 1 个随机奇遇位
3. 战斗区：0~2 场遭遇
4. 探索区 B：1~2 个可交互点（含 1 个隐藏）
5. 奖励点：宝箱 / 石碑 / 秘籍残页
6. 出口 / 传送点

| 指标 | 目标值 |
|------|--------|
| 单场景可交互点 | 3~6 个（其中 ≥ 1 个隐藏） |
| 单场景战斗场次 | 0~2 场 |
| 单场景停留时长 | 2~5 分钟 |
| 单场景构筑向奖励 | ≥ 1 个 |
| 单场景首次进入的奇遇触发率 | 25%~40%（一次性奇遇 100%） |

### 4.5.2 副本设计模板（以"黑虎寨"为例）

| 项 | 内容 |
|----|------|
| 副本名 | 黑虎寨 |
| 等级 | Lv8（推荐 6~10） |
| 定位 | 阶段 1 教学副本，教会玩家"布阵与连招" |
| 结构 | 3 波小怪 → 1 个精英（寨中头目）→ 1 个 BOSS（孙黑虎） |
| 敌人配置 | 波1：山贼×3；波2：山贼×2 + 弓手×1；波3：头目（精英）+ 山贼×2；BOSS：孙黑虎 + 山贼×2 |
| 目标回合数 | 小怪波 2~3 回合；BOSS 战 6~8 回合 |
| 机制 | BOSS 在气血 < 50% 时进入"狂暴"，伤害 +30%（教会玩家"爆发时机"） |
| 掉落 | 良品《断魂刀法》（必掉，首次）、断魂刀（利器，30%）、银两 200、寻访令·普通 ×2 |
| 时长目标 | 8~12 分钟 |
| 可跳过 | 三星通关后可跳过战斗直接领奖 |
| 复访价值 | 每日悬赏刷新一次（产出银两与材料） |

### 4.5.3 BOSS 设计规范

| 项 | 要求 |
|----|------|
| 阶段数 | ≥ 2（避免一阶段站桩） |
| 机制 | 至少 1 个"必须应对"的机制（如召唤、护盾、蓄力、场地效果） |
| 提示 | 机制发动前必须有 1 回合的视觉/文字预警 |
| 失败体验 | 失败后给出针对性提示（穿越者系统 Lv4 可给出"弱点分析"） |
| 掉落 | 首杀必掉 1 件构筑向奖励 |
| 禁用 | 不做"无提示秒杀"与"必须特定阵容"的设计 |

| ⑥ | 关卡搭建（编辑器内，1 人日） |
| ⑦ | 自测 + 数值校验脚本通过 |
| ⑧ | 集成测试（自动跑通流程）→ 进包 |

**单条标准奇遇目标工时：≤ 2.5 人日**（阶段 1 的硬门槛指标）。

**配置表规范（强制）**

1. 一律 **UTF-8 CSV / Excel**，由脚本导出为二进制或压缩 JSON。
2. **表内不写逻辑**：只填数据；涉及公式的字段只填参数。
3. 所有 `id` 全局唯一且带前缀（如 `GF_`、`EQ_`、`ENC_`）。
4. 提交前必须通过**自动校验脚本**（引用完整性、概率和、数值边界、单调性）。
5. 每次数据变更生成**变更记录**（谁、何时、改了哪一行、为什么）。

### 4.7.3 内容复用策略（降低边际成本）

| 策略 | 说明 | 节省 |
|------|------|------|
| 场景模块化拼装 | 小场景由 5~8 个"地块模块"拼装 | 场景制作 −40% |
| 奇遇模板化 | 4 类模板（选择型/战斗型/解谜型/混合型） | 奇遇工时 −30% |
| 敌人换皮 + 换招式 | 同模型不同招式组 + 不同数值 | 敌人美术 −60% |
| 立绘表情差分 | 1 张立绘 + N 个表情差分 | 立绘成本 −50% |
| 通用 UI 组件库 | 先建组件库再生产页面 | UI 工时 −35% |
| 事件脚本可视化 | 策划用节点编辑器配置，不改代码 | 程序介入 −70% |
