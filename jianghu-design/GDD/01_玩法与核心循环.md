## 1.1 玩法模块总览

《江湖从心》由 **1 个主菜 + 1 个副菜 + 3 条支撑线**构成。所有模块共享同一套四维属性与功法构筑，避免"两套战力"。

**模块结构**（自上而下：主菜 → 三条支撑线 → 推进与结局）：

1. **主菜：开放世界探索武侠**（地图节点 → 小场景 → 奇遇），向下产出「经验 / 装备 / 功法 / 寻访令 / 线索」，再分发给三条支撑线。
2. **三条支撑线**（横向相互往来）：
   - 支撑线 1「战斗」：布阵 + 自动回合；连招 · 词条 · 境界。与支撑线 2 之间以「产物」双向互通。
   - 支撑线 2「门派养成」：弟子 / 生产 / 外交；炼丹 / 烹饪 / 经营。与支撑线 3 之间以「情报」双向互通。
   - 支撑线 3「穿越者系统」：信息 / 导航 / 辅助；分级解锁 + 怀疑度。
3. 三条支撑线分别汇出「战力提升」「资源与情报」「信息优势」，向下汇合。
4. **推进：主线五阶段 → 结局**（声望 / 正邪值 / 关键支线）。

| 模块 | 定位 | 核心决策 | 目标玩家 | 最低维持成本 |
|------|------|----------|----------|--------------|
| 开放世界探索 | 主菜 | 去哪、信谁、救不救 | 全部 | 不可省略 |
| 战斗与功法构筑 | 支撑线 1 | 带谁、怎么站、怎么配功法和词条 | 核心向 | 不可省略 |
| 门派养成 | 副菜 | 招谁、生产什么、跟谁结盟 | 经营向 | 一键操作，最低 5 分钟/日 |
| 生活技能 | 门派养成的输入 | 做什么、给谁用 | 休闲向 | 可托管 |
| 穿越者系统 | 元系统 | 用不用、用多少 | 全部 | 可关闭提示 |
| 图鉴 / 成就 / 宠物 | 收集向 | 集不集齐 | 收集向 | 完全可选 |

## 1.2 核心循环

### 1.2.1 宏观循环（Meta Loop，单周目 30～40 小时）

> 这是玩家"从逃犯到左右江湖格局"的完整弧线，决定长期目标感。

| 步骤 | 环节 | 细节 |
|:----:|------|------|
| 1 | 选择目标 | 主线 / 支线 / 刷怪 / 经营 |
| 2 | 大地图移动 | 节点选择 + 移动耗时（时间推进） |
| 3 | 小场景探索 | 点击式探索 + 奇遇触发 |
| 4 | 遭遇与战斗 | 布阵 → 自动回合 → 结算 |
| 5 | 奖励结算 | 经验 / 银两 / 装备 / 功法 / 寻访令 / 线索 |
| 6 | 养成投入 | 加点 / 突破 / 装备 / 功法升级 / 词条调整 / 伙伴培养 |
| 7 | 战力与选择权提升 | 声望↑ 正邪值变化 势力好感变化 |
| 8 | 阶段推进 | 达到等级 + 声望门槛 → 解锁新区域 / 新玩法 |
| — | 循环 | 第 8 步完成后回到第 1 步，形成闭环 |
| 9 | 终局：结局判定 | 四因子：终局选择 / 声望 / 正邪值 / 关键支线 |
| 10 | 多周目 | 天赋继承 + 新支线 |

**循环健康度检查点（数值侧必须满足）**

| 检查点 | 目标 | 校验方式 |
|--------|------|----------|
| 单次循环时长 | 8～15 分钟（探索 → 战斗 → 养成一节） | 埋点 |
| 循环内必有产出 | 每次战斗至少 2 类奖励 | 配置校验 |
| 30 分钟内必有可见提升 | 至少 1 次等级/装备/功法/境界变化 | 埋点 |
| 停滞风险 | 任意阶段连续 2 小时无新内容解锁 = 失败 | 关卡评审 |

### 1.2.2 中观循环（Session Loop，单次会话 15～120 分钟）

> 这是玩家"打开游戏到关掉游戏"的完整过程。移动端与 PC 端共用同一结构，仅时长与操作粒度不同。

| 顺序 | 阶段 | 细节 |
|:----:|------|------|
| 1 | 启动 | 碎片记忆闪回（叙事钩子）+ 首屏"待办"提示（不强制） |
| 2 | 门派结算 | 一键收取：种植 / 店铺 / 弟子任务 / 宠物（≤60 秒，可跳过） |
| 3 | 选目标 | 主线 / 支线 / 刷怪 / 经营 / 收集（玩家自由选择，无强制引导） |
| 4 | 执行 2~5 次小循环 | 探索 / 战斗 / 奇遇 / 经营 |
| 5 | 整理养成 | — |
| 6 | 存档退出 | 自动存档 + 关键节点提示手动存 |

| 玩家类型 | 典型会话 | 会话内容配比 |
|----------|----------|--------------|
| 主线推进型 | 60～120 min（PC） | 剧情 30% / 探索 25% / 战斗 30% / 养成 15% |
| 碎片休闲型 | 15～30 min（移动） | 门派结算 20% / 战斗 40% / 养成 30% / 剧情 10% |
| 经营国型 | 30～60 min | 门派 50% / 生活技能 25% / 战斗 15% / 剧情 10% |
| 收集国型 | 45～90 min | 探索 50% / 战斗 25% / 图鉴整理 25% |

**设计约束**：任何会话类型都必须在 15 分钟内能完成一次"有意义进展"，否则移动端留存会崩。

### 1.2.3 微观循环（战斗，1～3 分钟/场）

| 环节 | 内容 | 细节 |
|------|------|------|
| 战前 | 布阵（九宫格，主角 + 3 伙伴） | 考虑：前后排 / 承伤分配 / 连招链路 / 词条联动 |
| 第 1 回合 | 按出手速度排序行动 | 每次行动：内力判定 → 选择功法 → 命中判定 → 暴击判定 → 伤害计算 → 防御减免 → 增伤修正 → 吸血 → 状态施加 |
| （连招） | 连招：前招收势 = 后招起势 | 威力 +30%（三连 +60% + 吸血） |
| 循环 | 直到一方全灭 或 回合上限（30 回合 → 判负） | 内力耗尽 → 自动普攻（攻击力 × 0.5） |
| 结算 | 经验 / 银两 / 掉落 / 修为 / 声望 / 好感度 | — |
| 死亡分支 | 全队覆灭 = 读档（有档）或结局（无档） | — |

| 微观决策点 | 玩家可操作性 | 说明 |
|------------|--------------|------|
| 布阵 | 战前 | 唯一强操作点，九宫格位置影响承伤与被击顺序 |
| 功法顺序 | 战前（装备位固定顺序） | 决定连招链路能否成立 |
| 词条搭配 | 战前 | 三层联动决定爆发上限 |
| 内功主动技 | 战中（PC 可选开关） | 消耗内力手动释放（内力 ≥ 阈值时可用），替代原"怒气大招" |
| 加速 / 跳过 | 战中 | 1× / 2× / 4× / 跳过（跳过仅限已三星通关过的战斗） |

> **注意**：原方案已删除"怒气 + 大招"。为保留"手动介入"的爽感，第 2 章将给出替代方案：**内功主动技**（消耗内力的手动释放技能，不破坏"无冷却、内力唯一资源"的框架），列为 P1 优先级。

### 1.2.4 经营循环（门派，日循环 + 周循环）

| 循环 | 步骤链 |
|------|--------|
| 日循环 | 弟子派遣 → 生产产出（药材 / 食材 / 矿石 / 酒）→ 加工（炼丹 / 烹饪 / 锻造）→ 自用（战前增益）或 出售（银两）或 上缴（门派贡献 / 外交筹码） |
| 周循环 | 门派任务刷新 → 外交关系变化（友好兑换武学 / 仇恨触发门派战）→ 门派等级提升 → 解锁新建筑与弟子位 |

**关键设计**：经营产出**必须回流战斗**（丹药 = 战前增益、锻造 = 装备、烹饪 = 临时属性），否则会被玩家判定为"与主线无关的挂机系统"。

## 1.3 首小时体验（FTUE）时间轴

> 目标：30 分钟内让玩家完成一次完整循环并产生"再来一次"的欲望；60 分钟内经历第一个情绪高点。

| 时间 | 内容 | 玩家学会 | 情绪 |
|------|------|----------|------|
| 0:00～2:00 | 穿越开场：雨夜、追杀、碎片记忆闪回 | 世界观与身份（逃犯） | 紧张、悬念 |
| 2:00～5:00 | 五问开局（决定四维倾向与天赋） | 属性概念 | 代入、期待 |
| 5:00～10:00 | 第一场战斗（教学：布阵 → 自动 → 结果） | 布阵、战斗流程 | 爽感、上手 |
| 10:00～15:00 | 第一次掉落 + 第一次装备 + 第一次加点 | 养成闭环 | 成长快感 |
| 15:00～22:00 | 第一个奇遇（含 2 选项分支）+ 生存抉择 | 选项会影响结果 | 好奇、后果意识 |
| 22:00～30:00 | 洛阳城探索 + 首个精英怪 + 功法获取 | 功法装备与连招 | 构筑萌芽 |
| 30:00～45:00 | 首个伙伴加入 + 好感度首次提升 | 伙伴与好感 | 归属感 |
| 45:00～60:00 | 首个区域 BOSS（有难度、需搭配） | 搭配意识 | 高潮、成就 |
| 60:00 | 阶段 1 收束：逃犯身份线索推进 + 势力登场钩子 | — | 留下继续动机 |

**FTUE 硬性要求**

1. 前 10 分钟不出现超过 3 个并行系统，逐级解锁。
2. 教学全部通过"任务式引导"，不用长文本弹窗（单次文本 ≤ 80 字）。
3. 前 60 分钟必须给予一次"免费洗点"，让玩家敢试错。
4. 首次死亡前必须已自动存档（避免挫败流失）。

## 1.4 目标梯度与动机设计

### 1.4.1 三层目标梯度（每一层都在同一时刻可被玩家看到）

| 层级 | 目标 | 时间尺度 | 呈现位置 |
|------|------|----------|----------|
| 短期 | 打掉这个精英 / 完成这条支线 / 攒够突破资源 | 5～30 分钟 | 任务追踪、战斗目标 |
| 中期 | 学成一套连招链 / 招募心仪伙伴 / 建立门派 | 2～8 小时 | 系统面板进度条 |
| 长期 | 推进到下一阶段 / 达成某个结局 / 集齐图鉴 | 10～40 小时 | 主线阶段页、图鉴 |

### 1.4.2 动机映射（玩家类型 → 钩子）

| 玩家动机 | 对应钩子 | 关键系统 |
|----------|----------|----------|
| 成就（Achiever） | 境界突破、图鉴集齐、成就印章 | 境界系统、图鉴 |
| 探索（Explorer） | 隐藏山洞、随机奇遇、地图迷雾 | 区域探索、奇遇系统 |
| 社交（Socializer） | 伙伴好感、门派弟子、NPC 态度变化 | 好感度、门派 |
| 竞争/支配（Killer） | 门派战、势力对抗、正邪路线 | 势力与门派战 |
| 收集/经营 | 宠物、时装、店铺收益 | 生活经营、外观 |

### 1.4.3 正反馈投放节奏（防疲劳）

| 时段 | 投放 | 目的 |
|------|------|------|
| 每 5～10 分钟 | 掉落、经验条推进 | 微反馈 |
| 每 30～60 分钟 | 等级提升 / 新功法 / 新装备 | 中反馈 |
| 每 2～4 小时 | 境界突破 / 新区域 / 新伙伴 | 强反馈 |
| 每 8～10 小时 | 阶段推进 / 势力事件 | 里程碑 |
| 终局 | 结局演出 + 周目天赋 | 收束与复玩 |

## 1.5 失败、遗憾与不可逆设计

| 机制 | 规则 | 设计意图 |
|------|------|----------|
| **死亡** | 全队覆灭即结束；有存档则读档，无存档则按当前声望与阶段给予结局 | 让"活着"有重量 |
| **存档** | 自动存档（进入场景、战斗前、突破前）+ 手动存档（不限次）；死亡不清档 | 尊重玩家时间，避免挫败流失 |
| **错过** | 奇遇/支线有触发窗口（时间、天气、声望、伙伴状态）；窗口关闭即永久错过 | 真实感、鼓励多周目 |
| **错过不阻塞** | 错过不影响阶段推进与结局可达成性，只影响结局"版本"与支线体验 | 防止玩家被卡死 |
| **正邪值** | 恶行降低正邪值但不减声望；两者独立 | 允许"名震江湖的魔头"与"默默无闻的侠客"两种人生 |
| **伙伴离队** | 好感度过低或剧情背叛 → 永久离队，甚至转为敌人 | 选择有代价 |
| **穿越者反噬** | 滥用系统 → 怀疑度上升 → 被调查/被抢夺 | 元系统参与叙事张力 |

**失败循环设计原则**：失败必须给出**可执行的下一次尝试方案**（提示"该敌人对某类功法抗性低"由穿越者系统产出，但需消耗系统功能等级）。

## 1.6 多周目设计

| 项 | 规则 |
|----|------|
| 继承 | 图鉴、成就永久保留；重开可获得已有图鉴/成就的奖励 |
| 不继承 | 等级、装备、功法、银两、门派（保证一周目体验纯度） |
| 每增加周目 | 解锁 1 个"周目天赋"（初始天赋槽 +1，最多 3 槽）；剧情微调；新增支线 |
| 新增内容 | 二周目起开放"隐藏势力线（秘境守护者）"与真结局路径 |
| 周目天赋示例 | ① 五问可重选一项 ② 初始携带 1 本指定凡品功法 ③ 寻访令掉率 +20% ④ 起点声望 +100 |

**目标**：二周目率 ≥ 12%；真结局只能在二周目后达成（提高复玩动力，但一周目仍有完整体验与 3 个可达结局）。

## 1.7 循环设计的风险与对策

| 风险 | 表现 | 对策 |
|------|------|------|
| 中后期"刷"感重 | 阶段 4~5 变成数值堆叠 | 阶段 4/5 用"势力事件 + 门派战"替代纯刷怪；引入一次性大额奖励节点 |
| 探索回报低 | 玩家只想推主线 | 奇遇奖励必须包含构筑向资源（功法/词条/寻访令），而非只给银两 |
| 战斗全自动导致无聊 | 战中无操作 | 内功主动技手动释放 + 布阵深度 + 4×/跳过让"想快就快" |
| 门派系统被忽略 | 玩家跳过经营 | 主线阶段 3 强制一次"门派建立"节点；门派产出作为突破资源来源之一 |
| 移动端会话太长 | 留存下降 | 移动端默认 2× 战斗速度；门派结算一键化；每区域提供"快速传送点" |
