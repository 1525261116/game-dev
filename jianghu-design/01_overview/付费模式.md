# 付费模式

## 基本原则

- **免费能玩**：核心内容免费，不花钱也能通关
- **不逼氪**：付费项是加速和便利，不是数值碾压
- **花钱买**：加速、外观、剧情和便利

## 付费项分类

| 类别 | 说明 |
|------|------|
| **加速** | 缩短养成时间，如经验加成、修为加成 |
| **外观** | 角色外观、装备皮肤、特效 |
| **剧情** | 额外剧情内容、支线故事 |
| **便利** | 一键操作、自动采集等功能性便利 |

## 不卖的东西

- 不卖数值（不通过付费获得战斗属性优势）
- 不卖伙伴（伙伴通过寻访令获取，寻访令靠刷怪掉落）

> **注**：商业化细节和定价待后续补充。
