# 游戏概念

## 基本信息

| 项目 | 内容 |
|------|------|
| **游戏名** | 江湖从心 |
| **类型** | 武侠开放世界 + 单机 RPG |
| **平台** | 多端支持（手机 / PC / 主机） |
| **画风** | 2.5D 斜视角，江湖气息 |
| **一周目时长** | 30～40 小时（主线 + 主要支线） |
| **难度** | 有挑战，需要搭配武功和装备，但不会卡死 |
| **付费** | 免费能玩，花钱买加速、外观、剧情和便利，不逼氪 |

## 一句话概述

穿越者带着游戏系统，从逃犯走到开宗立派，用门派作为查案复仇的根基，最终左右江湖格局。
