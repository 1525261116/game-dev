# 江湖从心 · 游戏方案设计

> 武侠开放世界 + 单机 RPG · 多端支持（手机 / PC / 主机）

## 项目说明

本仓库为《江湖从心》游戏方案设计项目，包含游戏设计文档（GDD）、世界观设定、剧情设计、角色设计、战斗系统、系统设计、关卡设计、数值设计、美术 UI、交互引导等全部设计内容。

## 目录结构

| 目录 | 说明 |
|------|------|
| `01_overview/` | 游戏概述（概念、核心体验、目标受众、设计支柱、付费模式） |
| `02_worldbuilding/` | 世界观设定（世界地图、五大区域、势力框架、历史背景） |
| `03_narrative/` | 剧情设计（主线五阶段、支线、结局、奇遇） |
| `04_characters/` | 角色设计（主角、伙伴系统、NPC、BOSS） |
| `05_combat/` | 战斗系统（属性、境界与突破、修为、功法〔含攻击范围〕、连招、词条、状态效果、装备） |
| `06_systems/` | 系统设计（任务、抽卡、生活、穿越者、经济、天赋） |
| `07_level/` | 关卡设计（区域、副本、BOSS战） |
| `08_balance/` | 数值设计（成长曲线、战斗数值、装备数值、掉落概率） |
| `09_art_ui/` | 美术与 UI（UI规范、美术风格、音乐音效） |
| `10_ux/` | 交互与引导（新手引导、操作设计、交互流程） |
| `GDD/` | **完整策划设计（执行版 v1.0）**：定位与商业化、玩法与核心循环、系统设计、数值框架、关卡与内容规划、生产计划 |
| `12_tech/` | 技术方案（引擎选型评估报告、技术预算、双端发行要点） |
| `assets/` | 设计资源（参考图、原型图、概念图） |
| `*.png` | 可视化图表（双境界系统对照、伤害结算流程、修为闭环），各设计文档内引用 |
| `reference/` | 参考资料（原始策划案） |
| `templates/` | 文档模板（角色、NPC、系统设计模板） |
| `drafts/` | 草案区（未定稿 / 待评审的设计草稿，定稿后并入对应编号模块） |

## 交付稿（根目录）

> **交付格式约定：只产出 Markdown（.md）**。根目录的 v1.0 DOCX 为历史产物，后续版本不再同步导出。

| 文件 | 说明 |
|------|------|
| `../江湖从心_完整策划设计_v1.0.md` | **完整策划设计（执行版）正式交付稿**，由 `GDD/` 各章合并导出 |
| `../江湖从心_引擎选型评估报告_v1.0.md` | **引擎选型评估正式交付稿**（首选 Unity 6.x LTS，备选 Cocos Creator） |
| `../江湖从心_策划案_v0.2.md` | 原始策划案（历史版本） |

> 各章源文件在 `GDD/`，可直接编辑；需要重新合并时用 `../build_gdd_docx.py`（该脚本会附带生成 DOCX，非必需）。
