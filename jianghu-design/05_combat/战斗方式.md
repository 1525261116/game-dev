# 战斗方式

## 基本规则

- 战前排兵布阵，战中全自动
- 上阵人数：主角 + 3 个伙伴，共 4 人
- 站位：九宫格，有前中后、上中下，站位讲究策略

## 九宫格站位

```
  上   中   下
┌────┬────┬────┐
│ 1  │ 2  │ 3  │  前排（近战/承伤）
├────┼────┼────┤
│ 4  │ 5  │ 6  │  中排（均衡/支援）
├────┼────┼────┤
│ 7  │ 8  │ 9  │  后排（远程/辅助）
└────┴────┴────┘
```

### 站位规则

| 位置 | 特点 | 适合 |
|------|------|------|
| 前排（1/2/3） | 优先承伤、受近战攻击 | 高防御、刀法/拳掌/枪法 |
| 中排（4/5/6） | 均衡，可进可退 | 剑法、均衡型 |
| 后排（7/8/9） | 免于近战直击，易被暗器/远程锁定 | 暗器、内功辅助、治疗 |

### 阵型策略要点

- 前排挡伤，后排输出/辅助，是最基础阵型。
- 敌方 AI 会优先攻击「同列」单位，玩家可利用站位诱导承伤。
- 连招站位：同一列的前中后三人，若外功起势/收势匹配，可跨位触发「列连击」。
- 特定功法有「范围伤害」（如枪法横扫前排三格），站位密集会受牵连。

## 出手顺序

1. **先手判定**：比较双方「身法 + 先手加成（身法/轻功、词条）」，高者先手。
2. **回合内出手**：按场上单位「身法值」从高到低依次行动。
3. **同身法**：先手方优先，再按站位顺序（1→9）。

### 身法与出手的关系

| 身法差距 | 出手影响 |
|----------|----------|
| 身法大幅领先 | 稳定先手 + 高闪避 |
| 身法接近 | 先手 55 开，看先手加成 |
| 身法落后 | 后手，但可用控制功法反制 |

## 战斗流程

```
战前布阵 → 先手判定 → 回合循环（自动）→ 胜负判定
```

1. **战前布阵**：玩家调整九宫格站位 + 设置战斗倾向（优先连招/优先输出）。
2. **先手判定**：决定首轮出手顺序。
3. **回合循环**：全场单位按身法依次行动，自动释放外功/普攻，内功被动生效。
4. **胜负判定**：一方全部气血归零（或特定失败条件），战斗结束。

## 玩家可设置

- 优先连招：AI 优先追求起势/收势匹配，最大化连招收益
- 优先输出：AI 优先释放最高威力技能，不刻意追求连招

## 设计要点

- 战前策略（排兵布阵）是核心，战中以自动为主
- 九宫格站位提供空间策略深度
- 玩家可以设置战斗倾向，但不直接操控每一步
- 身法决定出手顺序，与「先手」价值强关联，是快攻流派的核心属性
- **（本轮修订）** 原「怒气 / 大招」机制已移除（怒气不再是派生属性）；若后续要恢复大招体验，需另定积攒资源（如内力 / 冷却）后单独设计
