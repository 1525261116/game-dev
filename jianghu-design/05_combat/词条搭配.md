# 三层词条搭配系统

## 第一层：套路与套路联动

| 搭配 | 效果 |
|------|------|
| 狂风刀法 + 断岳刀法 | 断岳刀法威力 +20% |
| 流云剑法 + 落霞剑法 | 落霞剑法连击 +1 |
| 罗汉拳 + 太极拳 | 太极拳防御 +15% |
| 柳叶刀 + 暴雨梨花针 | 暗器无视防御概率 +10% |
| 判官笔 + 生死符 | 封穴概率 +10% |
| 杨家枪法 + 回马枪 | 击退概率 +15% |

### 跨类型搭配

| 搭配 | 效果 |
|------|------|
| 刀法 + 拳掌 | 刚柔并济：攻击 +10%，防御 +10% |
| 剑法 + 暗器 | 灵动双绝：闪避 +10%，暴击 +10% |
| 枪法 + 奇门 | 奇正相生：击退 + 额外效果 |

## 第二层：内功与套路联动

内功词条类型：**刚猛、灵动、诡变、深厚**
套路词条类型：**刚猛、灵动、诡变、深厚**

| 搭配 | 效果 |
|------|------|
| 金刚不坏体（刚猛）+ 断岳刀法（刚猛） | 刀法威力 +20%，防御 +10% |
| 纯阳无极功（深厚）+ 流云剑法（灵动） | 剑法内力消耗 -25%，连击 +1 |
| 吸星大法（诡变）+ 柳叶刀（灵动） | 暗器吸血 +15%，暴击 +10% |
| 冰心诀（灵动）+ 凌波微步（灵动） | 闪避 +15%，先手 +20% |
| 龙象般若功（深厚）+ 霸刀（刚猛） | 霸刀威力 +25%，气血 +15% |

> 不匹配时：内功基础属性仍然生效，只是没有额外联动效果。
