## 1. 烟雨江湖战斗机制拆解（6 项）

| # | 机制 | 我的理解 | 证据 |
|:-:|------|----------|------|
| 1 | **阵法系统（12 大阵法）** | 战前选择"阵法"，提供全队增益，各有独立效果与获取方式（探索/商店/门派等），是核心的战前策略层 | ✅ 多处独立来源均提到"12 大阵法全解析""全部阵法使用须知，含效果及获取方式"（[ZOL](https://game.zol.com.cn/1024/10240136.html)、[昆多](https://www.kunduo.com/strategy/51530.html)） |
| 2 | **上阵人数随进度增长（3→4→5）** | 并非固定 4 人；人数上限有等级/进度门槛，后期可上 5 人 | ✅ 多个"多少级可以上五个人""怎么上阵5人"问答（[9game](https://www.9game.cn/yyjh/11114208.html)、[游侠](https://app.ali213.net/wenda/116713.html)） |
| 3 | **阵型/站位影响承伤与输出** | 存在前后排概念，站位影响被攻击概率与输出效率（"阵型攻略""武道阵容打造指南"） | ✅ 来源标题佐证（[小米游戏中心](https://game.xiaomi.com/viewpoint/1098803155_1584686205542_13)、[ZOL](https://game.zol.com.cn/1167/11672521.html)） |
| 4 | **丰富的 BUFF / 状态效果** | 状态是战斗深度的重要来源；维基有专门的 BUFF 一览分类（含"减闪避"等细目） | ✅ [碧蓝维基 BUFF 一览](https://wiki.biligame.com/yanyu/%e6%b8%b8%e6%88%8f%e6%94%bb%e7%95%a5/BUFF%28%e6%95%88%e6%9e%9c%29%e4%b8%80%e8%a7%88) |
| 5 | **武学有完整技能数据（含冷却）** | 武学图鉴逐条列出技能数据（如星云剑诀、天刀三式、太阴绝命手）；社区讨论常涉及招式 CD 与集气 | 🟡 图鉴来源可定位（[dvg 图鉴](https://www.dvg.cn/ztgl/60359.html)），但**CD 具体回合数未能核验** ⚠️ |
| 6 | **战斗随机是"序列"制（可 SL）** | 每场战斗的随机结果是**确定序列**，玩家可通过存档/读档（SL）改变结果——这在其社区是公开玩法（"SL 与序列机制全解析"） | ✅ [ZOL 序列解析](https://m.zol.com.cn/article/10319506.html)、[TapTap 序列篇](https://www.taptap.cn/moment/578545467067990077) |

## 2. 与本作现有设计的逐项对比

| # | 机制 | 本作现状 | 差距 | 建议 |
|:-:|------|----------|:----:|------|
| 1 | 阵法系统 | **完全没有**（只有九宫格站位） | 🔴 缺失 | ✅ **采纳**（见 §3.1） |
| 2 | 上阵人数成长 | **固定 4 人**（主角+3 伙伴）；门派战 5 人 | 🟠 偏死板 | ✅ **采纳**（3→4→5，见 §3.2） |
| 3 | 阵型/站位 | 已有九宫格 + 同列集火 + 列连击 | ✅ 已覆盖且更细 | 保持 |
| 4 | BUFF/状态系统 | 仅 眩晕 / 击退 / 封穴（3 种） | 🔴 过薄 | ✅ **采纳扩展**（见 §3.3） |
| 5 | 招式冷却 | **明确设计为"内力消耗、无冷却"**（CHANGELOG v0.6 定案） | 🟡 路线不同 | ⚠️ **不采纳通用 CD**，理由见 §3.4 |
| 6 | 战斗随机序列 | 已要求"可播种 RNG、同种子同结果" | ✅ 一致 | 建议**每场战斗用新种子**，避免 SL 刷战斗（见 §3.5） |
| 7 | 连招（起势/收势） | 已有，且是本作特色 | ➕ 我们没有的它也没有 | 保持（这是本作的差异化） |
| 8 | 词条三层联动 | 已有 | ➕ 差异化 | 保持 |

**结论**：烟雨江湖的战斗 = **阵法 + 编队人数 + 状态系统 + 招式 CD** 四件套。
本作已有 **九宫格 + 连招 + 词条**，缺 **阵法、人数成长、状态系统**。
**采纳前 3 项（缺失项），第 4 项（CD）建议不采纳**——因为本作的"内力 + 连招"已经承担了 CD 的节奏功能，再叠一层 CD 会让自动战斗的 AI 表现变差（AI 会因 CD 空转，玩家观感是"站着不动"）。

## 3. 采纳项的落地方案

### 3.1 阵法系统（新增）

**定位**：战前策略的第二层（第一层是九宫格站位）。阵法 = 一个**全队增益 + 站位约束**的配置。

| 项 | 规则 |
|----|------|
| 获取 | 阵法秘籍：探索隐藏点 / 门派藏经阁 / 势力兑换 / 主线奖励 |
| 装备 | 战前可切换 1 个阵法（不消耗资源，鼓励试错） |
| 升级 | 消耗「阵法残卷」提升等级（1~5 级，加成线性提升） |
| 约束 | 每个阵法**要求特定站位形态**（如"前排满员""三人成列"），站位不符则加成减半或失效 |
| 与门派联动 | 部分阵法为门派专属（自创门派后可在藏经阁研习） |

**首发 12 个阵法（数值为初稿）**

| # | 阵法 | 站位要求 | 效果（1 级 → 5 级） | 获取 |
|:-:|------|----------|---------------------|------|
| 1 | 一字长蛇阵 | 前排 3 格满员 | 全体防御 +8% → +24% | 初始 |
| 2 | 二龙出水阵 | 上下两列各 2 人 | 全体攻击 +6% → +18% | 中原·双王镇 |
| 3 | 三才阵 | 前中后各 1 人 | 全属性 +4% → +12% | 初始 |
| 4 | 四象阵 | 四角站位 | 吸血 +6% → +18% | 江南·剑冢 |
| 5 | 五行阵 | 满编 5 人 | 内力回复 +15% → +45% | 巴蜀·青城后山 |
| 6 | 天罡北斗阵 | 前排 1 人 + 后排 3 人 | 减伤 +10% → +30%，受击反弹 5% → 15% | 六扇门兑换 |
| 7 | 雁行阵 | 中排满员 | 后排输出 +10% → +30%，前排承伤 −8% | 江湖散人 |
| 8 | 混元阵 | 任意 | 连招威力 +10% → +30% | 门派藏经阁 |
| 9 | 龟蛇阵 | 前中满员 | 气血上限 +10% → +30%，速度 −5% | 药王谷 |
| 10 | 锋矢阵 | 单列 3 人 | 单列伤害 +15% → +45%（配合列连击） | 西北·塞北 |
| 11 | 幽月阵 | 任意 | 暴击率 +5% → +15%，命中 −3% | 幽月教（邪线） |
| 12 | 守境阵 | 任意 | 全属性 +6% → +18%，且免疫首次控制 | 秘境守护者（终局） |

> **设计意图**：阵法让"九宫格"从"摆位置"升级为"选战术"，且与已有的**列连击**（锋矢阵）和**连招**（混元阵）产生协同。

### 3.2 上阵人数成长（修改）

| 阶段 | 上阵人数 | 解锁条件 |
|------|:--------:|----------|
| 阶段 1~2 | **3 人**（主角 + 2 伙伴） | 初始 |
| 阶段 3 | **4 人**（主角 + 3 伙伴） | 声望 ≥ 500（自创门派） |
| 阶段 4~5 | **5 人**（主角 + 4 伙伴） | 门派等级 ≥ 3 |
| 门派战 | **最多 6 人**（+ 战斗型弟子） | 门派等级 ≥ 3 |

**影响面（必须同步）**

- 战斗数值：3 人 → 5 人意味着**队伍总输出 +67%**，敌方模板需按人数缩放（新增"编队系数"）。
- 阵法：多数阵法按 5 人设计，3 人时部分阵法不可用（需在 UI 明示）。
- 关卡难度曲线：阶段 1~2 的 BOSS 按 3 人队设计。
- 平衡校验：`sim-battle` 必须支持 3/4/5/6 人编队分别跑。

### 3.3 状态效果系统（扩展）

**替代原"仅 3 种状态"的设计**，建立完整状态框架：

| 类别 | 状态 | 效果 | 持续 | 免疫/驱散 |
|------|------|------|:----:|-----------|
| **控制** | 眩晕 | 无法行动 | 1 回合 | 可被"免疫首次控制"抵挡 |
| | 封穴 | 无法释放功法（只能普攻） | 2 回合 | 可驱散 |
| | 定身 | 闪避归零 | 2 回合 | 可驱散 |
| | 击退 | 出手顺位后移 3 位 | 当回合 | 不可驱散 |
| **减益** | 破防 | 防御 −30% | 2 回合 | 可驱散 |
| | 虚弱 | 攻击 −25% | 2 回合 | 可驱散 |
| | 迟滞 | 速度 −30% | 2 回合 | 可驱散 |
| | 内伤 | 内力回复 −50% | 3 回合 | 可驱散 |
| | 中毒 | 每回合损失 5% 最大气血（可叠 3 层） | 3 回合 | 可驱散 |
| | 流血 | 每回合损失 3% 当前气血（可叠 5 层） | 2 回合 | 可驱散 |
| | 灼烧 | 每回合损失 4% 最大气血，受击额外 +10% | 2 回合 | 可驱散 |
| **增益** | 护体 | 减伤 +25% | 2 回合 | — |
| | 狂暴 | 攻击 +30%，防御 −15% | 3 回合 | — |
| | 疾行 | 速度 +40% | 2 回合 | — |
| | 回春 | 每回合回复 4% 最大气血 | 3 回合 | — |
| | 铁壁 | 免疫击退与破防 | 2 回合 | — |
| | 剑心 | 暴击率 +20% | 2 回合 | — |

**规则**
- 同状态**不叠加**（取最高值），**中毒/流血/灼烧例外**（按层数叠加）。
- 每回合结束统一结算持续性伤害与状态时长。
- **状态来源**：功法被动（境界解锁）、词条、装备特效（C 类词条）、内功主动技。
- **UI**：角色头顶最多显示 4 个状态图标，超出折叠；鼠标悬浮/长按查看详情。

> 这直接补齐了 [GDD 3.5.3 C 类特效词条](../GDD/03_数值框架.md)（封穴/眩晕/击退）的承载框架。

### 3.4 为什么不采纳"通用招式冷却"

| 维度 | 烟雨江湖（CD 制） | 本作（内力 + 连招） |
|------|-------------------|---------------------|
| 节奏来源 | 招式 CD 冷却 | 内力消耗 + 起势/收势链路 |
| 战前策略 | 武功 CD 搭配 | 功法顺序（连招链路）+ 词条 |
| 自动战斗表现 | AI 会在 CD 期间使用低威力招式 | 内力不足自动普攻 |
| 叠加风险 | — | **再加 CD 会导致 AI"空转"**：既没内力又没 CD，观感是站着不动 |

**结论**：两者功能重叠，**同时存在会互相削弱**。
保留本作的"内力 + 连招"，**不引入通用 CD**。
例外：**内功主动技使用回合冷却**（每场限 2 次 + 3 回合 CD），这吸收烟雨江湖"大招有节奏"的手感，同时不污染外功体系。

### 3.5 随机序列（对齐但收口）

烟雨江湖的"序列制"允许玩家 SL 改写战斗结果。本作：

- **保留**确定性（同种子同结果）——这是自动化测试与跨端一致的前提（GDD 5.4 硬要求）。
- **收口**：战斗种子 = `hash(存档版本 + 战斗ID + 战斗次数 + 存档槽)`，**读档后重打会得到相同序列**（与烟雨江湖一致，玩家可 SL 研究策略）。
- 不额外惩罚 SL（单机游戏，尊重玩家时间）。
