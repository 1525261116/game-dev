# 属性系统（人物属性设计）

> **定位**：定义角色（主角 / 伙伴 / 敌人）的属性体系——有哪些属性、各自作用、如何获取、如何成长、境界与突破、上限与流派。
> **关联**：伤害公式与战斗数值见 [`08_balance/战斗数值.md`](../08_balance/战斗数值.md)；人物境界与功法境界、突破机制见 [`境界系统.md`](境界系统.md)；修为见 [`修为系统.md`](修为系统.md)；成长曲线（经验/声望/好感度）见 [`08_balance/成长曲线.md`](../08_balance/成长曲线.md)。
> **说明**：本文核心决策由「你问我答」设计流程确认，后续按评审意见做过结构性修订，完整记录见文末「附录 · 设计决策记录」。

---

## 一、设计目标与原则

| 目标 | 说明 |
|------|------|
| **少而精** | 基础属性收敛为**四维**，玩家 5 秒看懂；深度放在「派生属性 + 搭配」 |
| **双轨并重** | 属性与功法各占约一半战力，**两条成长线都必须有效**（核心决策） |
| **可预测** | 全部固定公式，无随机成长，玩家能自己算伤害 |
| **台阶式成长** | 武者境每 10 级一个境界，突破给「大跳跃」；**后天以上不再显示等级**，纯靠突破进阶 |
| **一个隐藏资质** | 悟性不进战斗面板、不进加点面板，作为**隐藏资质**主导「突破资格 + 秘籍经验」 |
| **流派清晰** | 每维对应一条鲜明流派，加错点也能靠装备功法补救 |

## 二、属性分层架构

**L1 → L2 → L3 关系**：L1 基础四维经「固定换算」派生为 L2 战斗派生属性；L2 同时接受「加成注入」，注入来源为装备 · 功法 · 天赋 · 丹药 · 伙伴好感度 · 词条 · 境界；L3 为成长 / 隐藏属性，独立成层。

| 层级 | 名称 | 展示位置 | 内容 | 层级关系 |
|------|------|----------|------|----------|
| L1 | 基础四维 | 养成面板 · 玩家唯一加点处 | 臂力 · 身法 · 根骨 · 内息 | 经「固定换算」向下派生 L2 |
| L2 | 战斗派生属性 | 战斗面板 | 攻击 / 防御 / 气血 / 内力 / 暴击 / 命中闪避 … | 由 L1 换算 + 外部「加成注入」（装备 · 功法 · 天赋 · 丹药 · 伙伴好感度 · 词条 · 境界） |
| L3 | 成长 / 隐藏属性 | （独立层） | 修为 · 声望 · 福缘 · 悟性 · 内力属性 | 独立于 L1 / L2 的成长与隐藏层 |

| 层级 | 名称 | 内容 | 展示位置 |
|------|------|------|----------|
| **L1** | 基础四维 | 臂力、身法、根骨、内息 | 角色养成页（加点面板） |
| **L2** | 战斗派生属性 | 攻击力、防御力、气血、内力、暴击、命中/闪避… | 战斗详情页 |
| **L3** | 成长 / 隐藏属性 | 修为、声望、福缘、**悟性（隐藏）**、内力属性 | 系统页面 |

> **原则**：玩家只对 **L1** 加点；**L2** 全部由公式派生 + 外部注入；**L3** 靠玩法行为积累。三层不重叠。
> **v0.6 修订**：悟性由「五维之一」下调为 **L3 隐藏属性**，基础维度收敛为四维。

## 三、基础四维（L1）详解

| 属性 | 直接作用 | 次级作用 | 代表流派 |
|------|----------|----------|----------|
| **臂力** | 攻击力（×3）、暴击率（每 10 点 +1%） | 招架对抗（见第六节）、刚猛伤害倾向 | 爆发输出流 |
| **身法** | 出手速度、命中 / 闪避（每 10 点各 +1%） | 连招容错、先手权、移动速度 | 灵动闪避流 |
| **根骨** | 气血（每点 +20）、防御力（每点 +1.5） | 招架对抗、吸血容错、前排承伤 | 铁壁吸血坦 |
| **内息** | 内力上限（每点 +10）、内力回复（每 10 点 +1/回合） | 内功被动强度、连招续航 | 内功续航流 |

> **注**：原「悟性」已从基础维度移除，见第八节「成长 / 隐藏属性」。四维各自独立加成，**不设互克环**（详见第六节）。
> **⚠️ 加点与武功类型解耦（v0.7）**：「代表流派」仅描述**属性倾向的战斗风格**，**与任何功法 / 武器类型无关**——任何加点方案都能修炼任何类型的功法（详见第十节）。

## 四、战斗派生属性（L2）完整表

> 公式详见 [`08_balance/战斗数值.md`](../08_balance/战斗数值.md) 第一节。

| 派生属性 | 计算公式（来源） | 上限 / 基准 |
|----------|------------------|-------------|
| **攻击力** | 臂力 × 3 + 装备攻击 | 无硬上限 |
| **防御力** | 根骨 × 1.5 + 装备防御 | 减伤边际递减（常数 150） |
| **韧性** | 根骨 × 0.5 + 内功韧性 + 装备韧性 + 境界加成 | 生效率下限 **25%**；详见 [`状态效果系统.md`](状态效果系统.md) |
| **气血** | 根骨 × 20 + 装备气血 + 内功气血 | 无硬上限 |
| **内力** | 内息 × 10 + 内功内力 | 无硬上限 |
| **暴击率** | 5%（基础） + 臂力/10% + 装备/词条 | 上限 **75%** |
| **暴击伤害** | 150%（基础） + 装备/词条 | 上限 **300%** |
| **命中率** | 90%（基础） + 命中加成 − 目标闪避 | **5% ~ 95%** |
| **闪避率** | 身法/10% + 装备/词条 | 上限 **60%** |
| **出手速度** | 身法 + 身法/轻功加成 | 决定出手顺序 |
| **内力回复** | 内息/10 + 内功加成（每回合） | — |
| **吸血** | 内功被动 / 词条 / 三连连招 / 天赋 | 不超过气血上限 |
| **增伤修正** | 1 + 连招 + 词条 + 天赋 + 境界加成 | 各来源相加 |

> **v0.6 修订**：删除原「**怒气**」派生属性（及其触发的大招机制）。若要恢复「大招」体验，需重新指定其积攒资源（如内力、冷却），另行设计。

## 五、双轨并重：属性与功法的权重

### 5.1 权重目标

| 板块 | 目标权重 | 说明 |
|------|----------|------|
| 四维属性 | **45%** | 通过「攻击力（臂力 ×3）」提供稳定底盘 |
| 功法威力 | **45%** | 品质 × 功法境界 决定上限，是核心爽点 |
| 装备 / 词条 / 天赋 | **10%** | 提供差异化的加法与百分比 |

### 5.2 核心公式（摘要）

**公式**：

- 攻击力 = 臂力 × 3 + 装备攻击
- 功法威力 = 品质基础威力 × 功法境界倍率 × 3
- 修为差距 = 内力修为差距 + 功法类型修为差距（负数 ÷ 2）
- 基础伤害 = 攻击力 + 修为差距 + 功法威力
- 实际伤害 = 基础伤害 × 减伤修正 × 暴击修正 × (1 + 连招 / 词条 / 天赋 / 境界 增伤)

> **完整公式定义、因子说明、计算示例与防御减伤曲线**：见 [`08_balance/战斗数值.md`](../08_balance/战斗数值.md)。
> **境界倍率表与品质基础威力**：见 [`境界系统.md`](境界系统.md) 第七节。
> **修为系统（门槛 / 获取 / 入伤害）**：见 [`修为系统.md`](修为系统.md)。
> ⚠️ 「招式属性绑定」机制已移除（见第六节末），属性侧统一用 **攻击力（臂力 ×3）**。

## 六、对抗配对（属性之间的关系）

**不设四维互克环**（太难平衡），保留两个轻机制：

| 机制 | 配对 | 结算方式 |
|------|------|----------|
| **命中对抗** | 命中（身法） ↔ 闪避（身法） | 决定攻击是否生效，命中率 5% ~ 95% |
| **招架对抗** | 我方臂力 ↔ 敌方根骨（差值） | 招式被招架后，仍按差值造成部分伤害 |

> **设计意图**：属性关系发生在**结算层**（命中 / 招架），而不是属性层（臂力克身法）。既保留「属性相性」的策略感，又不会出现无解克制。
> **招架机制借鉴同类江湖游戏思路，具体系数待原型验证。**

> **v0.6 修订：移除「招式属性绑定」**
> 原「每门功法绑定 1 个主属性」的联动机制**已取消**。功法不再强绑某一维度，伤害的属性侧统一由 **攻击力（臂力 ×3）** 提供。属性与功法的解耦让功法选择更自由（不再被主属性绑死），代价是「属性即流派」的强关联被削弱——流派差异改由**词条搭配 + 功法特性**承载。

## 八、成长 / 隐藏属性（L3）

| 属性 | 性质 | 作用 | 获取 |
|------|------|------|------|
| **修为** | 成长 | 决定可学功法品质（凡/良/上/极/绝），分 8 类 | **仅由武功境界突破产出**（见 [`修为系统.md`](修为系统.md)） |
| **声望** | 成长 | 解锁主线阶段与自创门派（0 ~ 10000，5 档） | 任务、击败精英/BOSS、门派战、剧情事件 |
| **福缘** | 隐藏 | 影响奇遇触发率、宝箱品质、稀有掉落 | 主线/支线选择、特定奇遇，不显示具体数值 |
| **悟性** | **隐藏（本轮下调）** | **突破资质门槛**、**秘籍经验获取速率**、搭配发现、部分奇遇判定 | **不进加点面板**；靠天赋、奇遇、宝典研读、剧情事件提升 |
| **内力属性** | 隐藏 | 由所修主内功决定（刚猛/灵动/诡变/深厚），决定词条联动 | 更换主内功 |
| **好感度** | 关系 | 伙伴专属，5 档（0 ~ 100），属性 +5% ~ +20% | 一起战斗、送礼、完成任务、剧情选择 |

> **悟性定位**：它是唯一的「投资型 / 资质型」隐藏属性——**不进战斗面板、也不能加点**。它掌控两件事：① 后天 / 先天 / 宗师的**突破资格**；② 秘籍（功法）经验的**获取速率**。前期不涨战力，但决定你能走多高、练多快。

## 九、属性上限与边际收益

| 属性 | 规则 | 设计意图 |
|------|------|----------|
| 防御力 | 减伤 = 防御 /(防御 + **150**)，边际递减 | 防止坦克流叠到近 100% |
| 暴击率 | 上限 75% | 保留「不暴击」的对抗空间 |
| 暴击伤害 | 上限 300% | 防止暴击流一回合秒杀 |
| 闪避率 | 上限 60% | 闪避流强但非无敌 |
| 韧性 | 生效率下限 25%；每点收益递减（`有效值/(有效值+韧性)`） | 防止堆韧性到"免疫控制" |
| 命中率 | 5% ~ 95% | 永远有 miss / 命中可能 |
| 突破成功率 | 上限 95% | 高悟性收益递减，避免必成 |
| 四维 | **无硬上限**，靠境界台阶与修为门槛自然约束 | 满足数值膨胀爽感，又不失衡 |

## 十、流派与加点策略

> **⚠️ 加点与武功类型完全解耦（本轮定案）**：**加点方式和武功类型没有任何关系**——任何加点方案都能修炼任何类型的功法，不存在「加 X 属性才能玩 Y 功法」的绑定。下表「流派」仅描述**属性倾向带来的战斗风格**，不与任何功法类别挂钩；功法之间的差异由**功法特性与词条搭配**承载。

| 流派 | 主加 | 副加 | 战斗风格 | 优势 | 弱点 |
|------|------|------|----------|------|------|
| **爆发输出流** | 臂力 | 身法 | 高暴击、高单次伤害 | 秒杀快感强 | 脆、怕控 |
| **灵动闪避流** | 身法 | 臂力 | 先手压制、闪避存活 | 行动自由 | 单次伤害低 |
| **铁壁吸血坦** | 根骨 | 内息 | 前排承伤、容错极高 | 不易死 | 输出慢 |
| **内功续航流** | 内息 | 根骨 | 内力充盈、连招不断 | 输出稳定 | 前期弱 |

> **修订**：原「速成悟道流（主加悟性）」已移除——悟性不再可加点；原「擅长功法」列已删除——加点与武功类型完全解耦。四维上的玩法方向见上表。

## 十二、与其他系统的联动

| 系统 | 联动关系 |
|------|----------|
| **天赋系统** | 提供百分比加成与倾向（如「悟性通神」强化隐藏悟性收益 / 突破成功率），在增伤修正阶段结算 |
| **功法境界** | 与「人物境界」是两套系统（详见 [`境界系统.md`](境界系统.md)）：人物境界管等级上限与属性跃升，功法境界（初窥门径~天人合一，突破走耗时参悟制）管单门功法威力与被动解锁；**品质决定被动招式数量**（凡1/良2/上3/极4/绝5，见 [`功法系统.md`](功法系统.md) 6.3） |
| **修为系统** | 修为**唯一来源**是武功境界突破；修为差距作为独立加项进入伤害公式（见 [`修为系统.md`](修为系统.md)） |
| **词条搭配** | 三层词条提供百分比加成，是属性之外的差异化来源（招式绑定移除后，词条承担更多流派区分） |
| **伙伴系统** | **主角与伙伴同深度**，共用同一套四维 + 加点规则 |
| **装备系统** | 提供固定属性与词条，是 L2 的主要外部来源 |
| **生活经营** | 烹饪 / 丹药提供临时属性增益，支撑 BOSS 战前准备 |
| **状态效果系统** | 本文新增 L2 派生属性「**韧性**」，是唯一的状态抵抗通道；16 种状态（控制 4 / 减益 6 / 增益 6）由套路被动、词条、装备、内功、丹药提供（详见 [`状态效果系统.md`](状态效果系统.md)） |
| **死亡机制** | 根骨（气血）决定容错；死亡 = 游戏结束 |
