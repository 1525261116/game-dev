## 〇、设计决策（已确认）

|  #  | 决策点  | 结论                           | 理由摘要                                      |
| :-: | ---- | ---------------------------- | ----------------------------------------- |
|  D1 | 抵抗机制 | **新增统一「韧性」属性**               | 本作战中全自动，玩家无临场解控手段；必须给一条可成长、可预期的被动抵抗通道     |
|  D2 | 结算模型 | **混合制**（控制走档位 + 持续伤害/减益走层数）  | 控制是布尔量（"50% 眩晕"无意义）；持续伤害需要强度曲线；层数即累积条的离散版 |

**一句话概括**：**一套数据结构 + 一条生效率公式 + 16 个模板 + 6 组配方**。

## 一、设计原则

| 原则        | 含义                                                  |
| --------- | --------------------------------------------------- |
| **少而精**   | 16 种状态，每种有**唯一功能**，不做功能重叠的"马甲状态"（这是与烟雨江湖 40 种的最大分歧） |
| **参数化**   | 功法不新增状态，只填三个参数：**施加哪一种 + 触发概率 + 给几层**               |
| **可预测**   | 触发走可播种 RNG；结算顺序固定；伤害可手算                             |
| **可反制**   | 韧性（被动） + 定神（增益） + 丹药/装备（战前）三条反制通道，弥补"无法临场解控"        |
| **不打断节奏** | 状态只影响数值与行动权，不弹窗、不要求玩家做选择                            |

## 二、韧性：统一的抵抗阀

### 2.1 定位

韧性是一个 **L2 战斗派生属性**，作用是**唯一的状态抵抗通道**：它决定"敌人的控制/减益在你身上能发挥几成"。

- **不进加点面板**（玩家不直接加韧性），全部由外部来源派生。
- 与「防御力」的区别：防御管**伤害**，韧性管**状态**。

### 2.2 来源公式

**韧性 = 根骨 × 0.5 + 内功韧性 + 装备韧性 + 境界加成**。

| 来源           | 说明                                                          |
| ------------ | ----------------------------------------------------------- |
| **根骨 × 0.5** | 主来源。铁壁型（高根骨）天然抗控，符合直觉                                       |
| **内功韧性**     | 内功携带的固定值。**刚猛 / 深厚**类内功韧性高；**灵动 / 诡变**类内功韧性低但闪避 / 先手高（内含取舍） |
| **装备韧性**     | 装备固定属性 + 词条（B 类词条）                                          |
| **境界加成**     | 每完成一次人物境界突破 +固定值（低境界被高境界控制更疼，体现修为压制）                        |

### 2.3 生效率公式

**生效率 = 状态有效值 ÷（状态有效值 + 韧性）**。

| 边界    |     值    | 说明                              |
| ----- | :------: | ------------------------------- |
| 生效率上限 | **100%** | 韧性为 0 时全额生效                     |
| 生效率下限 |  **25%** | 保证任何状态都有 1/4 机会生效，控制流不会被完全堵死    |
| 边际特性  |    递减    | 韧性越高，每点收益越低（`韧性 = 有效值` 时恰好 50%） |

其中 **状态有效值 = 该状态的基础有效值 × 来源系数**（来源系数由施加方功法品质决定，见 §6.1）。

### 2.4 一条公式，两种解释（混合制的核心）

| 状态类型           | 生效率的使用方式                        | 玩家感知               |
| -------------- | ------------------------------- | ------------------ |
| **控制类**        | **掷骰判定**：生效率 = 控制命中率，中 / 不中（布尔） | "晕住了" / "没晕住"      |
| **减益 / 持续伤害类** | **数值打折**：`实际效果值 = 面板效果值 × 生效率`  | "中了虚弱，但只减了 12% 攻击" |
| **增益类**        | 不受韧性影响                          | —                  |

> **设计要点**：一套公式同时服务布尔判定与连续数值，避免为控制单独开一套规则。

### 2.5 控制递减（防控制链）

自动战斗下玩家无法临场解控，因此必须防止"被按到死"。规则：

> **同一目标在同一场战斗中，第 2 次受到控制类状态时生效率 ×0.6；第 3 次及以后 ×0.35。计次在战斗开始时重置。**

|   受控次数   | 生效率系数 | 举例（眩晕基础生效率 54%，目标韧性 80） |
| :------: | :---: | :---------------------: |
|   第 1 次  |  ×1.0 |           54%           |
|   第 2 次  |  ×0.6 |           32%           |
| 第 3 次及以后 | ×0.35 |           19%           |

> 只作用于**控制类**（眩晕 / 封穴 / 定身 / 击退）。持续伤害与减益类不加递减——它们已受"层数上限"天然约束。

## 三、状态总表（16 种）

**类色约定（用于 UI 与特效）**：控制 = 紫、减益 = 红 / 橙、增益 = 青碧。

### 3.1 控制类（4 种）—— 档位制，布尔判定

| 状态     | 效果                     |  持续  |   基础概率（参考）  |    基础有效值   | 备注                                         |
| ------ | ---------------------- | :--: | :---------: | :--------: | ------------------------------------------ |
| **眩晕** | 无法行动                   | 1 回合 | **20%**（最低） | **75**（最低） | 最强控制 → **概率与有效值双低**，最难中。不与其他控制叠加（同回合只结算一种） |
| **封穴** | 无法释放套路（只能普攻），内力回复 −50% | 2 回合 |     25%     |     85     | 内功流克星                                      |
| **定身** | 闪避归零，且**不参与同列连击**      | 2 回合 |     30%     |     95     | 打断连招链，反闪避流                                 |
| **击退** | 出手顺位后移 3 位             |  当回合 |     45%     |     130    | 顺位控制，最易触发（但收益也最小）                          |

> **为什么眩晕"最强"却"最难中"**：越强的状态，越要**既难触发（低基础概率）、又易被抵抗（低有效值）**，两层相乘后终值最低。见 §6.4。

> **互斥规则**：眩晕 / 封穴 / 定身**三者互斥**（同时存在时只保留最新施加的一个）；击退独立，可与任意控制共存。

### 3.2 减益类（6 种）—— 层数制，数值打折

| 状态     | 效果（按层数递增）                                               |  上限 |  持续  | 基础概率 | 基础有效值 | 唯一功能                  |
| ------ | ------------------------------------------------------- | :-: | :--: | :--: | :---: | --------------------- |
| **中毒** | 每回合 −2% / −3.5% / −5% **最大气血**；**受到治疗 −30%**（不随层数变化）    | 3 层 | 3 回合 |  35% |  110  | 持续伤害 + **抑制治疗**       |
| **流血** | 每回合 −1.5% / −2.5% / −3.5% / −5% / −6.5% **当前气血**（行动后触发） | 5 层 | 2 回合 |  35% |  110  | 持续伤害 + **按当前气血**（不秒杀） |
| **灼烧** | 每回合 −2% / −3% / −4% 最大气血；**受到伤害 +5% / +8% / +12%**      | 3 层 | 2 回合 |  30% |  105  | 持续伤害 + **爆发放大器**      |
| **破防** | 防御 −10% / −18% / −25%                                   | 3 层 | 2 回合 |  40% |  115  | 降低**物理减伤**            |
| **虚弱** | 攻击 −8% / −15% / −22%                                    | 3 层 | 2 回合 |  40% |  115  | 降低**输出**              |
| **破绽** | **受到攻击必定暴击**                                            | 不可叠 | 1 回合 |  30% |   95  | **处决前置**（高风险高回报）      |

> **数值打折示例**：上品功法施加 3 层破防（面板 −25%），若生效率 60%，则实际为 **−15% 防御**；层数仍显示 3 层，UI 上以"实际数值"为准。

### 3.3 增益类（6 种）—— 档位制，不受韧性影响

| 状态     | 效果                        |  持续  | 备注                         |
| ------ | ------------------------- | :--: | -------------------------- |
| **护体** | 减伤 +20%                   | 2 回合 | 与防御力**加算**，减伤总数仍受 80% 上限约束 |
| **狂暴** | 攻击 +25%，防御 −15%           | 3 回合 | 高风险高回报                     |
| **疾行** | 速度 +30%，先手 +20%           | 2 回合 | 抢顺位、抢连招先手                  |
| **回春** | 每回合回复 4% 最大气血             | 3 回合 | 与中毒（抑制治疗）直接对抗              |
| **定神** | **免疫控制类状态**（眩晕 / 封穴 / 定身） | 1 回合 | 唯一的"主动解控"手段，战前准备的核心        |
| **聚气** | 内力回复 +50%                 | 3 回合 | 支撑高频连招                     |

> **增益不叠层**：同名增益重复施加时**取最大值 + 刷新持续回合**。

## 四、组合效果（6 组）

**触发条件**：同一目标身上**同时存在**指定两个状态时，组合效果自动生效（无需额外操作）。组合效果会覆盖或增强原状态。

|  #  | 组合名      | 触发条件               | 效果                                          | 设计意图                  |
| :-: | -------- | ------------------ | ------------------------------------------- | --------------------- |
|  1  | **腐骨**   | 中毒 + 破防            | 中毒的每回合伤害 **+50%**，且破防的剩余回合**不再递减**（持续到战斗结束） | 毒 + 破甲 = 侵蚀，奖励"双腐蚀"配队 |
|  2  | **焦土**   | 流血 + 灼烧            | 流血与灼烧的结算伤害**各 +50%**                        | 双持续伤害叠加的爆发兑现          |
|  3  | **处决**   | 眩晕 + 破绽            | 对目标的下一次攻击**必定暴击且伤害 +50%**；命中后**清除**这两个状态    | 明确的"晕住 → 补刀"连携，爽点最高   |
|  4  | **崩溃**   | 虚弱 + 破防（**两者均满层**） | 立即对目标施加 **1 回合眩晕**，并清除虚弱 / 破防               | 压制到临界点的爆发，条件苛刻所以收益高   |
|  5  | **狂飙**   | 狂暴 + 疾行            | 攻击额外 **+10%**，先手额外 **+20%**                 | 唯一的己方双增益组合            |
|  6  | **生生不息** | 护体 + 回春            | 回复效果 **+100%**，且**免疫"抑制治疗"**（如中毒的 −30%）     | 反制中毒流的解，给治疗位一个明确答案    |

> **未参与组合的状态**：眩晕 / 破绽之外的其余控制（封穴 / 定身 / 击退）、定神、聚气。控制类定位是"打断"而非"放大器"，不参与组合是刻意的。

## 五、结算规则

### 5.1 回合结构（新增"回合末结算"阶段）

1. **回合开始** → 刷新状态生效（计算本回合有效属性）。
2. **行动** → 按身法顺序逐个单位行动（施加状态在单次攻击的第 7 步）。
3. **回合末** → 统一结算（持续伤害 → 组合效果检测 → 回合数递减 → 到期清除）。

| 阶段       | 内容                                                                              |
| -------- | ------------------------------------------------------------------------------- |
| **回合开始** | 把当前所有状态折算进面板（破防 → 有效防御；虚弱 → 有效攻击；疾行 → 有效速度），供本回合行动使用                            |
| **行动中**  | 命中 → 暴击 → 伤害 → 减伤 → 增伤 → 吸血 → **施加状态（第 7 步，含组合检测）**                             |
| **回合末**  | ① 结算持续伤害（中毒 / 流血 / 灼烧），**按出手顺序**逐个单位结算 → ② 检测并触发组合效果 → ③ 所有状态剩余回合 −1 → ④ 清除到期状态 |

> **顺序固定**：持续伤害在回合末结算（而非开始时），避免"刚被施加就立刻吃一次伤害"的体感问题。

### 5.2 叠加规则

| 类型          | 叠加方式                                     |
| ----------- | ---------------------------------------- |
| **控制（4 种）** | 眩晕 / 封穴 / 定身互斥取最新；击退独立                   |
| **减益（6 种）** | **层数 +1**（不超上限），**剩余回合取较大值**；重复施加同层数时不叠加 |
| **增益（6 种）** | **不叠层**，取最大值 + 刷新回合                      |
| **层数上限**    | 见 §3.2；中毒在「腐骨」组合下上限提升为 4 层               |

### 5.3 驱散与免疫

| 手段             | 说明                                                  |
| -------------- | --------------------------------------------------- |
| **定神**         | 免疫控制类（施加时直接判定失败，不消耗控制递减计次）                          |
| **铁壁型词条 / 装备** | 提供"免疫特定状态"或"受到控制时立即解除"，见 [词条搭配.md](词条搭配.md) C 类特效词条 |
| **驱散**         | 暂**不设**通用驱散技能（会削弱状态价值）；改由「定神」+「生生不息」+ 装备承担反制        |
| **不可驱散**       | 击退（当回合自动消失）                                         |

## 六、数值定型

### 6.1 状态有效值 = 基础值 × 来源系数

**来源系数（按施加方功法品质）**

| 功法品质 |   凡  |   良  |   上  |   极  |   绝  |
| ---- | :--: | :--: | :--: | :--: | :--: |
| 来源系数 | 1.00 | 1.10 | 1.25 | 1.50 | 1.75 |

> 高品质功法的控制与减益更难被抵抗——这是"品质决定下限"在状态侧的延伸。

**基础有效值一览**（**越强的状态值越低** → 越容易被韧性抵抗）

| 基础值 | 状态    |
| :-: | ----- |
|  75 | 眩晕    |
|  85 | 封穴    |
|  95 | 定身、破绽 |
| 105 | 灼烧    |
| 110 | 中毒、流血 |
| 115 | 破防、虚弱 |
| 130 | 击退    |

**基础概率一览**（**越强的状态概率越低**）

| 基础概率 | 状态       |
| :--: | -------- |
|  20% | 眩晕       |
|  25% | 封穴       |
|  30% | 定身、灼烧、破绽 |
|  35% | 中毒、流血    |
|  40% | 破防、虚弱    |
|  45% | 击退       |

> **阶梯原则**：强度 ↑ → 基础概率 ↓ **且** 基础有效值 ↓。两层同时下调，保证"强状态"的最终命中率远低于"弱状态"。功法可在参考值上下浮动（见 §7.2）。

### 6.2 韧性参考值（各阶段）

| 阶段          | 参考韧性 | 说明                               |
| ----------- | :--: | -------------------------------- |
| 武者一境（Lv1）   |  ~10 | 初始几乎不设防                          |
| 武者三境（Lv30）  |  ~50 |                                  |
| 武者五境（Lv50）  |  ~80 | 参考面板：根骨 100 → 50 + 内功 20 + 装备 10 |
| 武者圆满（Lv100） | ~150 |                                  |
| 后天武者        | ~200 | 突破开始给固定境界加成                      |
| 先天武者        | ~280 |                                  |
| 宗师          | ~380 | 高韧性 + 定神 = 近乎免疫控制                |

### 6.3 生效率验算（Lv50 对局）

假设：施加方使用**上品**功法（来源系数 1.25），目标韧性 80（Lv50）或 200（后天）。

| 状态 | 基础概率 | 有效值（上品） | 生效率 ＠韧性80 | **最终命中率 ＠韧性80** | 生效率 ＠韧性200 | 最终命中率 ＠韧性200 |
| -- | :--: | :-----: | :-------: | :-------------: | :--------: | :----------: |
| 眩晕 |  20% |    94   |    54%    |    **10.8%**    |     32%    |     6.4%     |
| 封穴 |  25% |   106   |    57%    |      14.3%      |     35%    |     8.8%     |
| 定身 |  30% |   119   |    60%    |      18.0%      |     37%    |     11.1%    |
| 中毒 |  35% |   138   |    63%    |      22.1%      |     41%    |     14.4%    |
| 破防 |  40% |   144   |    64%    |      25.6%      |     42%    |     16.8%    |
| 击退 |  45% |   163   |    67%    |      30.2%      |     45%    |     20.3%    |

> **观察**：  
> ① **最终命中率随状态强度单调递减**（眩晕 10.8% → 击退 30.2%）——强度与命中率形成对冲，强控制不会变成无解。  
> ② 韧性从 80 提到 200（＋150%），眩晕生效率 54% → 32%，仅降约 22 个百分点——**边际递减成立**，不会"堆韧性即免疫"。  
> ③ 控制递减（×0.6 / ×0.35）承担主要的防连锁职责。

### 6.4 两层概率：为什么"最强"也"最难中"

一个状态能否命中，由**两个互相独立、且都随强度反向调整**的环节相乘决定：

**最终命中率 = ① 基础概率（由功法决定）× ② 生效率（由目标韧性决定）**。

| 环节          | 由谁决定                     |   眩晕（最强）  |   击退（最弱）  |
| ----------- | ------------------------ | :-------: | :-------: |
| ① 基础概率      | 施加方**功法**（§7.2），参考值随强度递减 |    20%    |    45%    |
| ② 生效率       | 目标**韧性**；有效值越低越容易被抵抗     |    54%    |    67%    |
| **＝ 最终命中率** | ① × ②                    | **10.8%** | **30.2%** |

> **设计原理**：如果"最强控制"同时拥有高触发率与高有效值，它就会变成无解——**韧性也挡不住，玩家只能拼运气**。因此眩晕采取**双低**：低基础概率（不常出现）+ 低有效值（出现了也容易被韧性挡掉）。  
> 结果是**韧性成为对抗强控制的正解**，而不是被强控制绕过。

## 七、状态来源与功法映射

### 7.1 来源清单

| 来源                  | 主要提供                     |
| ------------------- | ------------------------ |
| **套路被动招式**（按功法境界解锁） | 控制与减益的**主要来源**（占 80%）    |
| **词条**（C 类特效词条）     | 状态的**触发概率提升**与**层数上限提升** |
| **内功被动**            | 增益类（护体 / 回春 / 聚气）与自身韧性   |
| **装备特效**            | 增益与免疫类（定神 / 铁壁）          |
| **丹药 / 烹饪**（战前）     | 增益与抗性，支撑 BOSS 战前准备       |

### 7.2 功法映射规则（不新增状态，只填参数）

每门套路功法在配置表里只写一行：

**一行配置 = 功法 ID → 该功法可施加的状态列表**；列表中每一项写 4 个字段：**状态 ID / 触发时机 / 基础概率 / 层数**。

**示例（3 门）**

| 功法          | 映射                                                    |
| ----------- | ----------------------------------------------------- |
| 五毒神掌（上品·拳掌） | 铁蜈毒：`{中毒, 命中时, 35%, 1层}`；主动招式额外 `{中毒, 命中时, 20%, +1层}` |
| 判官笔（良品·奇门）  | `{封穴, 命中时, 25%, —}`                                   |
| 杨家枪法（良品·枪法） | `{击退, 命中时, 45%, —}`；与「回马枪」同装时击退概率 +15%（沿用既有词条）        |

> **全量 87 门的映射表**由配置管线生成初稿，人工只做审美与强度微调——与动画方案（[12\_tech/动画复用方案\_v1.0.md](../12_tech/动画复用方案_v1.0.md)）同一套思路：**模板 + 参数**。

### 7.3 触发概率与韧性的关系

**最终触发概率 = 基础概率 × 生效率 × 控制递减系数**。

> 基础概率来自功法（参考值见 §6.1，可按功法特性上下浮动，但**强状态一律低于弱状态**）；生效率来自目标韧性；递减系数只作用于控制类。三者相乘后，由可播种 RNG 判定。
