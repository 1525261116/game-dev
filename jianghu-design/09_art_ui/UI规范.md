# UI 规范

## UI 风格

水墨江湖 + 简洁系统面板。

## 主色调

| 色彩 | 用途 |
|------|------|
| 墨色 | 主色调，背景、边框 |
| 宣纸白 | 背景色 |
| 暗金 | 强调、标题、品质高亮 |
| 朱红 | 印章、重要标记 |

## 字体

| 用途 | 字体 |
|------|------|
| 标题 | 毛笔书法体 |
| 正文 | 宋体/楷体 |

## 各场景 UI 风格

| 场景 | 风格 |
|------|------|
| 系统面板 | 淡蓝 + 墨色，半透明，不挡画面 |
| 战斗 UI | 九宫格布阵，血条内力条简洁 |
| 家园 UI | 温馨手绘感，一键操作大按钮 |
| 图鉴 UI | 江湖画册翻页，集齐盖朱红印章 |
