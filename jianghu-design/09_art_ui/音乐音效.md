# 音乐与音效

## 音乐风格

古风为主，穿越感点缀。

## 各场景音乐

| 场景 | 风格 | 配器 |
|------|------|------|
| 主界面 | 空灵舒缓 | 古筝、笛子、箫 |
| 大地图 | 轻快自由，不同区域变奏 | - |
| 战斗 | 紧张不吵 | 鼓点 + 二胡 + 琵琶 |
| 家园 | 轻松温暖 | 古筝 + 木鱼 + 鸟叫 |
| 穿越者专属 | 异常感 | 电子音 + 古琴混搭 |

## 设计要点

- 大地图音乐随区域变化，增强区域辨识度
- 战斗音乐紧张但不嘈杂，保持节奏感
- 家园音乐温馨，营造放松氛围
- 穿越者专属音乐用电子+古琴混搭，制造"不属于这个世界"的异常感
